## 장 개요

제12~18장에서 Attention, RoPE, FFN, RMSNorm, 잔차 연결을 하나씩 만들고, 실제 Qwen2.5의 계층 하나를 직접 계산해 재현했습니다. 부품은 모두 갖추어졌습니다. 이 장에서는 그 부품을 모아 **모델 하나를 처음부터 끝까지 조립합니다.**

다만 0.5B 모델을 그대로 학습시키기에는 우리 실습 환경(CPU 또는 GT 1030 2GB)이 너무 작습니다. 그래서 구조와 계층 이름은 Qwen2와 똑같이 두고 크기만 줄인 실험용 모델 **Qwen2-Tiny**를 설계합니다. 이 모델은 제25장의 사전학습, 제3부의 LoRA, 제5부의 SFT, 제6부의 GGUF 변환까지 책 끝까지 함께 쓰입니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 직접 만든 부품으로 모델 전체를 조립하면, 표준 라이브러리 모델과 똑같이 동작하는가 |
| 실습 결과물 | Qwen2-Tiny 구현, 파라미터 수 손계산, 차원 추적표, HF 형식 저장과 재로딩 비교 |
| 실습 파일 | `examples/ch19/`의 `tiny_model.py`, `hf_compat.py`, `test_ch19.py` |
| 선수 장 | 제10장(Embedding), 제15~18장(Attention·RoPE·FFN·Decoder Layer) |

```text
토큰 번호 ─▶ Embedding ─▶ [Decoder Layer] × 4 ─▶ Final Norm ─▶ LM Head ─▶ Logits
              ▲                                                   │
              └──────────────── 같은 가중치(Weight Tying) ──────────┘
```

## Qwen2-Tiny 설계

작은 모델을 만들 때 원칙은 하나입니다. **구조는 그대로, 크기만 줄인다.** 계층의 종류, 연결 순서, 편향이 붙는 위치, 계층 이름까지 Qwen2와 같아야 합니다. 그래야 Hugging Face가 이 모델을 "Qwen2"로 알아보고, 같은 학습·변환 도구를 그대로 쓸 수 있습니다.

| 항목 | Qwen2.5-0.5B | Qwen2-Tiny |
|---|---|---|
| hidden 크기 | 896 | 256 |
| 계층 수 | 24 | 4 |
| Query 헤드 / KV 헤드 | 14 / 2 | 4 / 1 |
| head_dim | 64 | 64 |
| FFN 중간 크기 | 4,864 | 768 |
| 어휘 크기 | 151,936 | 151,936 |
| rope_theta, RMSNorm eps | 1e6, 1e-6 | 1e6, 1e-6 |
| QKV 편향, Weight Tying | 있음, 있음 | 있음, 있음 |

몇 가지 선택에는 이유가 있습니다.

- **head_dim을 64로 유지했습니다.** 256 ÷ 4 = 64이므로 제16장의 RoPE 함수를 그대로 씁니다.
- **KV 헤드를 1개로 두었습니다.** Query 헤드 4개가 K·V 하나를 함께 쓰는 GQA(제15장)의 극단적인 형태로, 4 : 1 묶음이 됩니다.
- **어휘 크기는 줄이지 않았습니다.** Qwen2.5 토크나이저를 그대로 쓰기 위해서입니다. 토크나이저를 새로 만들면 실제 모델과 데이터를 공유할 수 없습니다. 이 선택의 대가는 제04절에서 숫자로 확인합니다.

## 전체 모델 조립

모델은 세 단계로 이루어집니다.

```text
1. Embedding      ids[B, T]      → x[B, T, 256]        표에서 행을 꺼낸다(제10장)
2. Block × 4      x[B, T, 256]   → x[B, T, 256]        Pre-Norm Decoder Layer(제18장)
3. 출력           Final Norm → LM Head → Logits[B, T, 151936]
```

구현에서 신경 쓴 점은 **이름과 계산을 분리한 것**입니다. `nn.Linear`, `nn.Embedding`은 가중치를 담고 이름을 붙이는 그릇으로만 쓰고, 계산은 제05·15·16·17·18장에서 직접 만든 함수(`linear_forward`, `grouped_attention`, `apply_rope`, `swiglu_ffn`, `rms_norm`)가 합니다. 그릇의 이름은 Hugging Face Qwen2와 똑같이 붙였습니다.

```text
model.embed_tokens.weight                         [151936, 256]
model.layers.0.input_layernorm.weight             [256]
model.layers.0.self_attn.q_proj.weight / .bias    [256, 256] / [256]
model.layers.0.self_attn.k_proj.weight / .bias    [64, 256]  / [64]
model.layers.0.self_attn.v_proj.weight / .bias    [64, 256]  / [64]
model.layers.0.self_attn.o_proj.weight            [256, 256]
model.layers.0.post_attention_layernorm.weight    [256]
model.layers.0.mlp.gate_proj.weight               [768, 256]
model.layers.0.mlp.up_proj.weight                 [768, 256]
model.layers.0.mlp.down_proj.weight               [256, 768]
  … layers.1 ~ layers.3 반복 …
model.norm.weight                                 [256]
lm_head.weight                                    (embed_tokens와 같은 텐서)
```

초기값은 Hugging Face 기본값처럼 평균 0, 표준편차 0.02의 정규분포로 채우고, RMSNorm의 `weight`는 1로 둡니다. 한 가지 다른 점은 편향도 0이 아니라 작은 난수로 채웠다는 것입니다. 편향이 0이면 편향을 빠뜨린 구현도 같은 답을 내므로, 비교 검증이 편향 경로를 잡아내지 못하기 때문입니다.

## Weight Tying

LM Head는 마지막 hidden 벡터를 어휘 151,936개 각각의 점수로 바꾸는 `[151936, 256]` 행렬입니다. Embedding 표도 정확히 같은 Shape입니다. Embedding은 "토큰 → 벡터", LM Head는 "벡터 → 토큰 점수"로 방향만 반대일 뿐 같은 대응 관계를 다루므로, 두 행렬을 **하나의 텐서로 공유**할 수 있습니다. 이것이 Weight Tying입니다.

```python
self.lm_head.weight = self.model.embed_tokens.weight     # 복사가 아니라 같은 텐서
```

공유는 셀 때 주의가 필요합니다. `model.parameters()`는 같은 텐서를 한 번만 내놓지만, `state_dict()`는 이름마다 하나씩 내놓으므로 두 번 셉니다. 저장할 때도 Hugging Face는 공유 텐서를 한 번만 기록합니다. 제10장에서 실제 0.5B 모델의 파일에 `lm_head`가 없던 이유가 바로 이것입니다.

## 차원 추적과 파라미터 수

계층 하나의 파라미터를 손으로 세어 봅시다(h = 256, KV 출력 = 1 × 64 = 64, FFN = 768).

```text
Attention  q: 256×256 + 256   =  65,792
           k:  64×256 +  64   =  16,448
           v:  64×256 +  64   =  16,448
           o: 256×256         =  65,536          소계 164,224
FFN        3 × 256 × 768                          소계 589,824
RMSNorm    2 × 256                                소계     512
───────────────────────────────────────────────────────────
계층 하나                                              754,560
계층 4개                                             3,018,240
Embedding  151,936 × 256                          38,895,616
Final Norm                                                256
───────────────────────────────────────────────────────────
합계                                              41,914,112   (약 4,190만)
```

이 숫자에서 Qwen2-Tiny의 성격이 드러납니다. **파라미터의 92.8%가 Embedding 표입니다.** 실제 계산을 하는 4개 계층은 300만 개 남짓에 불과합니다. 어휘 크기를 줄이지 않은 대가입니다. 0.5B 모델에서 Embedding 비중이 27.6%였던 것(제10장)과 비교하면, 작은 모델일수록 어휘 표가 모델을 지배한다는 것을 알 수 있습니다. 만약 Weight Tying이 없었다면 같은 크기의 LM Head가 하나 더 붙어 8,080만 개로 두 배 가까이 늘어났을 것입니다.

FP32로 저장하면 41,914,112 × 4바이트 = 약 168MB입니다. GT 1030의 2GB에 넉넉히 들어가고, CPU에서도 가볍게 학습할 수 있는 크기입니다.

차원은 처음과 끝만 바뀝니다. 토큰 번호 `[B, T]`가 Embedding에서 `[B, T, 256]`이 되고, 네 계층을 지나는 동안 Shape는 한 번도 바뀌지 않으며, LM Head에서 `[B, T, 151936]`이 됩니다. 잔차 연결이 가능한 것도 모든 계층의 입출력 Shape가 같기 때문입니다.

## Hugging Face 형식 호환

직접 만든 모델이 "정말 Qwen2"인지 확인하는 가장 엄격한 방법은, 그 가중치를 Hugging Face의 `Qwen2ForCausalLM`에 그대로 실어 보는 것입니다. 이 장의 검증은 세 겹입니다.

1. **가중치 싣기**(`load_state_dict`, `strict=True`): 이름 50개와 모든 Shape가 하나도 빠짐없이 일치하는가
2. **저장과 재로딩**(`save_pretrained` → `from_pretrained`): 표준 형식(`config.json` + `model.safetensors`)으로 저장되고 다시 읽히는가
3. **순전파 비교**: 같은 입력에 두 구현이 같은 Logits와 같은 Greedy 생성을 내는가

`strict=True`는 이름이 하나라도 남거나 모자라면 즉시 오류를 냅니다. 이름 하나를 잘못 붙였을 때 조용히 무작위 값으로 남는 사고를 막아 줍니다.

저장된 폴더는 0.5B 모델을 내려받았을 때와 같은 모양입니다. 앞으로 이 폴더는 `AutoModelForCausalLM`, PEFT, 그리고 제6부의 GGUF 변환 도구가 모두 같은 방식으로 읽습니다. 직접 만든 모델이 표준 생태계에 올라탄 것입니다.

## 핵심 실습

### 실습 1. Qwen2-Tiny 조립과 파라미터 수

Hugging Face와 같은 이름의 그릇에 가중치를 담고, 계산은 직접 만든 함수로 합니다. 파라미터 수를 손계산과 비교하고, 순전파 동안 Shape가 어떻게 흐르는지 기록합니다.

파일명: `examples/ch19/tiny_model.py`

```python
# 제19장 실습 1: 제12~18장에서 직접 만든 부품으로 Qwen2-Tiny 전체 모델을 조립한다
#
# 실행: python examples/ch19/tiny_model.py
#
# 계층 이름(model.layers.0.self_attn.q_proj …)은 Hugging Face Qwen2와 똑같이 맞춘다.
# 이름과 Shape가 같아야 제05절에서 가중치를 그대로 옮겨 실을 수 있다.

import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
for p in (ROOT, ROOT / "ch05", ROOT / "ch03", ROOT / "ch14", ROOT / "ch15",
          ROOT / "ch16", ROOT / "ch17", ROOT / "ch18"):
    sys.path.insert(0, str(p))

import torch  # noqa: E402
from torch import nn  # noqa: E402

from linear_scratch import linear_forward  # noqa: E402  (제05장)
from mha_gqa import grouped_attention  # noqa: E402     (제15장)
from norm_residual import rms_norm  # noqa: E402        (제18장)
from rope import apply_rope, rope_cos_sin  # noqa: E402 (제16장)
from swiglu import swiglu_ffn  # noqa: E402             (제17장)

TINY = dict(vocab_size=151_936, hidden_size=256, num_hidden_layers=4,
            num_attention_heads=4, num_key_value_heads=1, intermediate_size=768,
            rope_theta=1e6, rms_norm_eps=1e-6)


class Norm(nn.Module):
    """RMSNorm의 학습 가중치(γ)만 담는 그릇. 계산은 제18장 rms_norm이 한다."""

    def __init__(self, dim):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))


class Attention(nn.Module):
    def __init__(self, c):
        super().__init__()
        h, d = c["hidden_size"], c["hidden_size"] // c["num_attention_heads"]
        kv = c["num_key_value_heads"] * d
        self.q_proj = nn.Linear(h, h, bias=True)       # Qwen2: Q·K·V에만 편향
        self.k_proj = nn.Linear(h, kv, bias=True)
        self.v_proj = nn.Linear(h, kv, bias=True)
        self.o_proj = nn.Linear(h, h, bias=False)


class MLP(nn.Module):
    def __init__(self, c):
        super().__init__()
        h, i = c["hidden_size"], c["intermediate_size"]
        self.gate_proj = nn.Linear(h, i, bias=False)
        self.up_proj = nn.Linear(h, i, bias=False)
        self.down_proj = nn.Linear(i, h, bias=False)


class Block(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.self_attn, self.mlp = Attention(c), MLP(c)
        self.input_layernorm = Norm(c["hidden_size"])
        self.post_attention_layernorm = Norm(c["hidden_size"])


class Body(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.embed_tokens = nn.Embedding(c["vocab_size"], c["hidden_size"])
        self.layers = nn.ModuleList(Block(c) for _ in range(c["num_hidden_layers"]))
        self.norm = Norm(c["hidden_size"])


class Qwen2Tiny(nn.Module):
    def __init__(self, c=TINY):
        super().__init__()
        self.c = c
        self.model = Body(c)
        self.lm_head = nn.Linear(c["hidden_size"], c["vocab_size"], bias=False)
        self.lm_head.weight = self.model.embed_tokens.weight     # Weight Tying: 같은 텐서

    def block(self, b, x, cos, sin):
        c, eps = self.c, self.c["rms_norm_eps"]
        a = b.self_attn
        n = rms_norm(x, b.input_layernorm.weight, eps)
        q = linear_forward(n, a.q_proj.weight, a.q_proj.bias)
        k = linear_forward(n, a.k_proj.weight, a.k_proj.bias)
        v = linear_forward(n, a.v_proj.weight, a.v_proj.bias)
        rope = lambda q_, k_: (apply_rope(q_, cos, sin), apply_rope(k_, cos, sin))  # noqa: E731
        o = grouped_attention(q, k, v, c["num_attention_heads"], c["num_key_value_heads"], rope=rope)
        h = x + linear_forward(o, a.o_proj.weight)                          # 잔차 1
        m = b.mlp
        n = rms_norm(h, b.post_attention_layernorm.weight, eps)
        return h + swiglu_ffn(n, m.gate_proj.weight, m.up_proj.weight, m.down_proj.weight)  # 잔차 2

    def forward(self, ids, trace=None):
        c = self.c
        x = self.model.embed_tokens.weight[ids]                  # [B, T] → [B, T, 256]
        cos, sin = rope_cos_sin(ids.shape[1], c["hidden_size"] // c["num_attention_heads"],
                                c["rope_theta"])
        if trace is not None:
            trace.append(("Embedding", x.shape))
        for i, b in enumerate(self.model.layers):
            x = self.block(b, x, cos, sin)
            if trace is not None:
                trace.append((f"Block {i}", x.shape))
        x = rms_norm(x, self.model.norm.weight, c["rms_norm_eps"])
        logits = linear_forward(x, self.lm_head.weight)          # [B, T, 256] → [B, T, 151936]
        if trace is not None:
            trace += [("Final Norm", x.shape), ("LM Head", logits.shape)]
        return logits


def init_weights(model, seed=0, std=0.02):
    """Hugging Face 기본값처럼 N(0, 0.02)로 초기화한다. 편향도 작게 흔들어 편향 경로까지 검증한다."""
    g = torch.Generator().manual_seed(seed)
    with torch.no_grad():
        for name, p in model.named_parameters():                 # 공유 텐서는 한 번만 나온다
            if name.endswith("layernorm.weight") or name == "model.norm.weight":
                p.fill_(1.0)
            else:
                p.copy_(torch.randn(p.shape, generator=g) * std)
    return model


def count_by_hand(c=TINY):
    h, i, L, V = c["hidden_size"], c["intermediate_size"], c["num_hidden_layers"], c["vocab_size"]
    kv = c["num_key_value_heads"] * h // c["num_attention_heads"]
    attn = (h * h + h) + 2 * (h * kv + kv) + h * h               # q(편향) + k·v(편향) + o
    mlp = 3 * h * i
    layer = attn + mlp + 2 * h                                    # 정규화 2개
    emb = V * h
    return dict(embedding=emb, attention=attn, mlp=mlp, layer=layer,
                layers=L * layer, final_norm=h, total=emb + L * layer + h)


def main() -> None:
    model = init_weights(Qwen2Tiny()).eval()

    print("── 1. 파라미터 수: 손계산과 PyTorch 집계 ──")
    hand = count_by_hand()
    unique = sum(p.numel() for p in model.parameters())          # 공유 텐서 중복 제거
    naive = sum(t.numel() for t in model.state_dict().values())  # 이름마다 세면 두 번
    for k in ("embedding", "attention", "mlp", "layer", "layers", "final_norm", "total"):
        print(f"  {k:<11}{hand[k]:>12,}")
    print(f"  PyTorch 집계(공유 1회) {unique:,} / 이름별 합산 {naive:,}")
    print(f"  Embedding 비중 {hand['embedding'] / hand['total']:.1%}, "
          f"FP32 크기 {hand['total'] * 4 / 1e6:.1f}MB")
    same = model.lm_head.weight.data_ptr() == model.model.embed_tokens.weight.data_ptr()
    print(f"  lm_head와 embed_tokens가 같은 메모리: {same}")

    print("\n── 2. 차원 추적(토큰 6개) ──")
    trace = []
    with torch.no_grad():
        logits = model(torch.tensor([[9707, 11, 1879, 0, 1234, 42]]), trace=trace)
    print(f"  {'입력 ids':<11}(1, 6)")
    for name, shape in trace:
        print(f"  {name:<11}{tuple(shape)}")
    print(f"  무작위 모델의 Logits 표준편차 {logits.std().item():.3f}")


if __name__ == "__main__":
    main()
```

|---|---|
| 손계산 = PyTorch 집계 | 41,914,112개, 설계가 의도대로 구현되었다 |
| 이름별 합산 80,809,728 | `state_dict`는 공유 텐서를 두 번 센다 |
| 같은 메모리 `True` | LM Head와 Embedding이 실제로 한 텐서다 |
| Block 0~3 모두 `(1, 6, 256)` | 계층을 지나도 Shape가 변하지 않는다 |

입력 `[9707, 11, …]`은 의미 없는 임의 토큰 번호입니다. 학습 전 모델이므로 Logits는 표준편차 0.3 정도의 작은 값들로, 어느 토큰도 뚜렷하게 선호하지 않습니다.

### 실습 2. Hugging Face로 저장하고 다시 불러 비교

같은 가중치를 `Qwen2ForCausalLM`에 싣고, 표준 형식으로 저장한 뒤 다시 불러 직접 구현과 비교합니다.

파일명: `examples/ch19/hf_compat.py`

```python
# 제19장 핵심 실습: 직접 만든 Qwen2-Tiny를 저장하고 Hugging Face Qwen2ForCausalLM으로 다시 불러 비교
#
# 실행: python examples/ch19/hf_compat.py
#
# 저장 위치: 저장소 최상위 models/qwen2-tiny/ (.gitignore로 커밋 대상에서 제외)

import json
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE))
sys.path.insert(0, str(HERE.parent))

import torch  # noqa: E402
from safetensors import safe_open  # noqa: E402
from transformers import Qwen2Config, Qwen2ForCausalLM  # noqa: E402
from transformers.utils import logging  # noqa: E402

from common.qwen import load_tokenizer  # noqa: E402
from tiny_model import TINY, Qwen2Tiny, init_weights  # noqa: E402

OUT = HERE.parents[1] / "models" / "qwen2-tiny"
logging.disable_progress_bar()                              # 진행 막대 숨김
TEXT = "작은 모델도 큰 모델과 같은 길을 걷는다."


def hf_config() -> Qwen2Config:
    """TINY 설계를 Hugging Face 설정 객체로 옮긴다. 특수 토큰 번호는 Qwen2.5 토크나이저와 같게."""
    return Qwen2Config(**TINY, tie_word_embeddings=True, max_position_embeddings=2048,
                       eos_token_id=151645, pad_token_id=151643)


def to_hf(mine: Qwen2Tiny) -> Qwen2ForCausalLM:
    hf = Qwen2ForCausalLM(hf_config())
    missing, unexpected = hf.load_state_dict(mine.state_dict(), strict=True)
    assert not missing and not unexpected                  # 이름·Shape가 하나라도 다르면 여기서 멈춘다
    return hf.eval()


@torch.no_grad()
def greedy(step, ids, n=6):
    for _ in range(n):
        nxt = step(ids)[:, -1].argmax(-1, keepdim=True)
        ids = torch.cat([ids, nxt], dim=1)
    return ids[0, -n:].tolist()


def main() -> None:
    tok = load_tokenizer()
    ids = tok(TEXT, return_tensors="pt").input_ids
    mine = init_weights(Qwen2Tiny(), seed=0).eval()

    print("── 1. 같은 가중치를 Qwen2ForCausalLM에 싣기 ──")
    hf = to_hf(mine)
    print(f"  load_state_dict(strict=True) 통과, 파라미터 {hf.num_parameters():,}개")

    print("\n── 2. 저장(save_pretrained) ──")
    hf.save_pretrained(OUT)
    tok.save_pretrained(OUT)                                # 이후 장에서 함께 쓰도록 토크나이저도 저장
    with safe_open(OUT / "model.safetensors", "pt") as f:
        keys = list(f.keys())
    cfg = json.loads((OUT / "config.json").read_text())
    print(f"  model.safetensors 텐서 {len(keys)}개, lm_head 저장 여부: {'lm_head.weight' in keys}")
    print(f"  파일 크기 {(OUT / 'model.safetensors').stat().st_size / 1e6:.1f}MB, "
          f"config: hidden {cfg['hidden_size']}, 계층 {cfg['num_hidden_layers']}, "
          f"tie {cfg['tie_word_embeddings']}")

    print("\n── 3. 다시 불러 순전파 비교 ──")
    loaded = Qwen2ForCausalLM.from_pretrained(OUT, dtype=torch.float32).eval()
    with torch.no_grad():
        a = mine(ids)
        b = loaded(ids).logits
    print(f"  입력 토큰 {ids.shape[1]}개, Logits {tuple(a.shape)}")
    print(f"  최대 오차 {(a - b).abs().max().item():.1e}, "
          f"상대 오차 {((a - b).norm() / b.norm()).item():.1e}")
    print(f"  위치별 1등 토큰 일치: {torch.equal(a.argmax(-1), b.argmax(-1))}")
    same_tie = loaded.lm_head.weight.data_ptr() == loaded.model.embed_tokens.weight.data_ptr()
    print(f"  불러온 모델도 Weight Tying 유지: {same_tie}")

    print("\n── 4. Greedy 생성 6토큰 비교(학습 전이라 뜻은 없다) ──")
    g1 = greedy(mine, ids)
    g2 = greedy(lambda x: loaded(x).logits, ids)
    print(f"  직접 구현 {g1}\n  HF 모델   {g2}\n  일치: {g1 == g2}")


if __name__ == "__main__":
    main()
```

실행:

```bash
python examples/ch19/hf_compat.py
```

| 출력 | 의미 |
|---|---|
| `strict=True` 통과 | 이름 50개와 Shape가 Qwen2와 정확히 같다 |
| 텐서 50개, lm_head 없음 | 4계층 × 12개 + Embedding + Final Norm. 공유 텐서는 한 번만 저장된다 |
| 최대 오차 1e-6 수준 | 부동소수점 계산 순서 차이 정도로, 두 구현은 같은 함수다 |
| Greedy 6토큰 일치 | 오차가 다음 토큰 선택을 바꾸지 않는다 |

Greedy 생성이 같은 토큰을 계속 반복하는 것은 정상입니다. 학습 전 모델은 문맥을 활용할 줄 모르므로, 어떤 입력에도 비슷한 출력을 냅니다. 이 모델에 언어를 가르치는 일은 제25장에서 합니다.

저장된 `models/qwen2-tiny/` 폴더(약 168MB)는 `.gitignore`에 등록되어 저장소에 올라가지 않습니다. 스크립트를 다시 실행하면 같은 시드(0)로 똑같은 가중치가 다시 만들어집니다.

@pytest.fixture(scope="module")
def tiny():
    return init_weights(Qwen2Tiny(), seed=0).eval()


def test_param_count_matches_hand(tiny):
    hand = count_by_hand()
    assert hand["total"] == 41_914_112
    assert sum(p.numel() for p in tiny.parameters()) == hand["total"]
    assert hand["embedding"] / hand["total"] == pytest.approx(0.928, abs=1e-3)


def test_weight_tying_is_one_tensor(tiny):
    assert tiny.lm_head.weight is tiny.model.embed_tokens.weight
    naive = sum(t.numel() for t in tiny.state_dict().values())
    assert naive - count_by_hand()["total"] == 151_936 * 256


def test_shapes_through_model(tiny):
    trace = []
    with torch.no_grad():
        logits = tiny(torch.tensor([[1, 2, 3]]), trace=trace)
    assert [tuple(s) for _, s in trace[:-1]] == [(1, 3, 256)] * 6
    assert logits.shape == (1, 3, TINY["vocab_size"])


def test_causality(tiny):
    # 뒤 토큰을 바꿔도 앞 위치의 Logits는 그대로여야 한다
    with torch.no_grad():
        a = tiny(torch.tensor([[5, 6, 7, 8]]))
        b = tiny(torch.tensor([[5, 6, 7, 99]]))
    torch.testing.assert_close(a[:, :3], b[:, :3])


def test_hf_qwen2_gives_same_logits(tiny):
    from hf_compat import to_hf
    hf = to_hf(tiny)
    ids = torch.tensor([[9707, 11, 1879, 0, 1234, 42, 7]])
    with torch.no_grad():
        torch.testing.assert_close(tiny(ids), hf(ids).logits, atol=1e-5, rtol=1e-4)
    assert hf.num_parameters() == 41_914_112

## 핵심 정리

- Qwen2-Tiny는 구조·계층 이름은 Qwen2와 같고 크기만 줄인 실험용 모델입니다: hidden 256, 4계층, Query 4 / KV 1, FFN 768, 어휘 151,936.
- 모델은 Embedding → Decoder Layer × 4 → Final Norm → LM Head로 조립되며, Shape는 처음(Embedding)과 끝(LM Head)에서만 바뀝니다.
- Weight Tying은 LM Head와 Embedding이 한 텐서를 공유하는 것입니다. 파라미터는 한 번만 세고, 저장 파일에도 한 번만 기록됩니다.
- 파라미터는 41,914,112개이며 92.8%가 Embedding입니다. 작은 모델일수록 어휘 표의 비중이 커집니다.
- 직접 만든 가중치를 `Qwen2ForCausalLM`에 그대로 싣고 저장·재로딩해, 두 구현이 최대 오차 1e-6 수준으로 같은 Logits를 낸다는 것을 확인했습니다.

**다음 장 연결:** 제20장에서는 다시 실제 Qwen2.5-0.5B로 돌아가, Hugging Face가 모델을 불러오는 구조와 Forward Hook, Sampling 설정, KV Cache 메모리를 정리하고, Qwen2-Tiny와 실제 모델의 차이를 표로 비교하며 제2부를 마무리합니다.
