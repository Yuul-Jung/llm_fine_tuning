## 장 개요

학습이란 모델이 틀린 정도를 조금씩 줄여 가는 과정입니다. 그러려면 먼저 "얼마나 틀렸는가"를 **숫자 하나로** 잴 수 있어야 합니다. 그 숫자가 손실(Loss)입니다.

이 장은 언어 모델의 손실인 Cross Entropy를 손으로 계산하는 데서 출발해, 다음 토큰 예측에서 입력과 정답을 맞추는 방법(한 칸 이동), 학습하지 않을 위치를 빼는 방법(−100 마스킹), 그리고 사람이 읽기 쉬운 지표 Perplexity까지 다룹니다. 마지막으로 제21장의 고정 평가 데이터에서 세 모델의 Perplexity를 재어, 제3·4부 전체의 **비교 기준값**으로 저장합니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 모델이 다음 토큰을 얼마나 잘 맞히는지를 어떻게 하나의 숫자로 재는가 |
| 실습 결과물 | 손실 손계산, 한 칸 이동과 마스킹 확인, 모델 `loss`와 직접 계산 일치, 기준 PPL 파일 |
| 실습 파일 | `examples/ch22/`의 `loss_basics.py`, `qwen_ppl.py`, `test_ch22.py`, `baseline_ppl.json` |
| 선수 장 | 제06장(Softmax), 제07장(다음 토큰 예측), 제14장(Padding), 제21장(고정 데이터셋) |

```text
Logits [B, T, V] ──Softmax──▶ 확률 ──정답 토큰의 확률 p──▶ −log p ──평균──▶ 손실
                                                              │
                                               exp(평균 손실) ▼
                                                         Perplexity
```

## Cross Entropy와 NLL

모델은 위치마다 어휘 전체에 대한 점수(Logits)를 내고, Softmax(제06장)로 확률을 만듭니다. 그 확률 중 우리가 보는 것은 **정답 토큰의 확률 p** 하나뿐입니다.

```text
손실 = −log p          p = 정답 토큰에 모델이 준 확률
```

| 정답 토큰의 확률 p | 손실 −log p | 의미 |
|---|---|---|
| 1.0 | 0 | 완벽하게 맞혔다 |
| 0.5 | 0.69 | 반반 |
| 0.05 | 3.0 | 거의 기대하지 않았다 |
| 0에 가까움 | 무한대에 가까움 | 전혀 예상하지 못했다 |

확률이 높을수록 손실은 0에 가깝고, 정답을 낮게 볼수록 손실이 빠르게 커집니다. 로그를 쓰는 이유는 두 가지입니다. 확률을 곱하는 대신 더할 수 있고(여러 토큰의 손실을 합산), 아주 작은 확률도 다루기 쉬운 크기의 수로 바뀝니다.

이 값을 **NLL**(Negative Log Likelihood, 음의 로그 가능도)이라 부르고, 정답이 하나인 분류에서는 **Cross Entropy**(교차 엔트로피)와 같은 값입니다. PyTorch의 `F.cross_entropy`는 Logits를 받아 Softmax와 −log를 한 번에 계산합니다. 핵심 실습 1번에서 손계산과 맞춰 봅니다.

## 입력과 정답의 한 칸 이동

언어 모델은 위치 t의 출력으로 **t + 1번째 토큰**을 맞힙니다(제07장). 토큰열 하나로 입력과 정답을 모두 만들 수 있습니다.

```text
토큰열:     [11, 22, 33, 44, 55]
입력:       [11, 22, 33, 44]       ← 마지막 토큰은 맞힐 다음 토큰이 없다
정답:           [22, 33, 44, 55]   ← 첫 토큰은 앞 문맥이 없어 맞힐 수 없다
```

길이 T인 토큰열에서 예측할 수 있는 위치는 T − 1개입니다. 제21장의 128토큰 블록 하나에는 127개의 예측이 있습니다.

Causal Mask(제14장) 덕분에 이 127개의 예측은 **순전파 한 번으로 동시에** 계산됩니다. 위치 t의 출력은 t까지만 보았으므로, 같은 계산 안에 정답이 들어 있어도 베낄 수 없습니다. 이것이 Decoder-only 모델이 효율적으로 학습하는 비결입니다.

Hugging Face 모델에 `labels=input_ids`를 그대로 넘기면, 모델이 안에서 이 이동을 직접 합니다. 직접 계산할 때는 우리가 `logits[:, :-1]`과 `ids[:, 1:]`을 맞춰야 합니다. 이 이동을 빠뜨리면 모델이 "지금 토큰"을 맞히는 엉뚱한 손실이 계산되며, 오류는 나지 않습니다.

## Loss Masking 기초

모든 위치를 학습해야 하는 것은 아닙니다. 묶음을 맞추려 붙인 PAD(제14장)의 위치를 맞히라고 하면 모델은 쓸모없는 것을 배웁니다. 이런 위치의 정답을 **−100**으로 바꾸면 손실 계산에서 빠집니다.

```text
정답:     [22, 33, 44, PAD, PAD]
마스킹:   [22, 33, 44, -100, -100]     ← 평균을 낼 때 토큰 수도 3개로 센다
```

−100은 PyTorch `cross_entropy`의 `ignore_index` 기본값이고, Hugging Face도 같은 값을 씁니다. 중요한 것은 빠진 위치가 **합에서도, 개수에서도** 빠진다는 점입니다. 실습 3번에서 마스킹한 평균이 남은 위치만의 평균과 정확히 같은 것을 확인합니다.

이 장의 고정 데이터에는 PAD가 없으므로 마스킹하지 않습니다. 제45장에서는 같은 방법으로 "질문 부분은 빼고 답변 부분만 학습"하는 Completion-only 학습을 합니다.

## Perplexity

손실은 학습에는 편하지만 크기를 체감하기 어렵습니다. **Perplexity**(PPL, 혼란도)는 손실을 사람이 읽기 쉬운 단위로 바꾼 것입니다.

```text
PPL = exp( 전체 NLL 합 ÷ 유효 정답 토큰 수 )
```

PPL은 "모델이 매 위치에서 평균적으로 몇 개의 후보 사이에서 망설이는가"로 읽습니다. PPL이 20이면 매번 20개 후보를 고르게 놓고 고르는 정도의 불확실성입니다. 어휘 V개를 모두 똑같은 확률로 찍는 모델은 손실이 ln V, PPL이 정확히 V입니다.

평균은 **블록별 평균의 평균이 아니라, 전체 합을 전체 유효 토큰 수로** 나눕니다. 블록마다 유효 토큰 수가 다를 때(마스킹이 있을 때) 두 방법의 결과가 달라지기 때문입니다.

PPL을 비교할 때는 조건이 같아야 합니다. 다음 중 하나라도 다르면 두 PPL은 비교할 수 없습니다.

| 조건 | 이유 |
|---|---|
| 토크나이저 | 토큰을 잘게 자를수록 맞히기 쉬운 토큰이 많아진다 |
| 평가 데이터 | 문장이 쉬우면 PPL이 낮다 |
| 문맥 길이와 자르는 방식 | 앞 문맥이 길수록 맞히기 쉽다 |
| 마스킹 정책 | 어떤 위치를 세는지가 달라진다 |

이 교재의 기준은 "Qwen2.5 토크나이저, 고정 평가 데이터(지문 `1d8635627d660631`), 128토큰 블록마다 독립(겹침 없음), 마스킹 없음"입니다. 제50장의 실전 평가는 다른 데이터와 조건을 쓰므로, 이 장의 값과 직접 비교하지 않습니다.

## 기준값 저장

제3·4부에서는 학습 전후의 PPL을 비교합니다. "학습 전"이 무엇이었는지 매번 다시 재지 않도록, 이 장에서 한 번 재어 파일로 남깁니다. 기준값 파일에는 숫자만이 아니라 **그 숫자를 만든 조건**을 함께 적습니다. 데이터 지문, 모델 Revision, 문맥과 마스킹 정책, 라이브러리 버전입니다. 조건이 함께 있어야 나중에 같은 조건인지 확인할 수 있습니다.

0.5B 모델은 FP32로 약 2GB라 GT 1030의 VRAM에 들어가지 않으므로, 두 경로 모두 CPU에서 계산합니다. 작은 Qwen2-Tiny는 `select_device()`가 고른 장치에서 계산합니다.

## 핵심 실습

### 실습 1. 손실의 손계산, 한 칸 이동, 마스킹

파일명: `examples/ch22/loss_basics.py`

```python
# 제22장 실습 1: Cross Entropy를 손으로 계산하고, 한 칸 이동과 −100 마스킹을 확인한다
#
# 실행: python examples/ch22/loss_basics.py

import math

import torch
import torch.nn.functional as F

IGNORE = -100                                   # PyTorch·Hugging Face가 약속한 "계산 제외" 표시


def nll_by_hand(logits: list, target: int) -> float:
    """정답 토큰 확률의 −log. Softmax(제06장)를 직접 계산한다."""
    m = max(logits)
    exps = [math.exp(z - m) for z in logits]
    return -math.log(exps[target] / sum(exps))


def shift(ids: torch.Tensor) -> tuple:
    """위치 t의 출력이 t+1번 토큰을 맞히도록 입력과 정답을 한 칸 어긋나게 맞춘다."""
    return ids[..., :-1], ids[..., 1:]


def lm_loss(logits: torch.Tensor, labels: torch.Tensor) -> tuple:
    """logits [B, T, V], labels [B, T](같은 위치끼리 이미 정렬됨) → (NLL 합, 유효 토큰 수)"""
    nll_sum = F.cross_entropy(logits.reshape(-1, logits.shape[-1]).float(), labels.reshape(-1),
                              ignore_index=IGNORE, reduction="sum")
    return nll_sum, int((labels != IGNORE).sum())


def main() -> None:
    print("── 1. 어휘 4개의 점수 [2.0, 1.0, 3.0, 0.5]에서 정답별 손실 ──")
    logits = [2.0, 1.0, 3.0, 0.5]
    for target in (2, 0, 3):
        p = math.exp(-nll_by_hand(logits, target))
        print(f"  정답 {target}: 확률 {p:.4f} → 손실 −log p = {nll_by_hand(logits, target):.4f}")
    torch_loss = F.cross_entropy(torch.tensor([logits]), torch.tensor([2])).item()
    print(f"  PyTorch cross_entropy(정답 2) = {torch_loss:.4f}")

    print("\n── 2. 한 칸 이동 ──")
    ids = torch.tensor([[11, 22, 33, 44, 55]])
    inputs, labels = shift(ids)
    for t in range(inputs.shape[1]):
        print(f"  위치 {t}: 지금까지 {ids[0, :t + 1].tolist()} → 맞힐 정답 {labels[0, t].item()}")

    print("\n── 3. −100 마스킹 ──")
    torch.manual_seed(0)
    lg = torch.randn(1, 4, 6)
    lab = torch.tensor([[1, 4, 2, 5]])
    masked = lab.clone()
    masked[0, 2:] = IGNORE                                # 뒤 두 위치는 PAD라고 가정
    s_all, n_all = lm_loss(lg, lab)
    s_m, n_m = lm_loss(lg, masked)
    per = F.cross_entropy(lg[0], lab[0], reduction="none")
    print(f"  위치별 손실 {[round(v, 4) for v in per.tolist()]}")
    print(f"  전체 평균 {s_all.item() / n_all:.4f} (토큰 {n_all}개)")
    print(f"  마스킹 평균 {s_m.item() / n_m:.4f} (토큰 {n_m}개) = 앞 두 위치 평균 {per[:2].mean().item():.4f}")


if __name__ == "__main__":
    main()
```

실행:

```bash
python examples/ch22/loss_basics.py
```

실제 실행 결과(교재 검증 환경):

```text
── 1. 어휘 4개의 점수 [2.0, 1.0, 3.0, 0.5]에서 정답별 손실 ──
  정답 2: 확률 0.6308 → 손실 −log p = 0.4608
  정답 0: 확률 0.2321 → 손실 −log p = 1.4608
  정답 3: 확률 0.0518 → 손실 −log p = 2.9608
  PyTorch cross_entropy(정답 2) = 0.4608

── 2. 한 칸 이동 ──
  위치 0: 지금까지 [11] → 맞힐 정답 22
  위치 1: 지금까지 [11, 22] → 맞힐 정답 33
  위치 2: 지금까지 [11, 22, 33] → 맞힐 정답 44
  위치 3: 지금까지 [11, 22, 33, 44] → 맞힐 정답 55

── 3. −100 마스킹 ──
  위치별 손실 [3.0088, 0.7358, 2.5771, 4.7608]
  전체 평균 2.7706 (토큰 4개)
  마스킹 평균 1.8723 (토큰 2개) = 앞 두 위치 평균 1.8723
```

- 1번에서 점수가 가장 높은 토큰 2가 정답이면 확률 0.63, 손실 0.46입니다. 정답이 점수가 낮은 토큰 3이면 확률 0.05, 손실 2.96으로 커집니다. 손계산이 PyTorch와 같습니다.
- 2번은 한 칸 이동입니다. 토큰 5개에서 예측은 4번이며, 위치마다 그때까지의 토큰만 보고 바로 다음 토큰을 맞힙니다.
- 3번에서 뒤 두 위치를 −100으로 바꾸면 평균은 앞 두 위치(3.0088, 0.7358)의 평균 1.8723이 됩니다. 빠진 위치는 합과 개수 모두에서 빠졌습니다.
- `lm_loss()`는 평균 대신 **합과 개수**를 돌려줍니다. 여러 블록을 모아 PPL을 낼 때 전체 합 ÷ 전체 개수로 계산하기 위해서입니다.

### 실습 2. 모델 loss 확인과 기준 PPL 저장

세 모델로 고정 평가 데이터를 평가합니다. 무작위로 초기화한 Qwen2-Tiny(제19장), 사전학습만 한 Base, 사후 학습까지 한 Instruct(제21장)입니다.

파일명: `examples/ch22/qwen_ppl.py`

```python
# 제22장 핵심 실습: 직접 계산한 손실과 모델의 loss 출력을 맞추고, 고정 평가 데이터의 기준 PPL을 저장한다
#
# 실행: python examples/ch22/qwen_ppl.py
#
# 0.5B 모델(FP32 약 2GB)은 GT 1030의 VRAM에 들어가지 않으므로 두 경로 모두 CPU에서 계산한다.
# 작은 Qwen2-Tiny는 select_device()가 고른 장치에서 계산한다.

import json
import math
import platform
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
for p in (HERE, HERE.parent, HERE.parent / "ch19", HERE.parent / "ch21"):
    sys.path.insert(0, str(p))

import torch  # noqa: E402
import transformers  # noqa: E402

from base_vs_instruct import BASE_REVISION, load_base  # noqa: E402  (제21장)
from common.device import select_device  # noqa: E402
from common.fixed_data import SEQ_LEN, fingerprint, load_blocks  # noqa: E402
from common.models import QWEN_REVISION  # noqa: E402
from common.qwen import load_model, load_tokenizer  # noqa: E402
from hf_compat import to_hf  # noqa: E402               (제19장)
from loss_basics import lm_loss, shift  # noqa: E402
from tiny_model import Qwen2Tiny, init_weights  # noqa: E402

OUT = HERE / "baseline_ppl.json"


@torch.no_grad()
def evaluate(model, blocks: torch.Tensor, device: str = "cpu") -> dict:
    """블록마다 독립된 문맥(겹침 없음)으로 NLL을 모아 PPL을 계산한다."""
    model = model.to(device)
    total, count, hf_losses = 0.0, 0, []
    for block in blocks.split(1):                    # 블록 하나씩(메모리 절약)
        block = block.to(device)
        out = model(input_ids=block, labels=block)   # 모델 안에서 한 칸 이동
        inputs, labels = shift(block)
        s, n = lm_loss(out.logits[:, :-1], labels)   # 직접 계산
        total, count = total + s.item(), count + n
        hf_losses.append((out.loss.item(), s.item() / n))
    return {"nll_sum": total, "tokens": count, "loss": total / count,
            "ppl": math.exp(total / count), "hf_vs_mine": hf_losses}


def main() -> None:
    tok = load_tokenizer()
    blocks = load_blocks(tok, "eval")
    print(f"평가 데이터: 블록 {tuple(blocks.shape)}, 지문 {fingerprint(blocks)}, "
          f"예측 위치 {blocks.shape[0]} × {SEQ_LEN - 1} = {blocks.shape[0] * (SEQ_LEN - 1)}개\n")

    device, _ = select_device()
    runs = [("Qwen2-Tiny(무작위)", lambda: to_hf(init_weights(Qwen2Tiny(), seed=0)), device),
            ("Qwen2.5-0.5B Base", load_base, "cpu"),
            ("Qwen2.5-0.5B-Instruct", load_model, "cpu")]
    results = {}
    print("── 1. 모델 loss 출력 vs 직접 계산(블록 0) ──")
    for name, loader, dev in runs:
        r = evaluate(loader(), blocks, dev)
        hf, mine = r["hf_vs_mine"][0]
        print(f"  {name:<22}model.loss {hf:.6f} / 직접 {mine:.6f}  ({dev})")
        results[name] = r

    print("\n── 2. 고정 평가 데이터의 Perplexity ──")
    print(f"  {'모델':<22}{'평균 NLL':>9}{'PPL':>12}")
    for name, r in results.items():
        print(f"  {name:<22}{r['loss']:>9.4f}{r['ppl']:>12,.2f}")
    print(f"  참고: 어휘 151,936개를 고르게 찍으면 NLL = ln 151936 = {math.log(151936):.4f}")

    record = {
        "data": {"split": "eval", "shape": list(blocks.shape), "fingerprint": fingerprint(blocks),

        "models": {"Qwen2.5-0.5B Base": BASE_REVISION, "Qwen2.5-0.5B-Instruct": QWEN_REVISION,
                   "Qwen2-Tiny(무작위)": "seed 0, 제19장 init_weights"},
        "results": {n: {"tokens": r["tokens"], "loss": round(r["loss"], 4), "ppl": round(r["ppl"], 2)}
                    for n, r in results.items()},

    OUT.write_text(json.dumps(record, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    print(f"\n── 3. 기준값 저장: examples/ch22/{OUT.name} ──")

    main()
```

```python
def test_nll_by_hand_matches_pytorch():
    logits = [2.0, 1.0, 3.0, 0.5]
    for t in range(4):
        expect = F.cross_entropy(torch.tensor([logits]), torch.tensor([t])).item()
        assert nll_by_hand(logits, t) == pytest.approx(expect, abs=1e-6)


def test_shift_aligns_next_token():
    inputs, labels = shift(torch.tensor([[1, 2, 3, 4]]))
    assert inputs.tolist() == [[1, 2, 3]] and labels.tolist() == [[2, 3, 4]]


def test_ignore_index_excludes_positions():
    torch.manual_seed(1)
    lg, lab = torch.randn(2, 5, 7), torch.randint(0, 7, (2, 5))
    masked = lab.clone()
    masked[:, 3:] = IGNORE
    s, n = lm_loss(lg, masked)
    assert n == 6
    expect = F.cross_entropy(lg[:, :3].reshape(-1, 7), lab[:, :3].reshape(-1))
    assert s.item() / n == pytest.approx(expect.item(), abs=1e-5)


def test_uniform_model_ppl_equals_vocab():
```

## 핵심 정리

- 언어 모델의 손실은 정답 토큰 확률의 −log(NLL)이며, PyTorch의 `cross_entropy`가 Softmax와 −log를 한 번에 계산합니다.
- 위치 t의 출력은 t + 1번째 토큰을 맞힙니다. 길이 T의 토큰열에는 T − 1개의 예측이 있고, Causal Mask 덕분에 한 번에 계산됩니다.
- 학습하지 않을 위치는 정답을 −100으로 바꿔 합과 개수 모두에서 뺍니다.
- PPL = exp(전체 NLL 합 ÷ 유효 토큰 수)이며, 토크나이저·데이터·문맥·마스킹이 같을 때만 비교합니다.
- 고정 평가 데이터의 기준 PPL은 Base 18.13, Instruct 21.45, 무작위 Qwen2-Tiny 약 16만(≈ 어휘 크기)입니다.
