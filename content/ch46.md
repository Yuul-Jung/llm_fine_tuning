## 장 개요

제45장에서 학습 샘플 하나를 만들었습니다. 이제 이 샘플들로 모델을 실제로 학습합니다. 제25장의 학습 루프는 길이가 모두 같은 블록에서 무작위로 뽑았지만, SFT 샘플은 길이가 제각각이고 질문 부분이 가려져 있습니다. 그래서 묶음을 만드는 방법, 검증 손실을 계산하는 방법, 학습을 중단했다가 이어 가는 방법이 달라집니다.

이 장은 TRL 같은 라이브러리를 쓰지 않고 **SFT 루프를 직접 구현**합니다. 제47장에서 같은 일을 SFTTrainer로 하므로, 라이브러리의 설정 하나하나가 이 장의 어느 코드에 해당하는지 대응시킬 수 있게 됩니다. 모델은 제25장에서 사전학습한 작은 Qwen2-Tiny를 써서 CPU에서 몇 분 안에 끝냅니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 길이가 다른 SFT 샘플로 어떻게 학습하고 검증하며, 중단한 학습을 어떻게 정확히 이어 가는가 |
| 실습 결과물 | Dataset·Collator·DataLoader, 30단계 학습 기록(log.jsonl), Checkpoint 재개와 연속 학습의 일치 확인 |
| 실습 파일 | `examples/ch46/`의 `sft_loop.py`, `test_ch46.py`, `log.jsonl` |
| 선수 장 | 제25장(학습 루프, Qwen2-Tiny), 제43장(분할), 제45장(Label Masking) |

```text
split_v1(train 38) ─build_example─▶ SFTDataset ─RandomSampler(seed, epoch)─▶ 샘플 4개
   ─Collator(오른쪽 PAD)─▶ 묶음 ─Forward·Loss·Backward ×2(누적)─▶ Clipping → Step → Scheduler
   5단계마다: Validation(같은 Label 정책, 토큰 가중) → log.jsonl    15단계: Checkpoint 저장
```

## 데이터를 묶는 세 부품

PyTorch는 데이터를 세 부품으로 나눕니다.

| 부품 | 하는 일 | 이 장의 구현 |
|---|---|---|
| Dataset | 번호로 샘플 하나를 돌려준다 | `SFTDataset`: 제45장의 세 배열을 미리 만들어 둠 |
| Sampler | 어떤 순서로 번호를 뽑을지 정한다 | `RandomSampler`: seed와 에폭으로 정한 순서 |
| Collator | 샘플 여러 개를 하나의 묶음 텐서로 만든다 | `Collator`: 가장 긴 샘플에 맞춰 오른쪽 PAD |

DataLoader는 이 셋을 이어, 반복할 때마다 묶음 하나를 내놓습니다. 샘플 길이가 다르므로 묶음마다 길이도 다르며, Collator는 그 묶음에서 가장 긴 샘플에 맞춰 PAD를 채웁니다. 전체 데이터의 최대 길이에 맞추는 것보다 PAD가 적어 계산이 줄어듭니다.

Sampler의 순서는 **seed와 에폭 번호로 정합니다.** 에폭마다 순서가 달라야 모델이 순서를 외우지 않고, 같은 seed와 에폭이면 언제나 같은 순서여야 중단한 지점에서 정확히 이어 갈 수 있습니다.

## 학습 단계

한 단계는 제25장과 같은 순서입니다. 묶음 2개에 대해 Forward와 Backward를 하며 Gradient를 쌓고(Gradient Accumulation), Gradient 노름을 1.0으로 자른 뒤(Clipping), Optimizer와 Scheduler를 한 칸씩 진행합니다. 묶음 4 × 누적 2이므로 한 단계에 8개 샘플을 봅니다.

| 단계 | 하는 일 | 제25장과 다른 점 |
|---|---|---|
| Forward | 세 배열을 넣어 Loss를 얻는다 | 마스크와 가린 정답을 함께 넣는다 |
| Backward | Loss를 누적 횟수로 나눠 역전파 | 같음 |
| Clipping | Gradient 노름을 1.0으로 자른다 | NaN·Inf면 즉시 멈춤 |
| Step | AdamW, Warmup 후 Cosine | 같음 |

Loss는 모델이 labels가 -100이 아닌 자리만 평균한 값입니다. 묶음마다 학습 대상 토큰 수가 다르므로, 엄밀히는 묶음 평균을 다시 평균하면 토큰이 적은 묶음의 비중이 커집니다. 묶음이 작고 길이 차이가 크지 않은 이 교재에서는 이 차이를 받아들이고, 검증에서만 정확히 계산합니다.

## Validation 루프

검증은 학습과 **같은 Label 정책**으로 해야 합니다. 학습은 답 부분만 채점하는데 검증이 질문까지 채점하면, 두 손실은 다른 것을 재므로 비교할 수 없습니다. 그래서 검증 샘플도 제45장의 `build_example`로 만듭니다.

검증 손실은 **토큰 수로 가중 평균**합니다. 샘플마다 평균 Loss에 학습 대상 토큰 수를 곱해 더하고 전체 토큰 수로 나눕니다. 샘플 평균을 그대로 평균하면 답이 짧은 샘플의 몇 토큰이 긴 샘플의 수십 토큰과 같은 무게를 갖습니다. 이 값의 지수가 제43장 기준 파일의 도메인 PPL입니다. 검증하는 동안은 평가 모드로 바꾸고, 끝나면 학습 모드로 되돌립니다.

## 로그와 Checkpoint

학습 기록은 정해진 단계마다 한 줄씩 `log.jsonl`에 남깁니다. 단계, 에폭, 학습률, 학습 손실, Gradient 노름, 검증 손실과 PPL이 한 줄에 들어가므로, 학습이 끝난 뒤 곡선을 그리거나 다른 실험과 비교할 수 있습니다.

**Checkpoint**는 학습을 그 자리에서 이어 가는 데 필요한 모든 상태입니다.

| 저장 항목 | 빠지면 생기는 일 |
|---|---|
| 모델 가중치 | 처음부터 다시 학습 |
| Optimizer 상태(AdamW의 1·2차 모멘트) | 모멘트가 0에서 다시 시작해 처음 몇 단계가 크게 흔들린다 |
| Scheduler 상태 | 학습률이 Warmup부터 다시 시작한다 |
| 단계 수와 사용한 묶음 수 | 데이터 순서가 처음부터 다시 시작한다 |

저장 도중 프로그램이 멈추면 반쯤 쓴 Checkpoint가 남을 수 있습니다. 그래서 임시 폴더에 다 쓴 뒤 이름을 바꿔, 언제나 온전한 Checkpoint 하나가 남게 합니다. 재개할 때는 가중치를 불러오고, Optimizer와 Scheduler 상태를 되돌리고, 이번 에폭에서 이미 쓴 묶음 수만큼 Sampler를 건너뜁니다. 이 셋이 맞으면 재개한 학습은 멈추지 않고 이어 간 학습과 **소수점까지 같은 손실**을 냅니다.

## 핵심 실습

파일명: `examples/ch46/sft_loop.py`

```python
# 제46장 핵심 실습: Dataset·Collator·학습 단계·Validation·Checkpoint를 갖춘 SFT 루프를 직접 구현한다
#
# 실행: python examples/ch46/sft_loop.py   (제25장의 models/qwen2-tiny-pretrained 필요, CPU 약 5분)
#
# 만드는 파일: models/ch46_sft/(Checkpoint), examples/ch46/log.jsonl(학습 기록)

import json
import math
import random
import shutil
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
ROOT = HERE.parents[1]
for p in (HERE.parent, HERE.parent / "ch24", HERE.parent / "ch41", HERE.parent / "ch44", HERE.parent / "ch45"):
    sys.path.insert(0, str(p))

import torch  # noqa: E402
from torch.utils.data import DataLoader, Dataset, RandomSampler  # noqa: E402

from check_dataset import load  # noqa: E402                 (제41장)
from label_mask import IGNORE, build_example, pad_batch  # noqa: E402   (제45장)
from optim_memory import warmup_cosine  # noqa: E402          (제24장)

TINY = ROOT / "models" / "qwen2-tiny-pretrained"
CKPT = ROOT / "models" / "ch46_sft"
LOG = HERE / "log.jsonl"


def split_rows(name: str) -> list:
    split = json.loads((ROOT / "datasets/fpga_qa/split_v1.json").read_text(encoding="utf-8"))["split"]
    return [r for r in load() if split[r["id"]] == name]


class SFTDataset(Dataset):
    """샘플마다 제45장의 input_ids·attention_mask·labels를 미리 만들어 둔다"""

    def __init__(self, tok, rows: list, max_len: int = 256):
        self.items = [build_example(tok, r, max_len) for r in rows]

    def __len__(self):
        return len(self.items)

    def __getitem__(self, i):
        return self.items[i]


class Collator:
    """길이가 다른 샘플을 가장 긴 샘플에 맞춰 오른쪽 PAD로 묶는다"""

    def __init__(self, pad_id: int):
        self.pad_id = pad_id

    def __call__(self, examples: list) -> dict:
        return pad_batch(examples, self.pad_id)


def loader(ds, batch: int, seed: int, epoch: int) -> DataLoader:
    g = torch.Generator().manual_seed(seed * 1000 + epoch)      # 에폭마다 다르지만 재현되는 순서
    return DataLoader(ds, batch_size=batch, sampler=RandomSampler(ds, generator=g),
                      collate_fn=Collator(ds.pad_id), drop_last=True)


@torch.no_grad()
def validate(model, ds) -> dict:
    """학습과 같은 Label 정책. 토큰 수로 가중 평균해야 샘플 길이에 따라 치우치지 않는다."""
    was = model.training
    model.eval()
    total, n = 0.0, 0
    for e in ds.items:
        ids, lab = torch.tensor([e["input_ids"]]), torch.tensor([e["labels"]])
        k = int((lab[0, 1:] != IGNORE).sum())
        total += model(input_ids=ids, labels=lab).loss.item() * k
        n += k
    model.train(was)
    return {"val_loss": total / n, "val_ppl": math.exp(total / n), "val_tokens": n}


def save_checkpoint(path: Path, model, opt, sched, state: dict) -> None:
    tmp = path.with_name(path.name + ".tmp")
    shutil.rmtree(tmp, ignore_errors=True)
    tmp.mkdir(parents=True)
    model.save_pretrained(tmp)
    torch.save({"optimizer": opt.state_dict(), "scheduler": sched.state_dict(), **state}, tmp / "trainer_state.pt")
    shutil.rmtree(path, ignore_errors=True)
    tmp.rename(path)                     # 저장 도중 멈춰도 이전 Checkpoint가 남도록 다 쓴 뒤에 바꾼다


def train_sft(model, train_ds, val_ds, *, steps: int, batch: int = 4, accum: int = 2, lr: float = 1e-3,
              warmup: int = 6, clip: float = 1.0, seed: int = 0, log_every: int = 5,
              ckpt: Path = None, save_at: tuple = (), resume: bool = False, stop_at: int = None,
              log_path: Path = None) -> list:
    torch.manual_seed(seed)
    random.seed(seed)
    model.train()
    params = [p for p in model.parameters() if p.requires_grad]
    opt = torch.optim.AdamW(params, lr=lr, weight_decay=0.1)
    sched = torch.optim.lr_scheduler.LambdaLR(opt, lambda s: warmup_cosine(s, warmup, steps))
    step, consumed = 0, 0                                         # consumed: 지금까지 쓴 묶음 수
    if resume:
        st = torch.load(ckpt / "trainer_state.pt", weights_only=False)
        opt.load_state_dict(st["optimizer"])
        sched.load_state_dict(st["scheduler"])
        step, consumed = st["step"], st["consumed"]
    per_epoch = len(train_ds) // batch
    history = []
    log = open(log_path, "a", encoding="utf-8") if log_path else None
    batches = None
    while step < (stop_at or steps):
        total, tokens = 0.0, 0
        for _ in range(accum):
            epoch, pos = divmod(consumed, per_epoch)
            if batches is None or pos == 0:
                batches = iter(loader(train_ds, batch, seed, epoch))
                for _ in range(pos):                              # 재개: 이번 에폭에서 쓴 묶음 건너뛰기
                    next(batches)
            b = next(batches)
            consumed += 1
            out = model(input_ids=b["input_ids"], attention_mask=b["attention_mask"], labels=b["labels"])
            (out.loss / accum).backward()
            total += out.loss.item() / accum
            tokens += int((b["labels"][:, 1:] != IGNORE).sum())
        grad_norm = torch.nn.utils.clip_grad_norm_(params, clip).item()
        if not math.isfinite(grad_norm):
            raise RuntimeError(f"{step + 1}단계에서 Gradient가 NaN·Inf")
        opt.step()
        sched.step()
        opt.zero_grad(set_to_none=True)
        step += 1
        if step % log_every == 0 or step == steps:
            row = {"step": step, "epoch": round(consumed / per_epoch, 2), "lr": opt.param_groups[0]["lr"],
                   "train_loss": total, "grad_norm": grad_norm, "tokens": tokens, **validate(model, val_ds)}
            history.append(row)
            if log:
                log.write(json.dumps(row) + "\n")
        if ckpt and step in save_at:
            save_checkpoint(ckpt, model, opt, sched, {"step": step, "consumed": consumed, "seed": seed})
    if log:
        log.close()
    return history


def setup(model_dir: Path = TINY):
    """토크나이저는 언제나 원래 모델 폴더에서(Checkpoint에는 가중치와 학습 상태만 저장)"""
    from transformers import AutoModelForCausalLM, AutoTokenizer
    tok = AutoTokenizer.from_pretrained(TINY)
    torch.manual_seed(0)
    model = AutoModelForCausalLM.from_pretrained(model_dir, dtype=torch.float32)
    tr, va = SFTDataset(tok, split_rows("train")), SFTDataset(tok, split_rows("validation"))
    tr.pad_id = va.pad_id = tok.pad_token_id
    return tok, model, tr, va


def main() -> None:
    STEPS = 30
    tok, model, tr, va = setup()
    print("── 1. Dataset · DataLoader · Collator ──")
    b = next(iter(loader(tr, 4, 0, 0)))
    print(f"  train {len(tr)}개, validation {len(va)}개, 묶음 4 × 누적 2 = 단계당 8샘플, 에폭당 {len(tr) // 4}묶음")
    print(f"  첫 묶음 모양 {tuple(b['input_ids'].shape)}, PAD {int((b['attention_mask'] == 0).sum())}자리, "
          f"학습 대상 {int((b['labels'] != IGNORE).sum())}토큰")

    print(f"\n── 2·3. 학습 {STEPS}단계(Qwen2-Tiny, lr 1e-3, Warmup 6 + Cosine), 5단계마다 Validation ──")
    v0 = validate(model, va)
    print(f"  시작 전 val loss {v0['val_loss']:.3f}, val PPL {v0['val_ppl']:.1f}(학습 대상 {v0['val_tokens']}토큰)")
    LOG.unlink(missing_ok=True)
    full = train_sft(model, tr, va, steps=STEPS, ckpt=CKPT, save_at=(15,), log_path=LOG)
    print("  단계  에폭   lr        train   val     val PPL  grad")
    for h in full:
        print(f"  {h['step']:>4}  {h['epoch']:>4}  {h['lr']:.2e}  {h['train_loss']:.3f}  {h['val_loss']:.3f}"
              f"  {h['val_ppl']:>7.1f}  {h['grad_norm']:.2f}")

    print("\n── 4. Checkpoint 재개: 15단계 Checkpoint에서 다시 불러와 30단계까지 ──")
    _, model2, _, _ = setup(CKPT)
    resumed = train_sft(model2, tr, va, steps=STEPS, ckpt=CKPT, resume=True)
    for a, r in zip([h for h in full if h["step"] > 15], resumed):
        print(f"  {a['step']:>4}단계 train 연속 {a['train_loss']:.6f} / 재개 {r['train_loss']:.6f}   "
              f"val 연속 {a['val_loss']:.6f} / 재개 {r['val_loss']:.6f}")
    same = all(abs(a["train_loss"] - r["train_loss"]) < 1e-5 for a, r in zip(full[3:], resumed))
    print(f"  재개 결과가 연속 학습과 일치: {same}")
    _, model3, _, _ = setup(CKPT)
    weights_only = train_sft(model3, tr, va, steps=STEPS - 15, warmup=6)
    print("  비교: 가중치만 불러오고 Optimizer·Scheduler를 새로 시작하면(같은 15단계 더)")
    for a, w in zip([h for h in full if h["step"] > 15], weights_only):
        print(f"  {a['step']:>4}단계 train 연속 {a['train_loss']:.3f} / 가중치만 {w['train_loss']:.3f}   "
              f"val 연속 {a['val_loss']:.3f} / 가중치만 {w['val_loss']:.3f}   lr 연속 {a['lr']:.1e} / 가중치만 {w['lr']:.1e}")
    print(f"  기록 파일 {LOG.relative_to(ROOT)}: {len(LOG.read_text().splitlines())}줄")


if __name__ == "__main__":
    main()
```

## 검증과 완료 기준

파일명: `examples/ch46/test_ch46.py`

```python
# 제46장 검증 테스트
#
# 실행: python -m pytest examples/ch46 -q

import json
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE))

import pytest  # noqa: E402
import torch  # noqa: E402

from sft_loop import IGNORE, LOG, TINY, loader, setup, train_sft, validate  # noqa: E402

pytestmark = pytest.mark.skipif(not TINY.exists(), reason="제25장의 Qwen2-Tiny가 필요")


@pytest.fixture(scope="module")
def parts():
    return setup()


def test_collator_pads_and_masks(parts):
    _, _, tr, _ = parts
    b = next(iter(loader(tr, 4, 0, 0)))
    pad = b["attention_mask"] == 0
    assert b["input_ids"].shape == b["labels"].shape and (b["labels"][pad] == IGNORE).all()
    assert [x.tolist() for x in next(iter(loader(tr, 4, 0, 0)))["input_ids"]] == b["input_ids"].tolist()


def test_validation_is_token_weighted(parts):
    _, model, _, va = parts
    v = validate(model, va)
    assert v["val_tokens"] == sum(sum(t != IGNORE for t in e["labels"][1:]) for e in va.items)
    assert abs(v["val_ppl"] - torch.tensor(v["val_loss"]).exp().item()) < 1e-6 * v["val_ppl"]


def test_resume_continues_exactly(tmp_path):
    _, m1, tr, va = setup()
    full = train_sft(m1, tr, va, steps=4, log_every=1, ckpt=tmp_path / "c", save_at=(2,))
    _, m2, _, _ = setup(tmp_path / "c")
    resumed = train_sft(m2, tr, va, steps=4, log_every=1, ckpt=tmp_path / "c", resume=True)
    assert [round(h["train_loss"], 5) for h in full[2:]] == [round(h["train_loss"], 5) for h in resumed]
    assert full[-1]["train_loss"] < full[0]["train_loss"]


def test_recorded_log_decreases():
    rows = [json.loads(x) for x in LOG.read_text().splitlines()]
    assert [r["step"] for r in rows] == [5, 10, 15, 20, 25, 30]
    assert rows[-1]["val_loss"] < rows[0]["val_loss"] and rows[-1]["train_loss"] < rows[0]["train_loss"]
```

이 장의 실습은 CPU에서 실행합니다. Qwen2-Tiny는 작아서 GT 1030에서도 같은 코드가 동작하지만, CPU와 GPU는 연산 순서가 달라 손실의 소수점 아래 값이 조금 다를 수 있습니다. 재개 일치는 같은 장치 안에서 확인합니다.

## 핵심 정리

- Dataset은 샘플을, Sampler는 순서를, Collator는 묶음을 맡습니다. Collator는 묶음 안의 가장 긴 샘플에 맞춰 PAD를 채웁니다.
- 학습 단계는 Forward·Backward(누적)·Clipping·Step·Scheduler이며, SFT에서는 attention_mask와 가린 labels를 함께 넣습니다.
- 검증은 학습과 같은 Label 정책으로, 학습 대상 토큰 수로 가중 평균해 계산합니다.
- Checkpoint는 가중치, Optimizer, Scheduler, 단계와 데이터 위치를 모두 담아야 하며, 그래야 재개한 학습이 연속 학습과 같아집니다.
- 학습 기록은 한 줄에 한 단계씩 JSONL로 남겨, 나중에 곡선을 그리고 실험끼리 비교합니다.
