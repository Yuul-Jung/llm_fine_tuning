## 장 개요

제08장에서 Qwen2.5의 토크나이저는 `" model"`이나 `"한다"`를 토큰 하나로, "토큰"이라는 단어는 바이트 조각 다섯 개로 잘랐습니다. 무엇을 한 토큰으로 묶고 무엇을 쪼갤지는 누가 정했을까요? 답은 사람이 아니라 **데이터**입니다.

BPE(Byte Pair Encoding, 바이트 쌍 인코딩)는 "가장 자주 붙어 나오는 두 조각을 하나로 합친다"는 규칙 하나를 반복해 어휘를 만듭니다. 이 장에서는 BPE를 직접 구현해 병합이 한 번씩 일어날 때마다 어휘와 토큰열이 어떻게 바뀌는지 추적합니다. 그리고 실제 Qwen2.5의 어휘가 바로 이 방식으로 만들어졌음을 숫자로 확인합니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 서브워드 어휘는 어떻게 만들어지며, 새 문장은 어떻게 토큰으로 나뉘는가 |
| 실습 결과물 | 병합 과정 추적표, 병합 횟수별 토큰 수, Qwen 병합 규칙 확인 |
| 실습 파일 | `examples/ch09/`의 `bpe.py`, `qwen_merges.py`, `test_ch09.py` |
| 선수 장 | 제07장(학습 문장 `corpus.txt`), 제08장(서브워드·토크나이저) |

```text
[학습] 글자 단위로 시작 → 가장 잦은 쌍 찾기 → 합치기 → 반복 → 병합 규칙 목록
   ↓
[적용] 새 문장을 글자로 나눔 → 병합 규칙을 학습 순서대로 적용 → 토큰열
   ↓
[확장] 글자 대신 바이트에서 시작 → 어떤 문자도 표현 가능(Byte-level BPE)
   ↓
[확인] Qwen 어휘 151,643 = 바이트 256 + 병합 규칙 151,387
```

## BPE의 아이디어

BPE는 원래 데이터 압축 기법이었습니다. 자주 나오는 바이트 쌍을 새 기호 하나로 바꾸면 데이터가 짧아집니다. 토크나이저는 이 아이디어를 그대로 빌려, **자주 함께 나오는 글자 묶음을 한 토큰으로** 만듭니다.

```text
시작: 모든 단어를 글자로 쪼갠다        ▁ 모 델 은
병합 1: 가장 잦은 쌍 (▁, 모) 합치기     ▁모 델 은
병합 2: 가장 잦은 쌍 (▁모, 델) 합치기   ▁모델 은
병합 3: 가장 잦은 쌍 (▁모델, 은) 합치기 ▁모델은
```

| 개념 | 뜻 |
|---|---|
| 기본 어휘 | 학습 데이터에 나온 모든 글자(또는 바이트) |
| 병합 규칙(Merge Rule) | "이 두 조각을 합쳐라"라는 규칙과 그 순서 |
| 어휘 집합 | 기본 어휘 + 병합으로 생긴 새 토큰 |
| 병합 횟수 | 사람이 정하는 값. 많을수록 어휘가 크고 토큰열이 짧다 |

`▁` 표시는 단어의 시작, 즉 앞에 공백이 있던 자리를 뜻합니다. 공백 정보를 토큰에 담아 두어야 디코딩할 때 띄어쓰기를 정확히 복원할 수 있습니다. 제08장에서 Qwen의 토큰이 `" model"`처럼 앞 공백을 품고 있던 것과 같은 원리입니다.

## 쌍 빈도 계산과 병합

병합 한 번은 두 단계입니다.

```text
① 쌍 빈도 세기
   모든 단어 안에서 이웃한 두 조각을 짝지어 센다. 같은 단어가 여러 번 나오면 그 횟수만큼 더한다.
   예) "아아아" → (▁, 아) 1회, (아, 아) 2회

② 가장 잦은 쌍 합치기
   빈도가 가장 높은 쌍을 찾아, 모든 단어에서 그 쌍을 하나의 조각으로 바꾼다.
   왼쪽부터 겹치지 않게 합친다. 예) (아, 아, 아)에서 (아, 아) 합치기 → (아아, 아)
```

합치고 나면 단어의 모양이 바뀌므로 쌍 빈도를 다시 셉니다. 방금 생긴 `▁모`가 다음 병합에서 `델`과 짝을 이룰 수 있게 됩니다. 이렇게 짧은 조각이 점점 긴 조각으로 자라납니다.

빈도가 같은 쌍이 여럿이면 어느 것을 먼저 합칠지 규칙이 필요합니다. 이 교재의 구현은 먼저 등장한 쌍을 고릅니다. 실제 토크나이저 라이브러리는 각자 정한 규칙을 쓰므로, 같은 데이터로 학습해도 동점 처리 방식에 따라 병합 순서가 조금 다를 수 있습니다.

## 병합 규칙과 인코딩

학습이 끝나면 남는 것은 **순서가 매겨진 병합 규칙 목록**입니다. 새 문장을 토큰화할 때는 문장을 글자로 쪼갠 뒤, 이 규칙을 **학습한 순서대로** 하나씩 적용합니다.

```text
새 문장 "모델은"
  글자로 쪼개기:      ▁ 모 델 은
  규칙 2 (▁, 모):     ▁모 델 은
  규칙 4 (▁모, 델):   ▁모델 은
  규칙 5 (▁모델, 은): ▁모델은         → 토큰 1개
```

순서가 중요한 이유는 앞의 병합이 뒤의 병합 재료를 만들기 때문입니다. `▁모`가 먼저 만들어져야 `▁모델`을 만들 수 있습니다. 같은 규칙을 같은 순서로 적용하므로 같은 문장은 언제나 같은 토큰열이 됩니다.

### 처음 보는 단어

학습 데이터에 없던 단어도 아는 조각까지는 합쳐집니다. "모델링"은 `▁모델`까지 합쳐지고 `링`이 남습니다. 문제는 `링`이라는 **글자 자체**를 학습 데이터에서 본 적이 없다는 점입니다. 글자에서 출발하는 BPE는 기본 어휘에 없는 글자를 표현할 방법이 없습니다. 한글만 1만 자가 넘고, 한자·기호·이모지까지 생각하면 모든 글자를 기본 어휘에 넣는 것은 불가능합니다.

## Byte-level BPE

해법은 출발점을 글자에서 **바이트**로 바꾸는 것입니다. 컴퓨터는 모든 글자를 UTF-8이라는 규칙으로 1~4바이트에 담습니다. 바이트의 종류는 0부터 255까지 256가지뿐이므로, 256개의 바이트를 기본 어휘로 삼으면 **세상의 어떤 글자도** 표현할 수 있습니다.

| 글자 | UTF-8 바이트 수 | 바이트 값 |
|---|---|---|
| `A` | 1 | 65 |
| `토` | 3 | 237, 134, 160 |
| `🙂` | 4 | 240, 159, 153, 130 |

| 구분 | 글자 단위 BPE(이 장의 구현) | Byte-level BPE(Qwen2.5) |
|---|---|---|
| 기본 어휘 | 학습 데이터에 나온 글자 | 바이트 256개 |
| 처음 보는 글자 | 표현 불가 | 바이트로 쪼개 항상 표현 가능 |
| 어휘 크기 | 기본 글자 수 + 병합 수 | 256 + 병합 수 |

제08장에서 "토큰"이 깨진 글자 조각 다섯 개로 나뉜 이유가 이것입니다. Qwen의 학습 데이터에서 "토큰"의 바이트 조합은 통째로 병합될 만큼 자주 나오지 않았고, 그래서 일부 바이트 단위 토큰으로 남았습니다. 각 조각은 글자의 일부 바이트라 혼자서는 깨져 보이지만, 함께 디코딩하면 원래 글자로 정확히 돌아옵니다.

Byte-level BPE의 어휘 크기는 "256 + 병합 규칙 수"입니다. 실습 2에서 Qwen의 실제 병합 규칙 파일로 이 식을 확인합니다.

## 핵심 실습

### 실습 1. 교육용 BPE 학습과 인코딩

제07장의 학습 문장 10개(`examples/ch07/corpus.txt`)로 병합 규칙 60개를 학습하고, 병합이 늘수록 토큰열이 어떻게 짧아지는지 확인합니다.

파일명: `examples/ch09/bpe.py`

```python
# 제09장 핵심 실습: 교육용 BPE 토크나이저 직접 구현
#
# 실행: python examples/ch09/bpe.py
#
# BPE(Byte Pair Encoding): 가장 자주 붙어 나오는 두 토큰을 하나로 합치는 일을 반복해 어휘를 만든다.
# 단어 앞에 '▁'를 붙여 공백 위치를 기억한다(디코딩 때 공백으로 되돌림).

from collections import Counter
from pathlib import Path

SPACE = "▁"


def to_words(text: str) -> Counter:
    """문장을 공백으로 나누고, 단어마다 글자 튜플로 바꿔 등장 횟수를 센다."""
    words = Counter()
    for word in text.split():
        words[tuple(SPACE + word)] += 1
    return words


def pair_counts(words: Counter) -> Counter:
    """모든 단어 안에서 이웃한 두 토큰 쌍의 빈도를 센다(단어 빈도만큼 가중)."""
    counts = Counter()
    for symbols, freq in words.items():
        for pair in zip(symbols, symbols[1:]):
            counts[pair] += freq
    return counts


def merge_symbols(symbols: tuple, pair: tuple) -> tuple:
    """토큰열 안의 pair를 모두 하나의 토큰으로 합친다(왼쪽부터)."""
    out, i = [], 0
    while i < len(symbols):
        if i < len(symbols) - 1 and (symbols[i], symbols[i + 1]) == pair:
            out.append(symbols[i] + symbols[i + 1])
            i += 2
        else:
            out.append(symbols[i])
            i += 1
    return tuple(out)


def train_bpe(text: str, num_merges: int) -> tuple:
    """병합 규칙(merges)을 순서대로 학습한다. 동점이면 먼저 나온 쌍을 고른다."""
    words = to_words(text)
    base_vocab = sorted({c for symbols in words for c in symbols})
    merges = []
    for _ in range(num_merges):
        counts = pair_counts(words)
        if not counts:
            break
        best, freq = counts.most_common(1)[0]
        merges.append((best, freq))
        words = Counter({merge_symbols(s, best): f for s, f in words.items()})
    vocab = base_vocab + ["".join(pair) for pair, _ in merges]
    return merges, vocab


def encode(text: str, merges: list) -> list:
    """새 문장에 학습된 병합 규칙을 학습 순서대로 적용한다."""
    tokens = []
    for word in text.split():
        symbols = tuple(SPACE + word)
        for pair, _ in merges:
            symbols = merge_symbols(symbols, pair)
        tokens.extend(symbols)
    return tokens


def decode(tokens: list) -> str:
    return "".join(tokens).replace(SPACE, " ").strip()


def main() -> None:
    corpus = Path(__file__).parents[1].joinpath("ch07", "corpus.txt").read_text(encoding="utf-8")
    sample = "언어 모델은 토큰을 고른다."

    print("── 1. 병합 과정(처음 10번) ──")
    merges, vocab = train_bpe(corpus, num_merges=60)
    for step, (pair, freq) in enumerate(merges[:10], 1):
        print(f"{step:>2}. {pair[0]!r} + {pair[1]!r} → {pair[0] + pair[1]!r}  (빈도 {freq})")

    print("\n── 2. 병합 횟수에 따른 토큰 수 ──")
    for n in (0, 10, 30, 60):
        tokens = encode(sample, merges[:n])
        print(f"병합 {n:>2}번: {len(tokens):>2}개  {tokens}")

    print("\n── 3. 왕복 복원 ──")
    tokens = encode(sample, merges)
    print(f"{sample!r} → {tokens} → {decode(tokens)!r}")

    print("\n── 4. 처음 보는 단어 ──")
    unseen = "모델링"
    tokens = encode(unseen, merges)
    missing = [tok for tok in tokens if tok not in vocab]
    print(f"{unseen!r} → {tokens}")
    print(f"  '▁모델'은 학습한 조각으로 표현되지만, 어휘에 없는 토큰이 남는다: {missing}")

    print("\n── 5. Byte-level: 모든 글자는 바이트로 표현할 수 있다 ──")
    for ch in ("A", "토", "🙂"):
        data = list(ch.encode("utf-8"))
        print(f"{ch!r}: UTF-8 {len(data)}바이트 {data}")
    print(f"어휘 크기: 기본 글자 {len(vocab) - len(merges)}개 + 병합 {len(merges)}개 = {len(vocab)}개")


if __name__ == "__main__":
    main()
```

**핵심 코드 풀이**

- `to_words()`는 문장을 공백으로 나눠 단어마다 `('▁', '모', '델', '은')`처럼 글자 튜플로 만들고, 같은 단어의 등장 횟수를 셉니다. 같은 단어를 매번 다시 세지 않고 횟수로 가중해 계산을 줄입니다.
- `pair_counts()`가 02절의 ① 쌍 빈도 세기, `merge_symbols()`가 ② 합치기입니다. `train_bpe()`는 이 둘을 `num_merges`번 반복하며 합친 쌍을 `merges`에 순서대로 기록합니다.
- 1번 결과의 첫 병합은 `'다' + '.'`(빈도 10)입니다. 학습 문장 10개가 모두 "…다."로 끝나기 때문입니다. 데이터에서 가장 흔한 패턴이 가장 먼저 한 토큰이 된다는 BPE의 성질이 그대로 드러납니다.
- 4·5번 병합(`▁모델`, `▁모델은`)과 9·10번 병합(`▁토큰`, `▁토큰을`)은 03절에서 설명한 "앞의 병합이 뒤의 재료가 되는" 과정입니다.
- 2번 표에서 같은 문장이 병합 0번일 때 16개, 60번일 때 4개 토큰이 됩니다. 병합이 늘수록 어휘는 커지고 토큰열은 짧아집니다. 제08장에서 본 "어휘 크기와 시퀀스 길이의 균형"을 정하는 손잡이가 병합 횟수입니다.
- 3번은 인코딩한 토큰을 다시 문장으로 되돌립니다. `decode()`는 토큰을 이어 붙이고 `▁`를 공백으로 바꿔 원문과 정확히 같은 문장을 만듭니다.
- 4번은 03절의 한계를 실제로 보여 줍니다. `▁모델`은 학습한 조각으로 표현되지만 `링`은 어휘에 없는 토큰으로 남습니다.
- 5번은 그 해법인 바이트를 보여 줍니다. 영문자는 1바이트, 한글은 3바이트, 이모지는 4바이트이며, 모두 0~255 사이의 값입니다.

### 실습 2. 실제 Qwen2.5의 병합 규칙

Qwen2.5 토크나이저는 병합 규칙을 `merges.txt` 파일에 한 줄에 하나씩 저장합니다. 이 파일의 규칙 수로 Byte-level BPE의 어휘 크기 식을 확인합니다.

파일명: `examples/ch09/qwen_merges.py`

```python
# 제09장 실습 2: 실제 Qwen2.5 토크나이저의 병합 규칙 확인
#
# 실행: python examples/ch09/qwen_merges.py
#
# Byte-level BPE의 어휘 = 기본 바이트 256개 + 학습된 병합 규칙 수

import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from common.models import qwen_file  # noqa: E402


def load_merges(local_only: bool = False) -> list:
    path = qwen_file("merges.txt", local_only=local_only)
    with open(path, encoding="utf-8") as f:
        return [line.split() for line in f.read().split("\n") if line.strip()]


def main() -> None:
    merges = load_merges()
    print(f"병합 규칙 수: {len(merges):,}")
    print(f"기본 바이트 256 + 병합 {len(merges):,} = {256 + len(merges):,}  (일반 토큰 수와 비교)")
    print("\n처음 6개 규칙(Ġ는 공백 바이트를 표시하는 기호):")
    for i, (a, b) in enumerate(merges[:6], 1):
        print(f"  {i}. {a!r} + {b!r} → {a + b!r}")


if __name__ == "__main__":
    main()
```

```bash
python examples/ch09/qwen_merges.py
```

실제 실행 결과(교재 검증 환경):

```text
병합 규칙 수: 151,387
기본 바이트 256 + 병합 151,387 = 151,643  (일반 토큰 수와 비교)

처음 6개 규칙(Ġ는 공백 바이트를 표시하는 기호):
  1. 'Ġ' + 'Ġ' → 'ĠĠ'
  2. 'ĠĠ' + 'ĠĠ' → 'ĠĠĠĠ'
  3. 'i' + 'n' → 'in'
  4. 'Ġ' + 't' → 'Ġt'
  5. 'ĠĠĠĠ' + 'ĠĠĠĠ' → 'ĠĠĠĠĠĠĠĠ'
  6. 'e' + 'r' → 'er'
```

**결과 읽기**

- 병합 규칙 151,387개에 기본 바이트 256개를 더하면 151,643입니다. 제08장에서 확인한 Qwen 토크나이저의 일반 토큰 수와 **정확히** 같습니다. Qwen2.5의 어휘가 바이트에서 출발해 병합 규칙으로 만들어졌다는 직접적인 증거입니다. 여기에 특수 토큰 22개를 더하면 전체 151,665개가 됩니다.
- `Ġ`는 공백 바이트를 화면에 표시하기 위해 바꿔 쓴 기호로, 이 장 구현의 `▁`와 같은 역할입니다.
- 처음 규칙들은 공백 묶음(`ĠĠ`, `ĠĠĠĠ`)과 `in`, `er` 같은 영어 조각입니다. 코드의 들여쓰기 공백과 영어 텍스트가 학습 데이터에 매우 많았다는 뜻이며, 제08장에서 영문 문장의 토큰 수가 적었던 이유이기도 합니다.

```python

import sys
from pathlib import Path

import pytest

sys.path.insert(0, str(Path(__file__).resolve().parent))

from bpe import decode, encode, merge_symbols, pair_counts, to_words, train_bpe  # noqa: E402

CORPUS = Path(__file__).parents[1].joinpath("ch07", "corpus.txt").read_text(encoding="utf-8")


def test_pair_counts_hand_example():
    # "아아아" 한 단어 → ('▁','아') 1회, ('아','아') 2회
    counts = pair_counts(to_words("아아아"))
    assert counts[("▁", "아")] == 1 and counts[("아", "아")] == 2


def test_merge_symbols_left_to_right():
    assert merge_symbols(("a", "a", "a"), ("a", "a")) == ("aa", "a")


def test_first_merge_is_most_frequent():
    merges, _ = train_bpe(CORPUS, num_merges=1)
    (pair, freq), = merges
    assert freq == max(pair_counts(to_words(CORPUS)).values())


def test_more_merges_never_increase_tokens():
    merges, _ = train_bpe(CORPUS, num_merges=60)
    sample = "언어 모델은 토큰을 고른다."
    lengths = [len(encode(sample, merges[:n])) for n in range(0, 61, 5)]
    assert all(a >= b for a, b in zip(lengths, lengths[1:]))


@pytest.mark.parametrize("text", ["언어 모델은 토큰을 고른다.", "학습은 가중치를 고치는 일이다."])
def test_round_trip(text):
    merges, _ = train_bpe(CORPUS, num_merges=60)
    assert decode(encode(text, merges)) == text


def test_encoding_is_deterministic():
    merges, _ = train_bpe(CORPUS, num_merges=60)
    assert encode("모델은", merges) == encode("모델은", merges)


def test_vocab_size_is_base_plus_merges():
    merges, vocab = train_bpe(CORPUS, num_merges=60)
    base = {c for symbols in to_words(CORPUS) for c in symbols}
    assert len(vocab) == len(base) + len(merges)


def test_utf8_byte_lengths():
    assert [len(c.encode("utf-8")) for c in ("A", "토", "🙂")] == [1, 3, 4]


def test_qwen_vocab_equals_bytes_plus_merges():
    qwen_merges = pytest.importorskip("qwen_merges")
    try:
        merges = qwen_merges.load_merges(local_only=True)
    except Exception:
        pytest.skip("Qwen merges.txt가 아직 내려받아지지 않음(qwen_merges.py를 먼저 실행)")
    assert 256 + len(merges) == 151_643
```

## 핵심 정리

- BPE는 가장 자주 붙어 나오는 두 조각을 합치는 일을 반복해 어휘를 만듭니다. 어휘는 데이터가 정합니다.
- 학습 결과는 순서가 매겨진 병합 규칙 목록이며, 새 문장에는 같은 규칙을 같은 순서로 적용합니다.
- 병합 횟수가 늘면 어휘는 커지고 토큰열은 짧아집니다.
- 글자에서 출발하면 처음 보는 글자를 표현할 수 없습니다. Byte-level BPE는 바이트 256개에서 출발해 어떤 글자든 표현합니다.
- Qwen2.5의 일반 토큰 151,643개는 바이트 256개와 병합 규칙 151,387개의 합입니다.

**다음 장 연결:** 이제 문장은 Token ID의 나열이 되었습니다. 그러나 정수 번호에는 의미가 없습니다. 1614번과 1615번 토큰이 비슷한 뜻이라는 보장은 없습니다. 제10장에서는 Token ID를 의미를 담은 **벡터**로 바꾸는 Embedding을 다루고, 제1부를 마무리합니다.
