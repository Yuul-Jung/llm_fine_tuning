## 장 개요

제04장의 행렬곱에는 정해진 숫자가 들어 있었습니다. 이 장에서는 그 숫자를 **학습으로 바뀌는 값**, 즉 가중치로 바꿉니다. 가중치 행렬과 편향 벡터로 이루어진 Linear Layer(선형 계층)는 LLM에서 가장 많이 쓰이는 부품입니다. Qwen2.5-0.5B에는 계층마다 Linear가 7개씩, 24개 계층에 모두 168개가 있습니다(출력 직전의 LM Head 제외).

이 장은 Linear Layer를 직접 구현해 PyTorch의 `nn.Linear`와 비교하고, 교재 전체에서 쓸 **표기 규약**을 고정합니다. 그리고 처음으로 실제 Qwen2.5-0.5B 모델 파일을 열어 진짜 가중치를 꺼내 계산해 봅니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | Linear Layer는 무엇을 계산하며, 가중치는 어떤 모양으로 저장되는가 |
| 실습 결과물 | 직접 구현과 `nn.Linear` 출력 비교, 실제 Qwen 가중치로 계산한 결과 |
| 실습 파일 | `examples/ch05/`의 `linear_scratch.py`, `qwen_weight.py`, `test_ch05.py`와 공통 모듈 `examples/common/models.py` |
| 선수 장 | 제04장(행렬곱 차원 규칙, Broadcasting) |

```text
[개념] 가중치·편향 → 학습이란 이 숫자들을 바꾸는 일
   ↓
[규약] y = xWᵀ + b,  W의 저장 모양 [out, in]
   ↓
[구현] nn.Linear 해부 → 직접 구현 → 출력 비교
   ↓
[실전] Qwen2.5-0.5B 파일에서 k_proj 가중치를 꺼내 같은 계산
```

## 가중치와 편향

Linear Layer는 입력 벡터를 받아 다른 길이의 출력 벡터로 바꿉니다. 출력의 각 칸은 **입력 전체에 가중치를 곱해 더한 값에 편향을 더한 것**입니다.

```text
입력 x = [x₁, x₂, x₃, x₄]                     (in = 4)

출력 y₁ = w₁₁x₁ + w₁₂x₂ + w₁₃x₃ + w₁₄x₄ + b₁
출력 y₂ = w₂₁x₁ + w₂₂x₂ + w₂₃x₃ + w₂₄x₄ + b₂   (out = 3)
출력 y₃ = w₃₁x₁ + w₃₂x₂ + w₃₃x₃ + w₃₄x₄ + b₃
```

| 구성 | 역할 | 개수(in 4, out 3) |
|---|---|---|
| 가중치(Weight) | 입력의 각 칸이 출력에 얼마나 기여하는지 | in × out = 12 |
| 편향(Bias) | 입력과 무관하게 출력에 더해지는 기준값 | out = 3 |
| 합계 | 학습 가능한 파라미터 | 15 |

출력 한 칸은 제04장의 내적 그 자체입니다. 입력 벡터와 가중치 한 줄의 내적에 편향을 더한 것입니다. 출력이 3칸이면 내적 3번, 즉 행렬곱 한 번입니다.

모델의 "학습"이란 바로 이 가중치와 편향의 숫자를 조금씩 고치는 일입니다. 제3부에서 손실함수와 역전파로 이 숫자를 어떻게 고치는지 배우고, LoRA에서는 이 가중치를 얼려 둔 채 작은 행렬만 학습합니다. 모든 것이 이 장의 가중치에서 출발합니다.

## 교재 공통 표기 규약

같은 계산도 책마다 행렬을 쓰는 방향이 다릅니다. 이 교재는 PyTorch의 실제 저장 방식과 똑같은 규약 하나로 고정하고, 제60장까지 바꾸지 않습니다.

```text
y = x Wᵀ + b

x : [..., in]       입력은 행벡터, 앞쪽 축(batch, seq)은 몇 개든 그대로 유지
W : [out, in]       가중치는 출력 수 × 입력 수로 저장
Wᵀ: [in, out]       계산할 때 전치해서 곱함
b : [out]           편향은 Broadcasting으로 모든 위치에 더해짐
y : [..., out]
```

왜 `W`를 `[in, out]`으로 저장하지 않고 굳이 `[out, in]`으로 저장한 뒤 전치할까요? 가중치의 한 줄 `W[j]`가 곧 "출력 j번 칸을 만드는 가중치 묶음"이 되기 때문입니다. 출력 칸 하나에 해당하는 가중치를 한 줄로 꺼낼 수 있어 해석과 조작이 편리합니다. 제28장 LoRA의 행렬 `A [r, in]`, `B [out, r]`도 이 규약을 그대로 따릅니다.

| 대상 | 규약에 따른 모양 | 예 |
|---|---|---|
| `nn.Linear(4, 3)`의 가중치 | `[3, 4]` | 이 장의 실습 |
| Qwen2.5-0.5B `k_proj` 가중치 | `[128, 896]` | 입력 896 → 출력 128 |
| Qwen2.5-0.5B `o_proj` 가중치 | `[896, 896]` | 입력 896 → 출력 896 |

## nn.Linear 구조

PyTorch의 `nn.Linear(in_features, out_features)`는 규약 그대로 가중치와 편향을 저장합니다.

`layer = nn.Linear(4, 3)`으로 만든 계층을 예로 들면 다음과 같습니다.

| 속성·함수 | 내용 | 값 |
|---|---|---|
| `weight` | 가중치 `[out, in]` | `(3, 4)` |
| `bias` | 편향 `[out]` | `(3,)` |
| `parameters()` | 학습 대상 목록 | 12 + 3 = 15 |
| `layer(x)` | 순전파 계산 | `xWᵀ + b` |
| `bias=False` | 편향 없이 생성 | 파라미터 12 |

입력 `x`는 마지막 축 길이만 `in_features`와 맞으면 됩니다. `[2, 4]`든 `[2, 5, 4]`든 앞쪽 축은 그대로 두고 마지막 축만 `in`에서 `out`으로 바뀝니다. 제04장의 Batch 행렬곱과 Broadcasting 덕분입니다.

### 편향이 있는 계층, 없는 계층

모든 Linear에 편향이 있는 것은 아닙니다. 모델 설계자가 계층마다 정합니다. Qwen2.5에서는 Query·Key·Value를 만드는 세 계층에만 편향이 있고, 나머지(`o_proj`, FFN의 세 계층)에는 없습니다. 이 차이는 제12장에서 다시 확인하며, 파라미터 수를 정확히 계산할 때도 중요합니다.

## Linear Layer 직접 구현

규약을 코드로 옮기면 한 줄입니다.

```text
y = x @ weight.T + bias
```

다음 실습의 `linear_forward()`가 이 한 줄이고, `MyLinear`는 가중치와 편향을 직접 만들어 들고 있는 최소 계층입니다. `nn.Linear`와 같은 가중치를 넣었을 때 같은 출력이 나오면, 우리가 PyTorch의 계산을 정확히 이해했다는 증거가 됩니다.

### 실제 모델 파일에서 가중치 꺼내기

Qwen2.5-0.5B의 모든 가중치는 `model.safetensors` 파일 하나에 이름표를 달고 저장되어 있습니다. 모델 전체를 메모리에 올리지 않고도 `safe_open`으로 필요한 텐서 하나만 꺼낼 수 있습니다.

```text
model.layers.0.self_attn.k_proj.weight   ← 0번 계층 Attention의 Key 가중치
model.layers.0.self_attn.k_proj.bias     ← 같은 계층의 Key 편향
model.layers.0.self_attn.o_proj.weight   ← 0번 계층 Attention의 출력 가중치(편향 없음)
```

이름표는 점(`.`)으로 구분된 경로입니다. `layers.0`은 0번 계층, `self_attn`은 그 안의 Attention, `k_proj`는 Key를 만드는 Linear를 뜻합니다.

모델 파일은 교재가 고정한 Revision(커밋 해시)으로 내려받습니다. 공통 모듈 `examples/common/models.py`가 이 일을 맡아, 저장소의 모델이 갱신되어도 교재의 결과가 바뀌지 않게 합니다.

파일명: `examples/common/models.py`

## 핵심 실습

### 실습 1. 직접 구현과 nn.Linear 비교

파일명: `examples/ch05/linear_scratch.py`

```python
# 제05장 핵심 실습 1: Linear Layer를 직접 구현하고 nn.Linear와 비교
#
# 실행: python examples/ch05/linear_scratch.py
#
# 교재 공통 표기 규약: y = x Wᵀ + b,  W의 저장 모양 = [out_features, in_features]

import torch
from torch import nn


def linear_forward(x: torch.Tensor, weight: torch.Tensor, bias=None) -> torch.Tensor:
    """x: [..., in], weight: [out, in], bias: [out] → [..., out]"""
    y = x @ weight.T          # [..., in] × [in, out] = [..., out]
    if bias is not None:
        y = y + bias          # Broadcasting: [out]이 [..., out]으로 확장
    return y


class MyLinear:
    """nn.Linear와 같은 저장 방식으로 만든 최소 Linear 계층."""

    def __init__(self, in_features: int, out_features: int, bias: bool = True):
        # nn.Linear 기본 초기화와 같은 범위: U(-1/√in, 1/√in)
        bound = 1 / in_features ** 0.5
        self.weight = (torch.rand(out_features, in_features) * 2 - 1) * bound
        self.bias = (torch.rand(out_features) * 2 - 1) * bound if bias else None

    def __call__(self, x: torch.Tensor) -> torch.Tensor:
        return linear_forward(x, self.weight, self.bias)

    def num_parameters(self) -> int:
        n = self.weight.numel()
        return n + (self.bias.numel() if self.bias is not None else 0)


def main() -> None:
    torch.manual_seed(0)
    layer = nn.Linear(4, 3)        # in 4 → out 3

    print("── 1. nn.Linear의 저장 모양 ──")
    print(f"weight.shape = {tuple(layer.weight.shape)}   ← [out, in]")
    print(f"bias.shape   = {tuple(layer.bias.shape)}")
    params = sum(p.numel() for p in layer.parameters())
    print(f"파라미터 수   = {params}  (4×3 + 3)")

    print("\n── 2. 같은 가중치로 직접 구현과 비교 ──")
    x = torch.randn(2, 4)          # 입력 2개, 각 4차원
    y_torch = layer(x)
    y_mine = linear_forward(x, layer.weight, layer.bias)
    print("nn.Linear :", y_torch.detach())
    print("직접 구현 :", y_mine.detach())
    print(f"최대 절대오차: {(y_torch - y_mine).abs().max().item():.2e}")

    print("\n── 3. 출력 한 칸 손으로 따라가기 ──")
    w0, b0 = layer.weight[0].detach(), layer.bias[0].item()
    manual = sum(x[0, i].item() * w0[i].item() for i in range(4)) + b0
    print(f"y[0, 0] = x[0] · W[0] + b[0] = {manual:.6f}  (출력 {y_torch[0, 0].item():.6f})")

    print("\n── 4. 3차원 입력 [batch, seq, in] ──")
    h = torch.randn(2, 5, 4)
    print(f"{tuple(h.shape)} → {tuple(layer(h).shape)}")

    print("\n── 5. MyLinear(직접 만든 계층) ──")
    mine = MyLinear(4, 3)
    print(f"weight {tuple(mine.weight.shape)}, bias {tuple(mine.bias.shape)}, "
          f"파라미터 {mine.num_parameters()}개, 출력 {tuple(mine(h).shape)}")


if __name__ == "__main__":
    main()
```


**핵심 코드 풀이**

- `linear_forward()`의 `x @ weight.T`는 규약 `y = xWᵀ + b`를 그대로 옮긴 것입니다. 저장 모양 `[out, in]`을 전치해 `[in, out]`으로 만든 뒤 곱하므로, 제04장의 차원 규칙에 따라 `[..., in] × [in, out] = [..., out]`이 됩니다.
- 2번에서 두 결과의 오차가 정확히 0입니다. 같은 가중치로 같은 연산을 했기 때문입니다.
- 3번은 출력 한 칸을 반복문으로 다시 계산합니다. `x[0] · W[0] + b[0]`, 즉 입력과 가중치 첫 줄의 내적에 첫 편향을 더한 값이 출력과 같습니다. 가중치 한 줄이 출력 한 칸을 만든다는 규약의 의미를 숫자로 확인한 것입니다.
- `MyLinear`의 초기화 범위 `±1/√in`은 `nn.Linear`의 기본값과 같습니다. 입력이 많을수록 가중치를 작게 시작해, 더한 결과가 너무 커지지 않게 합니다. 제04장에서 본 "차원이 클수록 합이 커진다"는 성질에 대한 대비입니다.

### 실습 2. 실제 Qwen 가중치로 계산하기

파일명: `examples/ch05/qwen_weight.py`

```python
# 제05장 핵심 실습 2: 실제 Qwen2.5-0.5B의 Linear 가중치를 꺼내 직접 계산
#
# 실행: python examples/ch05/qwen_weight.py
# 준비: 처음 실행할 때 모델 파일(model.safetensors, 약 1GB)을 내려받는다.

import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
sys.path.insert(0, str(Path(__file__).resolve().parent))

import torch  # noqa: E402
import torch.nn.functional as F  # noqa: E402
from safetensors import safe_open  # noqa: E402

from common.models import qwen_file  # noqa: E402
from linear_scratch import linear_forward  # noqa: E402

LAYER = "model.layers.0.self_attn"


def load_tensors(names: list, local_only: bool = False) -> dict:
    """모델 전체를 올리지 않고, 필요한 텐서만 파일에서 꺼낸다."""
    path = qwen_file("model.safetensors", local_only=local_only)
    with safe_open(path, framework="pt") as f:
        return {name: f.get_tensor(name) for name in names}


def main() -> None:
    names = [f"{LAYER}.k_proj.weight", f"{LAYER}.k_proj.bias", f"{LAYER}.o_proj.weight"]
    t = load_tensors(names)

    print("── 1. 꺼낸 가중치 ──")
    for name, tensor in t.items():
        print(f"{name.replace(LAYER + '.', ''):<16} shape={str(tuple(tensor.shape)):<12} "
              f"dtype={str(tensor.dtype).replace('torch.', '')}")

    w = t[f"{LAYER}.k_proj.weight"].float()      # BF16 저장 → FP32 계산
    b = t[f"{LAYER}.k_proj.bias"].float()
    print(f"\nk_proj 파라미터 수: {w.numel() + b.numel():,}  (896×128 + 128)")

    print("\n── 2. 직접 계산과 PyTorch 함수 비교 ──")
    torch.manual_seed(0)
    x = torch.randn(1, 4, 896)                   # [batch, seq, hidden]
    y_mine = linear_forward(x, w, b)
    y_torch = F.linear(x, w, b)
    print(f"입력 {tuple(x.shape)} → 출력 {tuple(y_mine.shape)}")
    print(f"최대 절대오차: {(y_mine - y_torch).abs().max().item():.2e}")

    print("\n── 3. 가중치 값의 분포 ──")
    print(f"평균 {w.mean().item():+.4f}, 표준편차 {w.std().item():.4f}, "
          f"최솟값 {w.min().item():+.3f}, 최댓값 {w.max().item():+.3f}")


if __name__ == "__main__":
    main()
```

```text
입력 (1, 4, 896) → 출력 (1, 4, 128)
최대 절대오차: 1.53e-05

── 3. 가중치 값의 분포 ──
평균 +0.0001, 표준편차 0.0806, 최솟값 -1.023, 최댓값 +0.918
```

**핵심 코드 풀이**

- `safe_open()`으로 파일을 연 뒤 `get_tensor(이름)`으로 텐서 세 개만 꺼냅니다. 1GB 모델 전체를 올리지 않고 필요한 부분만 읽는 방법이며, 제53장 가중치 추출에서 본격적으로 씁니다.
- 꺼낸 가중치의 모양이 규약과 정확히 일치합니다. `k_proj`는 `[out 128, in 896]`, `o_proj`는 `[896, 896]`이며, `k_proj`에는 편향이 있고 `o_proj`에는 없습니다.
- 저장 자료형은 `bfloat16`입니다. 제01·02장의 원칙대로 계산 전에 `.float()`로 FP32로 바꿉니다. 저장은 16비트, 계산은 32비트입니다.
- 파라미터 수 114,816개는 제02장 `count_qwen_params()`에서 K Projection 몫으로 계산한 값(`896 × 128 + 128`)과 같습니다.
- 최대 절대오차 `1.53e-05`는 0이 아닙니다. 896개 항을 더하는 순서가 두 계산에서 달라서 생기는 FP32의 정상적인 반올림 차이로, 허용 오차 안에 있습니다(제04장 참고).
- 실제 가중치는 평균이 거의 0이고 대부분 ±0.1 근처에 모여 있습니다. 이 분포는 제36장 NF4 양자화가 "가중치는 정규분포에 가깝다"는 가정을 쓰는 근거가 됩니다.

```python
import sys
from pathlib import Path

import pytest
import torch

from torch import nn

from linear_scratch import MyLinear, linear_forward  # noqa: E402


def test_nn_linear_storage_shape_and_count():
    layer = nn.Linear(4, 3)
    assert layer.weight.shape == (3, 4)            # [out, in]
    assert layer.bias.shape == (3,)
    assert sum(p.numel() for p in layer.parameters()) == 15


@pytest.mark.parametrize("shape", [(2, 4), (2, 5, 4), (3, 2, 5, 4)])
def test_linear_forward_matches_nn_linear(shape):
    torch.manual_seed(0)
    layer = nn.Linear(4, 3)
    x = torch.randn(*shape)
    torch.testing.assert_close(linear_forward(x, layer.weight, layer.bias), layer(x))


def test_hand_calculation():
    x = torch.tensor([[1., 2.]])
    w = torch.tensor([[1., 0.], [2., 3.], [0., -1.]])   # [out 3, in 2]
    b = torch.tensor([10., 20., 30.])
    # [1×1+2×0, 1×2+2×3, 1×0+2×(-1)] + b = [11, 28, 28]
    assert torch.equal(linear_forward(x, w, b), torch.tensor([[11., 28., 28.]]))


def test_no_bias():
    w = torch.randn(3, 4)
    x = torch.randn(2, 4)
    torch.testing.assert_close(linear_forward(x, w), F.linear(x, w))


def test_my_linear():
    mine = MyLinear(4, 3)
    assert mine.num_parameters() == 15
    assert mine(torch.randn(2, 5, 4)).shape == (2, 5, 3)
    assert MyLinear(4, 3, bias=False).num_parameters() == 12


def test_qwen_k_proj():
    qwen_weight = pytest.importorskip("qwen_weight")
    names = ["model.layers.0.self_attn.k_proj.weight", "model.layers.0.self_attn.k_proj.bias",
             "model.layers.0.self_attn.o_proj.weight"]
    try:
        t = qwen_weight.load_tensors(names, local_only=True)
    except Exception:
        pytest.skip("Qwen 모델 파일이 아직 내려받아지지 않음(qwen_weight.py를 먼저 실행)")
    w, b = t[names[0]].float(), t[names[1]].float()
    assert w.shape == (128, 896) and b.shape == (128,)

    assert t[names[0]].dtype == torch.bfloat16
```

## 핵심 정리

- Linear Layer는 출력 칸마다 "입력과 가중치 한 줄의 내적 + 편향"을 계산합니다. 출력 전체로 보면 행렬곱 한 번입니다.
- 교재 공통 규약은 `y = xWᵀ + b`, 가중치 저장 모양은 `[out, in]`입니다. PyTorch와 실제 Qwen 파일이 모두 이 방식입니다.
- 파라미터 수는 `in × out`(+ 편향이 있으면 `out`)입니다. Qwen2.5에서는 Q·K·V Projection에만 편향이 있습니다.
- 실제 모델 가중치는 BF16으로 저장되어 있으며, 교재에서는 FP32로 바꿔 계산합니다.

**다음 장 연결:** Linear Layer만 여러 겹 쌓으면 결국 하나의 Linear와 같아집니다. 제06장에서는 이 한계를 깨는 활성화 함수와, 출력 점수를 확률로 바꾸는 Softmax를 다룹니다.
