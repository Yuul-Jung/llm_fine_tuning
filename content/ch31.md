## 장 개요

제3부에서 LoRA로 **학습할 파라미터**를 크게 줄였습니다. 하지만 원본 가중치는 여전히 FP32, 숫자 하나에 32비트(4바이트)로 저장되어 있습니다. Qwen2.5-0.5B는 원본만 약 2GB라 GT 1030에 올라가지 않습니다. 제4부는 원본을 **더 적은 비트로 저장하는** 양자화를 다루고, 마지막에 4비트 원본 위에서 LoRA를 학습하는 QLoRA로 0.5B 모델을 GT 1030에서 학습합니다.

양자화는 결국 "실수를 적은 비트의 정수로 바꾸는 일"입니다. 그래서 출발점은 컴퓨터가 수를 비트로 어떻게 표현하는지입니다. 이 장은 정수와 2의 보수, 비트 폭과 범위, 소수점 위치를 약속하는 고정소수점, 그리고 범위를 넘거나 끝자리를 처리할 때의 규칙을 직접 만든 변환기로 확인합니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | n개의 비트로 어떤 수들을 표현할 수 있으며, 실수를 정수 비트로 담으면 무엇을 잃는가 |
| 실습 결과물 | 2의 보수 변환기, 비트 폭별 범위표, Q Format 변환과 오차, Overflow·Saturation·Rounding 비교 |
| 실습 파일 | `examples/ch31/`의 `num_format.py`, `test_ch31.py` |
| 선수 장 | 제02장(자료형과 메모리) |

```text
FP32 가중치 0.3  ──양자화──▶  8비트 정수 코드 38  ──복원──▶  0.296875
  32비트                       8비트(4분의 1)                  오차 0.003
```

## 정수와 2의 보수

8비트는 `00000000`부터 `11111111`까지 256가지 패턴입니다. 이 패턴을 어떤 수로 읽을지는 **약속**에 달려 있습니다.

| 비트 패턴 | 부호 없는 정수 | 부호 있는 정수(2의 보수) |
|---|---|---|
| `00000101` | 5 | 5 |
| `01111111` | 127 | 127 |
| `10000000` | 128 | −128 |
| `11111111` | 255 | −1 |

**2의 보수**는 맨 앞 비트의 자리값을 +128 대신 **−128**로 읽는 약속입니다. `11111111`은 −128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = −1입니다. 음수를 만드는 손 계산법은 "비트를 모두 뒤집고 1을 더하기"입니다. 5 = `00000101`을 뒤집으면 `11111010`, 1을 더하면 `11111011` = −5입니다.

2의 보수가 표준이 된 이유는 덧셈 회로 하나로 양수와 음수를 모두 계산할 수 있기 때문입니다. `5 + (−5)`를 비트로 더하면 `00000101 + 11111011 = 1 00000000`이 되고, 넘친 맨 앞 1을 버리면 정확히 0입니다. FPGA에서 Verilog의 `signed` 연산이 따로 뺄셈기를 두지 않는 것도 같은 원리입니다.

## 비트 폭과 표현 범위

부호 있는 n비트 정수의 범위는 **−2ⁿ⁻¹부터 2ⁿ⁻¹ − 1까지**입니다. 음수 쪽이 하나 더 많은 것은 0이 양수 쪽 자리를 하나 차지하기 때문입니다.

| 자료형 | 범위 | 값의 가짓수 |
|---|---|---|
| INT4 | −8 ~ 7 | 16 |
| INT8 | −128 ~ 127 | 256 |
| INT16 | −32,768 ~ 32,767 | 65,536 |
| INT32 | 약 ±21억 | 약 43억 |

양자화는 이 표에서 출발합니다. INT8로 양자화한다는 것은 가중치 수천만 개를 **256가지 값 중 하나**로 바꾼다는 뜻이고, INT4는 **16가지 값**으로 바꾼다는 뜻입니다. 비트를 하나 줄일 때마다 표현할 수 있는 값은 절반이 되고, 메모리도 그만큼 줄어듭니다. 이 교환을 어떻게 잘하느냐가 제33~36장의 주제입니다.

## 고정소수점과 Q Format

정수 비트로 실수를 표현하는 가장 단순한 방법은 **소수점의 위치를 미리 약속**하는 것입니다. 이것이 고정소수점(Fixed-point)이며, 약속은 **Q Format**으로 적습니다.

```text
Qm.n:  부호 1비트 + 정수부 m비트 + 소수부 n비트
       실수 x  →  정수 코드 = round(x × 2ⁿ)
       코드 c  →  실수 = c ÷ 2ⁿ
```

같은 8비트라도 소수점 위치에 따라 성격이 달라집니다.

| 형식 | 간격(가장 작은 차이) | 범위 |
|---|---|---|
| Q0.7 | 1/128 ≈ 0.0078 | −1 ~ 0.992 |
| Q3.4 | 1/16 = 0.0625 | −8 ~ 7.94 |

소수부 비트를 늘리면 간격이 좁아져 **정밀**해지지만 범위가 줄어들고, 정수부 비트를 늘리면 범위는 넓어지지만 **거칠어집니다**. 비트 수가 정해져 있으면 범위와 정밀도는 서로 맞바꿔야 합니다. 이 맞바꿈은 제32장의 FP16과 BF16, 제33장 양자화의 Scale 선택에서도 똑같이 나타납니다.

고정소수점은 FPGA·DSP에서 실수를 다룰 때의 기본 방식입니다. 덧셈은 정수 덧셈 그대로이고, 곱셈은 정수 곱셈 뒤 소수부 비트만큼 오른쪽으로 밀면 됩니다. 양자화된 신경망을 하드웨어로 만들 때 이 계산이 그대로 쓰입니다.

## Overflow, Saturation, Rounding

정수로 바꿀 때는 두 가지 상황을 정해 두어야 합니다. 범위를 넘을 때, 그리고 끝자리가 딱 떨어지지 않을 때입니다.

| 상황 | 규칙 | INT8 예 |
|---|---|---|
| 범위를 넘음 | **Overflow**(감싸기): 반대쪽 끝으로 돌아간다 | 127 + 1 → −128 |
| 범위를 넘음 | **Saturation**(포화): 가장 가까운 끝에 머문다 | 127 + 1 → 127 |
| 끝자리 처리 | 짝수 쪽 반올림: .5에서 짝수를 고른다 | 2.5 → 2, 3.5 → 4 |
| 끝자리 처리 | 0에서 먼 쪽 반올림(사사오입) | 2.5 → 3, −2.5 → −3 |

정수 하드웨어와 PyTorch의 정수 텐서는 기본적으로 **감싸기**를 합니다. 오류 없이 127 + 1이 −128이 되므로, 큰 양수 가중치가 갑자기 큰 음수로 뒤집힐 수 있습니다. 양자화에서는 이런 사고를 막기 위해 범위 밖의 값을 **포화**시킵니다.

반올림 규칙의 차이는 .5에서만 나타나지만, 수천만 개의 가중치를 처리하면 결과가 한쪽으로 치우칠 수 있습니다. 사사오입은 .5를 언제나 크기가 커지는 쪽으로 올리므로 평균적으로 값이 커지고, 짝수 쪽 반올림은 올림과 내림이 반반이라 치우침이 없습니다. 그래서 IEEE 754(제32장)와 Python의 `round()`, PyTorch의 `torch.round()`는 짝수 쪽 반올림을 기본으로 씁니다.

## 핵심 실습

파일명: `examples/ch31/num_format.py`

```python
# 제31장 핵심 실습: Python 비트 연산으로 만드는 정수·고정소수점 변환기
#
# 실행: python examples/ch31/num_format.py

import torch


def int_range(bits: int, signed: bool = True) -> tuple:
    """n비트 정수의 (최솟값, 최댓값). 부호 있는 정수는 2의 보수."""
    return (-(1 << (bits - 1)), (1 << (bits - 1)) - 1) if signed else (0, (1 << bits) - 1)


def to_bits(value: int, bits: int) -> str:
    """정수를 n비트 2의 보수 비트열로. 음수는 2ⁿ을 더한 것과 같다."""
    lo, hi = int_range(bits)
    if not lo <= value <= hi:
        raise OverflowError(f"{value}는 {bits}비트 범위 [{lo}, {hi}] 밖")
    return format(value & ((1 << bits) - 1), f"0{bits}b")


def from_bits(pattern: str, signed: bool = True) -> int:
    """비트열을 정수로. 부호 있는 정수는 맨 앞 비트가 −2ⁿ⁻¹의 자리값을 가진다."""
    u = int(pattern, 2)
    return u - (1 << len(pattern)) if signed and pattern[0] == "1" else u


def wrap(value: int, bits: int) -> int:
    """Overflow: 범위를 넘으면 반대쪽 끝으로 돌아간다(정수 하드웨어의 기본 동작)."""
    return from_bits(format(value & ((1 << bits) - 1), f"0{bits}b"))


def saturate(value: int, bits: int) -> int:
    """Saturation: 범위를 넘으면 가장 가까운 끝값에 머문다."""
    lo, hi = int_range(bits)
    return max(lo, min(hi, value))


def round_half_even(x: float) -> int:
    """반올림(짝수 쪽으로): 정확히 .5일 때 짝수를 고른다. Python round()와 IEEE 754 기본값."""
    return round(x)


def round_half_away(x: float) -> int:
    """반올림(0에서 먼 쪽으로): 학교에서 배우는 사사오입"""
    return int(x + 0.5) if x >= 0 else -int(-x + 0.5)


def to_fixed(x: float, int_bits: int, frac_bits: int) -> int:
    """실수 → Qm.n 고정소수점 정수 코드(전체 비트 = 1 + m + n, 반올림 후 Saturation)"""
    return saturate(round_half_even(x * (1 << frac_bits)), 1 + int_bits + frac_bits)


def from_fixed(code: int, frac_bits: int) -> float:
    return code / (1 << frac_bits)


def main() -> None:
    print("── 1. 같은 8비트, 다른 해석 ──")
    for pattern in ("00000101", "01111111", "10000000", "11111111"):
        print(f"  {pattern}: 부호 없음 {from_bits(pattern, False):>4}, 부호 있음(2의 보수) {from_bits(pattern):>5}")
    print(f"  −5 = {to_bits(-5, 8)}  (5 = {to_bits(5, 8)}을 뒤집고 1 더하기)")

    print("\n── 2. 비트 폭과 표현 범위 ──")
    for bits in (4, 8, 16, 32):
        lo, hi = int_range(bits)
        print(f"  INT{bits:<3}[{lo:>14,}, {hi:>13,}]  값 {1 << bits:,}가지")

    print("\n── 3. Q Format 고정소수점(8비트) ──")
    for m, n in ((0, 7), (3, 4)):
        step = 1 / (1 << n)
        lo, hi = int_range(1 + m + n)
        print(f"  Q{m}.{n}: 간격 {step:g}, 범위 [{from_fixed(lo, n)}, {from_fixed(hi, n)}]")
        for x in (0.3, -0.71, 1.5):
            code = to_fixed(x, m, n)
            print(f"    {x:>5} → 코드 {code:>4} ({to_bits(code, 8)}) → {from_fixed(code, n):>9.6f}, "
                  f"오차 {abs(from_fixed(code, n) - x):.5f}")

    print("\n── 4. Overflow, Saturation, Rounding ──")
    print(f"  INT8 127 + 1: 감싸기 {wrap(128, 8)}, 포화 {saturate(128, 8)}")
    t = torch.tensor([127], dtype=torch.int8)
    print(f"  PyTorch int8 텐서 127 + 1 = {(t + 1).item()}  (오류 없이 감싸기)")
    for x in (2.5, 3.5, -2.5, 2.4999):
        print(f"  {x:>7}: 짝수 쪽 {round_half_even(x):>3}, 0에서 먼 쪽 {round_half_away(x):>3}")


if __name__ == "__main__":
    main()
```

- **1번**에서 같은 비트 패턴 `10000000`이 부호 없이 읽으면 128, 2의 보수로 읽으면 −128입니다. −5는 5를 뒤집고 1을 더한 `11111011`입니다.

```python
# 제31장 검증 테스트
#
# 실행: python -m pytest examples/ch31 -q

import sys
from pathlib import Path

import pytest
import torch

sys.path.insert(0, str(Path(__file__).resolve().parent))

from num_format import (from_bits, from_fixed, int_range, round_half_away, round_half_even,  # noqa: E402
                        saturate, to_bits, to_fixed, wrap)


def test_ranges():
    assert int_range(8) == (-128, 127) and int_range(4) == (-8, 7)
    assert int_range(8, signed=False) == (0, 255)


@pytest.mark.parametrize("v", [-128, -1, 0, 1, 127])
def test_roundtrip_boundaries(v):
    assert from_bits(to_bits(v, 8)) == v


def test_overflow_raises_and_wraps_like_pytorch():
    with pytest.raises(OverflowError):
        to_bits(128, 8)
    assert wrap(128, 8) == -128 == (torch.tensor([127], dtype=torch.int8) + 1).item()
    assert wrap(-129, 8) == 127


def test_saturation():
    assert saturate(300, 8) == 127 and saturate(-300, 8) == -128 and saturate(5, 8) == 5


def test_fixed_point_q07_and_q34():
    assert to_fixed(0.3, 0, 7) == 38 and from_fixed(38, 7) == 0.296875
    assert to_fixed(1.5, 0, 7) == 127                    # 범위 밖 → 포화
    assert to_fixed(-1.0, 0, 7) == -128                  # 최솟값은 정확히 표현
    assert from_fixed(to_fixed(1.5, 3, 4), 4) == 1.5
    for x in (0.3, -0.71, 0.05):                         # 범위 안의 오차는 간격의 절반 이하
        assert abs(from_fixed(to_fixed(x, 0, 7), 7) - x) <= 0.5 / 128


def test_rounding_modes():
    assert [round_half_even(x) for x in (0.5, 1.5, 2.5, -2.5)] == [0, 2, 2, -2]
    assert [round_half_away(x) for x in (0.5, 1.5, 2.5, -2.5)] == [1, 2, 3, -3]
```

| 고정소수점 | Q0.7·Q3.4 코드값, 최솟값 −1.0 정확 표현, 범위 안 오차는 간격의 절반 이하 | 통과 |
| 반올림 | 0.5, 1.5, 2.5, −2.5에서 두 규칙의 결과 | 통과 |

이 장의 실습은 장치와 관계없이 같은 결과가 나오므로, CPU와 GT 1030 경로 모두 위 결과가 기준입니다.

**완료 기준:** −100을 8비트 2의 보수로 손으로 바꾼 뒤 `to_bits()`로 확인하고, Qwen2.5 가중치의 대부분이 −0.2 ~ 0.2에 있다면(제33장에서 확인) Q0.7과 Q3.4 중 어느 쪽이 맞는지 이유와 함께 적으며, 테스트 10개를 모두 통과하면 이 장을 마친 것입니다.

## 핵심 정리

- 같은 비트 패턴도 약속에 따라 다른 수가 됩니다. 2의 보수는 맨 앞 비트를 −2ⁿ⁻¹로 읽어, 덧셈 회로 하나로 음수까지 계산합니다.
- 부호 있는 n비트 정수는 −2ⁿ⁻¹ ~ 2ⁿ⁻¹ − 1, 2ⁿ가지 값을 표현합니다. INT8은 256가지, INT4는 16가지입니다.
- 고정소수점 Qm.n은 소수점 위치를 약속해 정수로 실수를 표현합니다. 비트 수가 같으면 범위와 정밀도를 맞바꿔야 합니다.
- 범위를 넘는 값은 감싸기 대신 포화시키고, 끝자리는 치우침이 없는 짝수 쪽 반올림을 기본으로 씁니다.

**다음 장 연결:** 고정소수점은 소수점이 고정되어 있어 아주 큰 수와 아주 작은 수를 함께 다루기 어렵습니다. 제32장에서는 소수점이 "떠다니는" 부동소수점, FP32·FP16·BF16의 구조와 차이를 비트 단위로 분해합니다.
