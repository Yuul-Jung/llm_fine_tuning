## 장 개요

제46장에서 SFT 루프를 직접 만들었습니다. 실제 프로젝트에서는 같은 일을 TRL의 **SFTTrainer**로 하는 경우가 많습니다. 설정 몇 줄로 학습·검증·기록·저장이 모두 돌아가므로 편리하지만, 기본값 하나가 실험 전체를 바꿀 수 있습니다. 이 장의 실습에서 확인하듯, 지금 버전의 기본값은 BF16 연산을 켜고 Gradient Checkpointing도 켭니다.

이 장은 제46장의 코드 한 줄 한 줄을 SFTConfig 항목에 대응시키고, 같은 모델·데이터·설정으로 SFTTrainer를 실행해 두 손실 곡선을 비교합니다. 예전 자료에서 흔히 보는 API 중 이 버전에서 사라진 것을 확인해 사용 금지 목록을 만들고, 마지막으로 Qwen2.5-0.5B의 학습 전 기준값을 제43장 지표로 기록합니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | SFTTrainer의 설정은 직접 구현한 루프의 어디에 해당하며, 같은 조건이면 같은 결과가 나오는가 |
| 실습 결과물 | 설정 대응표, 기본값과 교재 설정 비교, 제거된 API 목록, 두 방식의 손실 비교, Qwen2.5 기준값 |
| 실습 파일 | `examples/ch47/`의 `sft_trainer.py`, `baseline.py`, `test_ch47.py`, `baseline.json` |
| 선수 장 | 제43장(평가 기준), 제46장(SFT 루프) |

```text
제46장 SFTDataset ─(labels → completion_mask)─▶ HF Dataset ─▶ SFTTrainer(SFTConfig, FP32)
   ─train()─▶ log_history ── 제46장 log.jsonl과 비교
Qwen2.5-0.5B ─제43장 네 지표─▶ baseline.json(학습 전 기준값, 이후 장의 비교 대상)
```

## SFTTrainer와 SFTConfig

SFTTrainer는 Transformers의 Trainer를 SFT에 맞게 넓힌 것이고, SFTConfig는 그 설정을 담는 객체입니다. 제46장의 코드는 거의 그대로 설정 항목 하나가 됩니다.

```text
제46장의 코드              SFTConfig 항목                    이 장의 값
묶음 크기                  per_device_train_batch_size       4
Gradient 누적              gradient_accumulation_steps       2
학습 단계 수               max_steps                         30
AdamW 학습률·Weight Decay  learning_rate, weight_decay       1e-3, 0.1
Gradient Clipping          max_grad_norm                     1.0
Warmup 후 Cosine           lr_scheduler_type, warmup_steps   cosine, 6
최대 길이                  max_length                        256
질문 부분 -100             completion_only_loss              True
5단계마다 검증             eval_strategy, eval_steps         steps, 5
5단계마다 기록             logging_steps                     5
```

데이터는 제46장의 샘플을 그대로 넘깁니다. 이미 토큰화된 데이터(input_ids 열이 있는 데이터)를 받으면 SFTTrainer는 다시 토큰화하지 않고, completion_mask 열이 1인 자리만 학습합니다. 제45장의 labels에서 -100이 아닌 자리를 1로 바꾸면 이 열이 됩니다.

주의할 점이 있습니다. completion_only_loss의 기본값은 "데이터에 prompt와 completion 열이 있으면 켬"입니다. 토큰화된 데이터에는 그 열이 없으므로 **직접 True로 지정하지 않으면 질문까지 학습합니다.** 오류 없이 진행되므로 설정 파일에 반드시 적어 둡니다.

## 자료형 설정

| 항목 | 이 버전의 기본값 | 이 교재(CPU·GT 1030) |
|---|---|---|
| bf16 | 켜짐 | 끔 |
| fp16 | 꺼짐 | 끔 |
| Gradient Checkpointing | 켜짐 | 끔(제49장에서 필요할 때 켬) |

이 버전은 bf16이 기본으로 켜져 있어, GPU가 BF16을 지원하지 않으면 설정 객체를 만드는 순간 오류가 납니다. GT 1030(Pascal)은 BF16 연산을 지원하지 않고, FP16 혼합 정밀도도 이 GPU에서는 속도 이득 없이 Overflow 위험만 더합니다(제32장). 교재 검증 CPU는 BF16을 지원하지만, CPU와 GT 1030의 결과를 같은 기준으로 비교하려고 두 경로 모두 FP32로 통일합니다. 그래서 bf16과 fp16을 **명시적으로 끕니다.**

Gradient Checkpointing도 기본으로 켜져 있습니다. 메모리를 아끼는 대신 계산이 늘어나므로(제38장), 메모리가 충분한 이 장의 작은 모델에서는 끄고 제46장과 같은 조건을 맞춥니다.

## 버전별 API 변화

TRL과 Transformers는 빠르게 바뀝니다. 예전 블로그나 강의 자료의 코드를 그대로 쓰면 이름이 바뀐 항목에서 오류가 납니다. 이 장의 실습은 아래 다섯 이름이 이 버전에서 쓰이지 않음을 직접 확인합니다.

```text
예전 이름                          지금 쓰는 것
max_seq_length                     max_length
warmup_ratio                       warmup_steps(1보다 작은 실수는 비율로 읽음)
evaluation_strategy                eval_strategy
SFTTrainer(tokenizer=…)            SFTTrainer(processing_class=…)
DataCollatorForCompletionOnlyLM    completion_only_loss와 completion_mask 열
```

이 교재는 `requirements/cpu.txt`로 버전을 고정하고, 위 다섯 이름을 사용 금지 목록으로 둡니다. 버전을 올릴 때는 실습 2번처럼 기본값과 사라진 이름을 먼저 확인합니다.

## 기준 모델 평가

학습 결과가 좋은지 판단하려면 **학습 전 값**이 있어야 합니다. 제43장의 기준 파일은 도메인 PPL과 일반 PPL을 "학습 전보다 몇 %"로 정했으므로, 학습을 시작하기 전에 Qwen2.5-0.5B-Instruct의 네 지표를 재서 `baseline.json`에 남깁니다.

| 지표 | 재는 방법 | 학습 후에 볼 점 |
|---|---|---|
| 도메인 PPL | validation 6개, 답 부분, 토큰 가중(제46장 validate) | 20% 이상 내려갔는가 |
| 일반 PPL | 제21장 고정 eval 5블록 | 10% 넘게 오르지 않았는가 |
| 핵심어·형식 | test 6개를 Greedy, 최대 160토큰으로 생성 | 0.60, 0.80을 넘었는가 |

생성 설정은 Greedy(do_sample 끔)로 고정합니다. 무작위 샘플링을 쓰면 같은 모델도 실행마다 답이 달라 학습 전후를 비교할 수 없습니다. 측정 함수는 제48·49장에서 학습한 모델에도 그대로 씁니다.

## 핵심 실습 1: 직접 구현과 비교

파일명: `examples/ch47/sft_trainer.py`

```python
# 제47장 핵심 실습: 제46장과 같은 조건으로 TRL SFTTrainer를 실행해 두 결과를 비교한다
#
# 실행: python examples/ch47/sft_trainer.py   (제25장의 models/qwen2-tiny-pretrained 필요, CPU 약 3분)

import json
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parent / "ch46"))

import torch  # noqa: E402

from sft_loop import IGNORE, LOG, setup, validate  # noqa: E402      (제46장)

OUT = HERE / "trainer_log.json"

# 제46장의 코드 → SFTConfig 항목(같은 값)
SAME_AS_CH46 = {
    "per_device_train_batch_size": 4,     # loader(ds, batch=4)
    "gradient_accumulation_steps": 2,     # for _ in range(accum)
    "max_steps": 30,                      # steps
    "learning_rate": 1e-3,                # AdamW(lr)
    "weight_decay": 0.1,                  # AdamW(weight_decay)
    "max_grad_norm": 1.0,                 # clip_grad_norm_
    "lr_scheduler_type": "cosine",        # warmup_cosine
    "warmup_steps": 6,                    # warmup
    "max_length": 256,                    # build_example(max_len)
    "completion_only_loss": True,         # labels의 -100(completion_mask)
    "eval_strategy": "steps",             # 5단계마다 validate
    "eval_steps": 5,
    "logging_steps": 5,                   # log_every
    "per_device_eval_batch_size": 1,      # 검증은 샘플 하나씩
    "dataloader_drop_last": True,         # DataLoader(drop_last)
    "seed": 0,
    # CPU·GT 1030 경로: FP32. 이 버전의 기본값은 bf16 켜짐, Gradient Checkpointing 켜짐
    "bf16": False,
    "fp16": False,
    "gradient_checkpointing": False,
    "save_strategy": "no",
    "report_to": "none",
}


def to_hf_dataset(ds):
    """제45장의 labels를 TRL이 읽는 열로: -100이 아닌 자리 = completion_mask 1"""
    from datasets import Dataset
    return Dataset.from_list([{"input_ids": e["input_ids"],
                               "completion_mask": [int(t != IGNORE) for t in e["labels"]]} for e in ds.items])


def defaults() -> dict:
    from trl import SFTConfig
    c = SFTConfig(output_dir="/tmp/ch47_probe", use_cpu=True)
    return {k: getattr(getattr(c, k), "value", getattr(c, k)) for k in ("bf16", "fp16", "gradient_checkpointing", "learning_rate",
                                       "lr_scheduler_type", "per_device_train_batch_size", "max_length")}


def removed_names() -> list:
    """예전 자료에 흔한 이름이 이 버전에서 그대로 쓰이는지 확인한다"""
    import trl
    from trl import SFTConfig, SFTTrainer
    import inspect
    checks = []
    for key in ("max_seq_length", "warmup_ratio", "evaluation_strategy"):
        try:
            SFTConfig(output_dir="/tmp/ch47_probe", bf16=False, **{key: 1 if key != "evaluation_strategy" else "no"})
            checks.append((f"SFTConfig({key}=…)", "사용 가능"))
        except TypeError:
            checks.append((f"SFTConfig({key}=…)", "제거됨"))
    checks.append(("SFTTrainer(tokenizer=…)",
                   "사용 가능" if "tokenizer" in inspect.signature(SFTTrainer.__init__).parameters else "제거됨"))
    checks.append(("trl.DataCollatorForCompletionOnlyLM",
                   "사용 가능" if hasattr(trl, "DataCollatorForCompletionOnlyLM") else "제거됨"))
    return checks


def run_trainer(model, tok, tr, va, out_dir: str = "/tmp/ch47_run") -> list:
    from trl import SFTConfig, SFTTrainer
    args = SFTConfig(output_dir=out_dir, use_cpu=True, **SAME_AS_CH46)
    trainer = SFTTrainer(model=model, args=args, processing_class=tok,
                         train_dataset=to_hf_dataset(tr), eval_dataset=to_hf_dataset(va))
    trainer.train()
    return trainer.state.log_history


def main() -> None:
    import transformers
    import trl
    print(f"── 1. 버전과 기본값(TRL {trl.__version__}, Transformers {transformers.__version__}) ──")
    for k, v in defaults().items():
        print(f"  {k:<28}기본 {v!s:<8}→ 이 교재 {SAME_AS_CH46.get(k, v)}")

    print("\n── 2. 예전 API 확인 ──")
    for name, state in removed_names():
        print(f"  {name:<38}{state}")

    print("\n── 3. SFTTrainer로 30단계(제46장과 같은 모델·데이터·설정) ──")
    tok, model, tr, va = setup()
    logs = run_trainer(model, tok, tr, va)
    train = {r["step"]: r["loss"] for r in logs if "loss" in r}
    evals = {r["step"]: r["eval_loss"] for r in logs if "eval_loss" in r}
    ours = {r["step"]: r for r in map(json.loads, LOG.read_text().splitlines())}
    print("  단계  train(직접)  train(TRL)  val(직접)  val(TRL)")
    for s in sorted(evals):
        print(f"  {s:>4}  {ours[s]['train_loss']:>10.3f}  {train[s]:>10.3f}  {ours[s]['val_loss']:>9.3f}  {evals[s]:>8.3f}")
    v = validate(model, va)
    model.eval()
    with torch.no_grad():
        per = [model(input_ids=torch.tensor([e["input_ids"]]), labels=torch.tensor([e["labels"]])).loss.item()
               for e in va.items]
    print(f"  학습 후 같은 모델: 토큰 가중 평균 {v['val_loss']:.3f}(제46장 validate), "
          f"샘플 평균 {sum(per) / len(per):.3f}, TRL eval_loss {evals[30]:.3f}")
    OUT.write_text(json.dumps({"train": train, "eval": evals, "validate_token_weighted": v["val_loss"]},
                              indent=1) + "\n", encoding="utf-8")


if __name__ == "__main__":
    torch.manual_seed(0)
    main()
```

**결과 읽기**

- **1번**에서 기본값이 bf16 켜짐, Gradient Checkpointing 켜짐, 학습률 2e-5, Linear Scheduler입니다. 아무것도 지정하지 않으면 제46장과 전혀 다른 실험이 됩니다.
- **2번**에서 예전 이름 다섯 개가 모두 이 버전에서 사라졌습니다.
- **3번**에서 두 방식의 검증 손실은 8.3에서 6.2~6.4로 같은 모양으로 내려갑니다. 값이 정확히 같지 않은 데는 세 가지 이유가 있습니다. 데이터 순서를 정하는 난수가 다르고, Scheduler가 Warmup 첫 단계의 학습률을 계산하는 방식이 조금 다르며(제46장은 1/6부터, Trainer는 0부터), Trainer의 학습 손실은 기록 간격 5단계의 평균인 반면 제46장은 그 단계의 값입니다.
- 마지막 줄은 **검증 손실의 평균 방식**이 다르다는 것을 보여 줍니다. 학습을 마친 같은 모델에서 TRL의 eval_loss(6.371)는 샘플 평균과 같고, 제46장의 토큰 가중 평균(6.382)과는 다릅니다. 검증 묶음을 샘플 하나씩으로 두면 Trainer는 샘플별 손실을 평균합니다. 이 교재의 도메인 PPL은 토큰 가중 평균으로 정의했으므로, 기준 판정에는 Trainer의 값 대신 제46장 validate를 씁니다.

## 핵심 실습 2: 기준값 기록

파일명: `examples/ch47/baseline.py`

```python
# 제47장 실습 2: 학습 전에 Qwen2.5-0.5B-Instruct의 기준값을 제43장 지표로 기록한다
#
# 실행: python examples/ch47/baseline.py   (CPU 약 3분)
#
# 만드는 파일: examples/ch47/baseline.json

import json
import math
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
for p in (HERE.parent, HERE.parent / "ch25", HERE.parent / "ch43", HERE.parent / "ch44",
          HERE.parent / "ch45", HERE.parent / "ch46"):
    sys.path.insert(0, str(p))

import torch  # noqa: E402

from chat_template import render  # noqa: E402                 (제44장)
from common.fixed_data import load_blocks  # noqa: E402
from common.qwen import load_model, load_tokenizer  # noqa: E402
from criteria import format_ok, keyword_hit, load_criteria  # noqa: E402   (제43장)
from label_mask import chat  # noqa: E402                     (제45장)
from sft_loop import SFTDataset, split_rows, validate  # noqa: E402   (제46장)
from trainer import eval_loss  # noqa: E402                   (제25장)

OUT = HERE / "baseline.json"
GEN = {"max_new_tokens": 160, "do_sample": False}


def answer(tok, model, r: dict) -> str:
    text = render(tok, chat(r)[:2], gen=True)
    ids = tok(text, return_tensors="pt", add_special_tokens=False).input_ids
    with torch.no_grad():
        out = model.generate(ids, **GEN, pad_token_id=tok.pad_token_id)
    return tok.decode(out[0, ids.shape[1]:], skip_special_tokens=True).strip()


def measure(tok, model) -> dict:
    """제43장 기준 파일의 네 지표를 잰다(학습 전후에 같은 함수를 쓴다)"""
    c = load_criteria()
    va = SFTDataset(tok, split_rows("validation"))
    general = math.exp(eval_loss(model, load_blocks(tok, "eval"), "cpu"))
    max_s = c["metrics"]["format_ok"]["max_sentences"]
    answers = {r["id"]: answer(tok, model, r) for r in split_rows("test")}
    return {
        "domain_ppl": validate(model, va)["val_ppl"],
        "general_ppl": general,
        "keyword_hit": {i: keyword_hit(a, c["keywords"][i]) for i, a in answers.items()},
        "format_ok": {i: format_ok(a, max_s) for i, a in answers.items()},
        "answers": answers,
        "generation": GEN,
    }


def main() -> None:
    torch.manual_seed(0)
    tok, model = load_tokenizer(), load_model()
    m = measure(tok, model)
    OUT.write_text(json.dumps(m, ensure_ascii=False, indent=1) + "\n", encoding="utf-8")
    hits, fmts = list(m["keyword_hit"].values()), list(m["format_ok"].values())
    print("── Qwen2.5-0.5B-Instruct 기준값(학습 전) ──")
    print(f"  도메인 PPL(validation 답 부분)  {m['domain_ppl']:.2f}")
    print(f"  일반 PPL(고정 eval)            {m['general_ppl']:.2f}")
    print(f"  핵심어 적중률(test 평균)        {sum(hits) / len(hits):.2f}")
    print(f"  형식 준수율(test)               {sum(fmts) / len(fmts):.2f}")
    print("\n── test 답(앞부분) ──")
    for i, a in m["answers"].items():
        print(f"  {i}  핵심어 {m['keyword_hit'][i]:.2f}  형식 {m['format_ok'][i]!s:<5}  {a[:44].replace(chr(10), ' ')}…")
    c = load_criteria()["metrics"]
    print("\n── 학습 후 합격선(제43장 기준 파일) ──")
    print(f"  도메인 PPL ≤ {m['domain_ppl'] * c['domain_ppl']['max_ratio']:.2f}, "
          f"일반 PPL ≤ {m['general_ppl'] * c['general_ppl']['max_ratio']:.2f}, "
          f"핵심어 ≥ {c['keyword_hit']['min_mean']:.2f}, 형식 ≥ {c['format_ok']['min_rate']:.2f}")


if __name__ == "__main__":
    main()
```

## 핵심 정리

- SFTConfig의 항목은 제46장 루프의 코드와 하나씩 대응합니다. 대응표를 만들어 두면 라이브러리의 설정이 무엇을 하는지 알 수 있습니다.
- 토큰화된 데이터는 completion_mask 열로 학습 대상을 넘기며, completion_only_loss는 직접 True로 지정해야 합니다.
- 이 버전의 기본값은 bf16과 Gradient Checkpointing이 켜져 있습니다. CPU·GT 1030 경로에서는 FP32로 통일하고 두 옵션을 명시적으로 끕니다.
- max_seq_length, warmup_ratio, evaluation_strategy, tokenizer 인자, DataCollatorForCompletionOnlyLM은 이 버전에서 쓰지 않습니다.
- Trainer의 eval_loss는 샘플 평균이고, 이 교재의 도메인 PPL은 토큰 가중입니다. 기준값은 학습 전에 같은 측정 함수로 기록합니다.
