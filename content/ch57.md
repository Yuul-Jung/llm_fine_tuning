## 장 개요

학습한 모델을 다른 프로그램이 쓰게 하려면 **API**가 필요합니다. 웹 페이지, 업무 프로그램, 다른 언어로 만든 도구가 모두 같은 약속(HTTP 요청과 JSON 응답)으로 모델에게 질문하고 답을 받습니다. Ollama는 이런 API를 기본으로 제공하는 로컬 실행 도구입니다.

이 장은 Ollama API의 요청·응답 형식을 그대로 따르는 작은 로컬 서버를 직접 만들어, 제52장의 병합 모델을 API로 제공합니다. 그리고 대화 이력을 관리하고, 답을 조각 단위로 받으며(Streaming), Timeout·재시도·오류 응답을 처리하는 Python 클라이언트를 만듭니다. 같은 클라이언트는 실제 Ollama 서버(제56장)에도 주소만 바꿔 쓸 수 있습니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 로컬 모델을 API로 제공하고 쓸 때 요청·응답·Streaming·오류·접근 제어를 어떻게 다루는가 |
| 실습 결과물 | Ollama 형식의 로컬 서버(학습한 모델), 대화 이력 클라이언트, Streaming 수신, 오류·Timeout·재시도, 접근 차단 확인 |
| 실습 파일 | `examples/ch57/`의 `local_api.py`, `api_demo.py`, `test_ch57.py` |
| 선수 장 | 제44장(Chat Template, System 문구), 제52장(병합 모델) |

```text
클라이언트 ─POST /api/chat {model, messages, stream}─▶ 서버(127.0.0.1)
   ◀─ 한 줄에 JSON 하나: {"message": {"content": "조각"}, "done": false} … {"done": true}
서버: 템플릿 적용(제44장) → 병합 모델 Greedy 생성 → 조각마다 바로 전송
```

## HTTP와 REST API

HTTP는 요청과 응답을 주고받는 약속입니다. 클라이언트는 주소(경로)와 방법(GET, POST)을 정해 요청하고, 서버는 상태 코드와 본문으로 답합니다. **REST API**는 이 약속 위에서 자원마다 경로를 정하고, 본문을 JSON으로 주고받는 방식입니다.

| 상태 코드 | 뜻 | 클라이언트의 대응 |
|---|---|---|
| 200 | 성공 | 본문을 읽는다 |
| 400, 404 | 요청이 틀림(형식 오류, 없는 모델) | 다시 시도해도 같으므로 바로 오류를 알린다 |
| 500대 | 서버 쪽 문제 | 잠시 기다렸다 다시 시도할 수 있다 |

Ollama는 기본적으로 이 컴퓨터의 11434번 포트에서 API를 엽니다. 이 장의 서버는 같은 경로(/api/generate, /api/chat)와 같은 JSON 항목을 쓰되, 빈 포트를 골라 엽니다.

## Generate API와 Chat API

| API | 보내는 것 | 쓰임 |
|---|---|---|
| Generate | 질문 하나(prompt), 선택으로 System 문구 | 한 번 묻고 끝나는 요청 |
| Chat | 메시지 목록(system, user, assistant) | 이전 대화를 이어 가는 요청 |

서버는 이전 대화를 기억하지 않습니다. Chat API로 대화를 이어 가려면 **클라이언트가 이력을 들고 있다가 매번 전체를 보냅니다.** 이력이 길어지면 요청이 커지고 문맥 길이와 KV Cache(제58장)도 늘어나므로, 최근 몇 차례만 보내도록 잘라 냅니다. System 문구는 학습 때와 같은 것을 맨 앞에 매번 붙입니다(제44장: 빼면 기본 영어 문구가 들어가 학습 조건과 달라진다).

## Streaming과 오류 처리

긴 답을 다 만든 뒤 한 번에 보내면, 사용자는 생성이 끝날 때까지 아무것도 보지 못합니다. **Streaming**은 토큰이 만들어지는 대로 조각을 보내는 방식입니다. Ollama는 한 줄에 JSON 객체 하나를 쓰는 형식(NDJSON, 제42장의 JSONL과 같음)으로 조각을 보내고, 마지막 줄에 done을 참으로 표시합니다.

네트워크 너머의 호출은 언제든 실패할 수 있으므로 세 가지를 정합니다.

| 상황 | 처리 |
|---|---|
| 응답이 너무 늦음 | Timeout을 정해 기다림을 끊는다(Streaming은 조각 사이의 간격에 적용) |
| 연결 실패, 500대 | 기다리는 시간을 두 배씩 늘리며 정해진 횟수만 다시 시도한다 |
| 400대 | 다시 시도하지 않고 서버가 보낸 오류 문구를 그대로 알린다 |

## 접근 제어

Ollama의 API에는 **인증이 없습니다.** 주소에 접속할 수 있으면 누구나 모델을 쓰고, 모델을 지우거나 내려받게 할 수도 있습니다. 그래서 기본값은 이 컴퓨터 안에서만 접속할 수 있는 127.0.0.1입니다. 다른 컴퓨터에서 써야 한다면 0.0.0.0으로 바로 여는 대신, 방화벽으로 허용할 주소를 제한하거나, 인증을 붙인 리버스 프록시(Nginx 같은) 뒤에 둡니다. 이 장의 서버도 127.0.0.1에만 열고, 외부용 주소로는 접속되지 않음을 확인합니다.

## 핵심 실습

파일명: `examples/ch57/local_api.py`

```python
# 제57장: Ollama와 같은 형식의 로컬 API 서버(학습한 모델 제공)와, 대화 이력·Streaming·오류를 다루는 클라이언트
#
# 서버는 Ollama의 /api/generate, /api/chat 요청·응답 형식(JSON, 줄마다 JSON 하나인 Streaming)을 따른다.
# 같은 클라이언트를 실제 Ollama(기본 주소 http://127.0.0.1:11434)에 그대로 쓸 수 있다.

import json
import socket
import threading
import time
import urllib.error
import urllib.request
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer


# ── 서버 ──────────────────────────────────────────────────────────────

class EchoBackend:
    """테스트용: 마지막 사용자 말을 단어 단위로 되돌려준다(지연 시간 조절 가능)"""

    def __init__(self, name="echo", delay=0.0):
        self.name, self.delay = name, delay

    def stream(self, messages):
        for word in ("답: " + messages[-1]["content"]).split(" "):
            time.sleep(self.delay)
            yield word + " "


class HFBackend:
    """학습한 모델(제52장 병합 모델)을 Greedy로 생성하며 조각을 내보낸다"""

    def __init__(self, model_dir, name="fpga-qwen", max_new_tokens=120):
        from transformers import AutoModelForCausalLM, AutoTokenizer
        import torch
        self.torch, self.name, self.n = torch, name, max_new_tokens
        self.tok = AutoTokenizer.from_pretrained(model_dir)
        self.model = AutoModelForCausalLM.from_pretrained(model_dir, dtype=torch.float32).eval()

    def stream(self, messages):
        from transformers import TextIteratorStreamer
        text = self.tok.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
        ids = self.tok(text, return_tensors="pt", add_special_tokens=False).input_ids
        streamer = TextIteratorStreamer(self.tok, skip_prompt=True, skip_special_tokens=True)
        kw = dict(input_ids=ids, max_new_tokens=self.n, do_sample=False, streamer=streamer,
                  pad_token_id=self.tok.pad_token_id)
        threading.Thread(target=lambda: self.model.generate(**kw), daemon=True).start()
        yield from (piece for piece in streamer if piece)


def make_server(backend, host="127.0.0.1", port=0):
    """host 기본값 127.0.0.1: 이 컴퓨터 안에서만 접속할 수 있다(인증이 없으므로 외부에 열지 않는다)"""

    class Handler(BaseHTTPRequestHandler):
        def log_message(self, *args):                       # 요청마다 찍히는 기록 끔
            pass

        def reply(self, code, obj):
            body = json.dumps(obj, ensure_ascii=False).encode()
            self.send_response(code)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)

        def do_POST(self):
            try:
                req = json.loads(self.rfile.read(int(self.headers.get("Content-Length", 0))))
            except json.JSONDecodeError:
                return self.reply(400, {"error": "invalid JSON"})
            if self.path not in ("/api/generate", "/api/chat"):
                return self.reply(404, {"error": "not found"})
            if req.get("model") != backend.name:
                return self.reply(404, {"error": f"model '{req.get('model')}' not found"})
            chat = self.path == "/api/chat"
            if chat:
                messages = req.get("messages", [])
            else:                                            # generate: system 항목이 있으면 앞에 붙인다(Ollama와 같음)
                messages = ([{"role": "system", "content": req["system"]}] if req.get("system") else []) \
                    + [{"role": "user", "content": req.get("prompt", "")}]

            def chunk(text, done):
                obj = {"model": backend.name, "done": done}
                if chat:
                    obj["message"] = {"role": "assistant", "content": text}
                else:
                    obj["response"] = text
                return obj

            if not req.get("stream", True):
                return self.reply(200, chunk("".join(backend.stream(messages)), True))
            self.send_response(200)
            self.send_header("Content-Type", "application/x-ndjson")
            self.end_headers()
            for piece in backend.stream(messages):           # 한 줄에 JSON 하나(NDJSON)
                self.wfile.write((json.dumps(chunk(piece, False), ensure_ascii=False) + "\n").encode())
                self.wfile.flush()
            self.wfile.write((json.dumps(chunk("", True)) + "\n").encode())

    server = ThreadingHTTPServer((host, port), Handler)
    threading.Thread(target=server.serve_forever, daemon=True).start()
    return server


# ── 클라이언트 ────────────────────────────────────────────────────────

class APIError(Exception):
    pass


class Client:
    def __init__(self, base_url="http://127.0.0.1:11434", model="fpga-qwen", timeout=60.0, retries=2):
        self.base, self.model, self.timeout, self.retries = base_url, model, timeout, retries

    def _open(self, path, payload):
        """연결 실패·5xx는 잠시 기다렸다 다시 시도, 4xx는 요청이 틀린 것이므로 바로 오류"""
        data = json.dumps(payload).encode()
        for attempt in range(self.retries + 1):
            req = urllib.request.Request(self.base + path, data=data, headers={"Content-Type": "application/json"})
            try:
                return urllib.request.urlopen(req, timeout=self.timeout)
            except urllib.error.HTTPError as e:
                msg = json.loads(e.read() or b"{}").get("error", e.reason)
                if e.code < 500 or attempt == self.retries:
                    raise APIError(f"HTTP {e.code}: {msg}") from None
            except (urllib.error.URLError, ConnectionError) as e:
                if attempt == self.retries:
                    raise APIError(f"연결 실패({self.retries + 1}회 시도): {e}") from None
            time.sleep(0.2 * 2 ** attempt)                          # 0.2초, 0.4초 … 지수적으로 늘림

    def generate(self, prompt, system=None):
        payload = {"model": self.model, "prompt": prompt, "stream": False}
        if system:
            payload["system"] = system
        with self._open("/api/generate", payload) as r:
            return json.loads(r.read())["response"]

    def chat_stream(self, messages):
        """조각을 차례로 돌려준다. 조각 사이가 timeout보다 길면 socket.timeout"""
        with self._open("/api/chat", {"model": self.model, "messages": messages, "stream": True}) as r:
            for line in r:
                obj = json.loads(line)
                if obj["done"]:
                    return
                yield obj["message"]["content"]


class Conversation:
    """대화 이력을 들고 있다가 매번 전체를 보낸다(서버는 이전 대화를 기억하지 않는다)"""

    def __init__(self, client, system, max_turns=4):
        self.client, self.system, self.max_turns, self.turns = client, system, max_turns, []

    def ask(self, text, on_piece=None):
        self.turns.append({"role": "user", "content": text})
        messages = [{"role": "system", "content": self.system}] + self.turns[-(2 * self.max_turns - 1):]
        pieces = []
        for p in self.client.chat_stream(messages):
            pieces.append(p)
            if on_piece:
                on_piece(p)
        answer = "".join(pieces)
        self.turns.append({"role": "assistant", "content": answer})
        return answer, len(pieces), len(messages)


def reachable(host, port, timeout=0.5) -> bool:
    try:
        with socket.create_connection((host, port), timeout=timeout):
            return True
    except OSError:
        return False
```

```python
# 제57장 핵심 실습: 학습한 모델을 로컬 API로 띄우고, 대화 이력·Streaming·오류·접근 제어를 확인한다
#
# 실행: python examples/ch57/api_demo.py   (제52장의 병합 모델 필요, CPU 약 1분)

import socket
import sys
import time
from pathlib import Path

HERE = Path(__file__).resolve().parent
ROOT = HERE.parents[1]
for p in (HERE, HERE.parent / "ch44"):
    sys.path.insert(0, str(p))

from chat_template import SYSTEM  # noqa: E402                   (제44장, 학습 때의 System 문구)
from local_api import APIError, Client, Conversation, EchoBackend, HFBackend, make_server, reachable  # noqa: E402

MERGED = ROOT / "models" / "fpga_merged_v1"                      # 제52장


def lan_address():
    """이 컴퓨터의 외부용 주소(없으면 None). 패킷은 보내지 않는다."""
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        s.connect(("10.255.255.255", 1))
        ip = s.getsockname()[0]
        return None if ip.startswith("127.") else ip
    except OSError:
        return None
    finally:
        s.close()


def main() -> None:
    print("── 1. 서버 시작(학습한 병합 모델, 127.0.0.1) ──")
    server = make_server(HFBackend(MERGED))
    host, port = server.server_address
    client = Client(f"http://{host}:{port}", model="fpga-qwen")
    print(f"  주소 http://{host}:<port>, 모델 이름 fpga-qwen")

    print("\n── 2. Generate API(한 번에 받기) ──")
    print(f"  {client.generate('FPGA의 LUT는 어떤 역할을 하나요?', system=SYSTEM)[:70]}…")

    print("\n── 3. Chat API + Streaming, 대화 이력 ──")
    conv = Conversation(client, SYSTEM)
    for q in ("블로킹 할당과 논블로킹 할당은 언제 쓰나요?", "그럼 조합 논리에서는 어느 쪽을 쓰나요?"):
        answer, n, sent = conv.ask(q)
        print(f"  질문: {q}\n  답({n}조각, 보낸 메시지 {sent}개): {answer[:70]}…")
    print(f"  이력에 쌓인 메시지 {len(conv.turns)}개(사용자 2 + 모델 2), 매 요청마다 System과 함께 다시 보냄")
    server.shutdown()

    print("\n── 4. 오류 처리 ──")
    echo = make_server(EchoBackend(delay=1.0))
    url = f"http://127.0.0.1:{echo.server_address[1]}"
    try:
        Client(url, model="없는-모델").generate("안녕")
    except APIError as e:
        print(f"  없는 모델: {e}(4xx는 다시 시도하지 않음)")
    try:
        list(Client(url, model="echo", timeout=0.3).chat_stream([{"role": "user", "content": "느린 응답"}]))
    except (TimeoutError, socket.timeout):
        print("  Timeout: 조각 사이 1초 > 기다림 0.3초 → 시간 초과로 중단")
    echo.shutdown()
    echo.server_close()
    t0 = time.time()
    try:
        Client(url, model="echo", retries=2).generate("안녕")
    except APIError as e:
        print(f"  서버 꺼짐: {str(e)[:22]}… {time.time() - t0:.1f}초(0.2 + 0.4초 기다리며 재시도)")

    print("\n── 5. 접근 제어 ──")
    srv = make_server(EchoBackend())
    port = srv.server_address[1]
    lan = lan_address()
    print(f"  127.0.0.1로 접속: {reachable('127.0.0.1', port)}")
    if lan:
        print(f"  이 컴퓨터의 외부용 주소로 접속: {reachable(lan, port)}(127.0.0.1에만 열었으므로 차단)")
    else:
        print("  외부용 주소가 없는 환경(확인 생략)")
    srv.shutdown()


if __name__ == "__main__":
    main()
```

```text
  이 컴퓨터의 외부용 주소로 접속: False(127.0.0.1에만 열었으므로 차단)
```

**결과 읽기**

- **1·2번**에서 병합 모델을 Ollama 형식의 API로 띄우고, Generate API로 질문 하나에 답을 받았습니다. 학습 때와 같은 System 문구를 함께 보냈습니다.
- **3번**에서 Chat API로 두 차례 대화했습니다. 첫 요청은 메시지 2개(System, 질문), 둘째 요청은 4개(System, 첫 질문, 첫 답, 둘째 질문)를 보냈습니다. 서버는 이전 대화를 모르므로 이력을 보내야 "그럼"이 무엇을 가리키는지 알 수 있습니다. 답은 약 100개의 조각으로 나뉘어 도착했습니다.
- 답의 **내용은 틀립니다.** 블로킹 할당을 "모든 연산자를 동시에 실행"한다고 설명하는데, 이 질문은 학습 데이터(fpga-012)에 있던 것입니다. 제50장에서 배포 후보로 채택하지 않은 모델이므로, 이 장의 목적은 API 구조를 익히는 것이지 답의 품질이 아닙니다.
- **4번**에서 없는 모델 이름은 404로 바로 실패하고, 조각 사이가 1초인 느린 응답은 0.3초 Timeout으로 끊기며, 꺼진 서버에는 0.2초와 0.4초를 기다리며 세 번 시도한 뒤(약 0.6초) 실패를 알립니다.
- **5번**에서 127.0.0.1로는 접속되고, 같은 컴퓨터의 외부용 주소로는 접속되지 않습니다.

```python
    with pytest.raises((TimeoutError, socket.timeout)):
        list(Client(url(s), model="echo", timeout=0.2).chat_stream([{"role": "user", "content": "a b"}]))

def test_retry_when_server_down():
    s = make_server(EchoBackend())
    u = url(s)
    s.shutdown()
    s.server_close()
    t0 = time.time()
    with pytest.raises(APIError, match="3회"):
        Client(u, model="echo", retries=2).generate("x")
```

## 핵심 정리

- REST API는 경로와 방법으로 요청하고 상태 코드와 JSON으로 답합니다. 4xx는 요청 오류라 재시도하지 않고, 연결 실패와 5xx는 기다리며 다시 시도합니다.
- Generate API는 한 번의 질문, Chat API는 메시지 목록입니다. 서버는 대화를 기억하지 않으므로 클라이언트가 이력을 보내며, 학습 때의 System 문구를 함께 보냅니다.
- Streaming은 한 줄에 JSON 하나(NDJSON)로 조각을 보내고 마지막 줄에 끝을 표시합니다. Timeout은 조각 사이 간격에 적용됩니다.
- Ollama API에는 인증이 없습니다. 127.0.0.1에만 열고, 외부에 열려면 방화벽이나 인증을 붙인 리버스 프록시 뒤에 둡니다.
