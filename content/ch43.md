## 장 개요

제42장에서 데이터를 무작위로 나누었더니 분류별 개수가 고르지 않았고, 코드가 들어간 문항은 모두 train에 몰렸습니다. 더 큰 문제는 눈에 보이지 않습니다. 같은 내용을 조금 바꿔 쓴 문항이 train과 test에 함께 들어가면, 모델은 답을 **외워서** 맞히고 평가 점수는 실력보다 높게 나옵니다.

이 장은 학습 전에 데이터를 정리하는 네 단계를 실행합니다. 결측과 정확한 중복을 지우고, 글자 N-gram과 문장 임베딩으로 비슷한 문항을 찾아 같은 그룹으로 묶고, 그룹 단위로 나누어 누출이 없는지 확인합니다. 마지막으로 이후 장의 학습 결과를 판정할 **평가 지표와 합격 기준을 실험 전에 파일로 적어 둡니다.**

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 평가 점수가 외운 결과가 아니라 실력임을 어떻게 보장하고, 무엇을 합격으로 볼지 언제 정하는가 |
| 실습 결과물 | 중복·유사 후보 목록, 분류별 균형 그룹 분할(38/6/6), 누출 검사 결과, 합격 기준 파일 |
| 실습 파일 | `examples/ch43/`의 `clean_split.py`, `criteria.py`, `test_ch43.py`, `configs/eval_criteria.yaml` |
| 선수 장 | 제41장(데이터 원본), 제42장(분할), 제22장(Perplexity) |

```text
원본 50개 ─결측·해시 중복 제거─▶ 3-gram·임베딩 유사 후보 ─Union-Find─▶ 그룹
   ─분류별 그룹 분할(seed 0)─▶ split_v1.json ─누출 검사─▶ 확정
   eval_criteria.yaml(지표·기준) ── 학습 전에 확정, 결과를 본 뒤 고치지 않음
```

## 결측·오류·중복 제거

정리의 첫 단계는 기계적으로 판정할 수 있는 문제부터 지우는 것입니다. 질문이나 답이 비어 있는 샘플, 필드가 빠진 샘플은 제41장의 검사로 이미 걸렀습니다.

**정확한 중복**은 해시(Hash)로 찾습니다. 문장을 그대로 해시하면 띄어쓰기 하나, 물음표 하나만 달라도 다른 값이 나오므로, 먼저 **정규화(Normalization)** 로 공백·문장부호·대소문자 차이를 지운 뒤 해시합니다. 정규화가 같은 두 문장은 해시가 같으므로, 수만 개의 샘플에서도 사전(Dictionary) 하나로 한 번에 중복을 찾습니다.

**거의 같은 문장**은 해시로 찾을 수 없습니다. 이때는 문장을 연속한 글자 세 개(3-gram)의 집합으로 바꾸고 두 집합이 얼마나 겹치는지 **Jaccard 유사도**(교집합 크기 ÷ 합집합 크기)로 잽니다. 한국어는 조사와 어미가 붙어 단어 단위로 자르면 같은 말도 다른 단어가 되므로, 글자 단위 N-gram이 더 잘 맞습니다. 이 장은 0.5 이상을 유사 후보로 봅니다.

## 문장 임베딩 유사도

N-gram은 **같은 글자를 쓴** 문장만 찾습니다. "LUT는 어떤 역할을 하나요?"와 "룩업 테이블이 하는 일은?"처럼 뜻이 같고 글자가 다른 문장은 놓칩니다. 이를 찾으려면 문장을 **의미를 담은 벡터**로 바꿔 비교해야 합니다.

| 방식 | 비교 대상 | 장점과 한계 |
|---|---|---|
| 토큰 임베딩 | 토큰마다 하나인 입력 벡터 | 문맥이 없다. 문장 비교에는 부족하다 |
| 문장 임베딩 | 모델을 통과한 hidden state의 평균 | 문맥이 반영된다. 모델이 의미보다 형식을 볼 때가 있다 |

이 장은 Qwen2.5-0.5B의 마지막 hidden state를 토큰 위치에 걸쳐 평균(Mean Pooling)해 문장 벡터로 쓰고, 코사인 유사도를 잽니다. 모든 문장 벡터에 공통으로 들어 있는 성분이 커서 그대로 비교하면 모든 쌍이 비슷해 보이므로, 전체 평균을 먼저 뺍니다. 문장 비교 전용으로 학습한 임베딩 모델이 더 정확하지만, 이 교재는 새 모델을 내려받지 않고 이미 있는 모델로 원리를 확인합니다.

임베딩 유사도는 **후보를 좁히는 도구**입니다. 실습에서 보듯 높은 점수가 나온 쌍이 실제로는 다른 주제일 수 있습니다. 최종 판단은 사람이 후보를 읽고 내립니다. 판단이 애매하면 같은 그룹으로 묶는 쪽이 안전합니다. 다른 주제를 같은 그룹으로 묶으면 분할이 조금 덜 고르게 될 뿐이지만, 같은 주제를 갈라 놓으면 누출이 생기기 때문입니다.

## 분할과 데이터 누출

**데이터 누출(Data Leakage)** 은 평가 데이터의 정보가 학습에 섞여 들어가는 것입니다. 같은 문항이 그대로 들어가는 경우는 드물고, 대개는 같은 내용을 조금 바꾼 문항, 같은 코드 조각을 쓴 문항이 train과 test에 나뉘어 들어갑니다. 그러면 test 점수는 "처음 보는 질문에 답하는 능력"이 아니라 "본 적 있는 내용을 기억하는 능력"을 잽니다.

막는 방법은 **그룹 단위 분할**입니다. 유사 후보 쌍을 이어 그룹을 만들고(Union-Find: 쌍마다 두 원소의 대표를 하나로 합친다), 그룹 전체를 한 분할에 넣습니다. 이 장은 여기에 **분류별 층화(Stratification)** 를 더해, 여섯 분류마다 test 1개와 validation 1개를 뽑습니다.

| 분할 | 크기 | 뽑는 방법 |
|---|---|---|
| test | 6 | 분류마다 그룹 하나(크기 1)를 seed 0으로 뽑는다 |
| validation | 6 | 남은 그룹에서 같은 방법으로 하나씩 |
| train | 38 | 나머지 전부(크기 2 이상인 그룹은 여기에 둔다) |

분할을 마친 뒤에는 **누출 검사**를 합니다. test와 validation 문항마다 train에서 가장 비슷한 문항을 찾아 유사도를 적고, 가장 높은 값이 기준(0.5) 아래인지 확인합니다. 분할 결과는 `datasets/fpga_qa/split_v1.json`에 id 목록으로 저장해, 이후 모든 장이 같은 분할을 씁니다.

## 평가 지표 정의

무엇을 재는지 정하지 않으면 학습이 잘 되었는지 판단할 수 없습니다. 도메인 파인튜닝의 목표는 "도메인 질문에 정확하고 원하는 형식으로 답하면서, 원래 능력은 잃지 않는 것"이므로 지표도 이 세 방향을 모두 봅니다.

| 지표 | 무엇을 재는가 | 한계 |
|---|---|---|
| 도메인 PPL | validation 답 부분을 얼마나 잘 예측하는가 | 낮아도 답이 틀릴 수 있다 |
| 핵심어 적중률 | test 답에 정답의 핵심어가 들어 있는가 | 문장이 틀려도 단어만 맞으면 오른다 |
| 형식 준수율 | 존댓말 평서문으로 끝나고 4문장 이하인가 | 내용과는 무관하다 |
| 일반 PPL | 일반 문장(제21장 고정 eval)을 여전히 잘 예측하는가 | 일반 능력의 일부만 본다 |

정답 문장과 글자까지 같아야 맞는 **완전 일치(Exact Match)** 는 서술형 답에 너무 엄격해 쓰지 않습니다. 대신 문항마다 정답에서 꼭 들어가야 할 핵심어를 사람이 골라 두고, 그중 몇 개가 답에 있는지 셉니다. 사람이 기준표(Rubric)로 점수를 매기는 평가가 가장 정확하지만 비용이 크므로, 이 교재는 자동 지표로 걸러 낸 뒤 마지막 장들에서 답을 직접 읽어 확인합니다.

모든 지표에는 한계가 있습니다. 그래서 하나만 보지 않고 네 지표를 함께 보며, 하나라도 기준을 넘지 못하면 그 이유를 찾습니다.

## 합격 기준 사전 기록

지표와 기준은 **학습을 시작하기 전에** 정해 파일로 남깁니다. 결과를 본 뒤 기준을 정하면, 의도하지 않아도 결과에 맞는 기준을 고르게 됩니다. 핵심어 적중률이 0.55로 나온 뒤에 "0.5면 충분하다"고 정하는 식입니다. 이를 막는 가장 간단한 방법이 기준을 먼저 적고 버전 관리에 넣어 두는 것입니다.

이 교재의 기준 파일은 `configs/eval_criteria.yaml`입니다. 지표마다 정의와 합격선을 적고, test 문항의 핵심어 목록을 함께 둡니다. 기준을 고쳐야 할 이유가 생기면 파일을 덮어쓰지 않고 version을 올리고 고친 이유를 남깁니다. 제44장 이후의 모든 학습 결과는 이 파일로 판정합니다.

## 핵심 실습 1: 정리와 그룹 분할

```python
# 제43장 핵심 실습: 중복·유사 검출 → 그룹 분할 → 누출 검사를 순서대로 실행한다
#
# 실행: python examples/ch43/clean_split.py
#
# 만드는 파일: datasets/fpga_qa/split_v1.json(분할 목록, 저장소에 포함)

import hashlib
import json
import random
import re
import sys
from itertools import combinations
from pathlib import Path

HERE = Path(__file__).resolve().parent
ROOT = HERE.parents[1]
for p in (HERE.parent, HERE.parent / "ch41"):
    sys.path.insert(0, str(p))

import torch  # noqa: E402

from check_dataset import load  # noqa: E402            (제41장)

SPLIT = ROOT / "datasets" / "fpga_qa" / "split_v1.json"
NGRAM_T, EMB_T, SEED = 0.5, 0.92, 0


def normalize(s: str) -> str:
    """공백·문장부호·대소문자 차이를 지운다."""
    return re.sub(r"[\s\.,!?·()\[\]\"'“”‘’:;]", "", s).lower()


def text_hash(s: str) -> str:
    return hashlib.sha256(normalize(s).encode()).hexdigest()[:12]


def ngrams(s: str, n: int = 3) -> set:
    s = normalize(s)
    return {s[i:i + n] for i in range(max(1, len(s) - n + 1))}


def jaccard(a: set, b: set) -> float:
    return len(a & b) / len(a | b)


def sentence_embeddings(texts: list) -> torch.Tensor:
    """Qwen2.5의 마지막 hidden state를 토큰 평균(mean pooling)해 문장 벡터로 쓴다."""
    from common.qwen import load_model, load_tokenizer
    tok, model = load_tokenizer(), load_model()
    vecs = []
    with torch.no_grad():
        for t in texts:
            ids = tok(t, return_tensors="pt").input_ids
            h = model(ids, output_hidden_states=True).hidden_states[-1][0]
            vecs.append(h.mean(dim=0))
    v = torch.stack(vecs)
    return torch.nn.functional.normalize(v - v.mean(dim=0), dim=-1)   # 평균을 빼 공통 성분 제거


def groups_from_pairs(ids: list, pairs: list) -> dict:
    """유사 쌍을 이어 같은 그룹으로 묶는다(Union-Find)."""
    parent = {i: i for i in ids}

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    for a, b in pairs:
        parent[find(a)] = find(b)
    return {i: find(i) for i in ids}


def group_split(rows: list, group: dict, per_cat: int = 1, seed: int = SEED) -> dict:
    """분류마다 그룹 단위로 test 1개, validation 1개를 뽑고 나머지는 train(같은 그룹은 같은 분할)."""
    rng = random.Random(seed)
    split = {}
    for cat in sorted({r["category"] for r in rows}):
        gids = sorted({group[r["id"]] for r in rows if r["category"] == cat})
        rng.shuffle(gids)
        for g in gids:
            members = [r["id"] for r in rows if group[r["id"]] == g]
            name = "train"
            for s in ("test", "validation"):
                cat_n = sum(1 for r in rows if r["category"] == cat and split.get(r["id"]) == s)
                if cat_n < per_cat and len(members) <= per_cat:
                    name = s
                    break
            for m in members:
                split.setdefault(m, name)
    return split


def main() -> None:
    rows = load()
    ids = [r["id"] for r in rows]
    text = {r["id"]: r["instruction"] + " " + r["input"] for r in rows}

    print("── 1. 결측·오류·정확한 중복(정규화 후 해시) ──")
    empty = [r["id"] for r in rows if not r["output"].strip() or not r["instruction"].strip()]
    hashes = {}
    for r in rows:
        hashes.setdefault(text_hash(text[r["id"]]), []).append(r["id"])
    dups = [v for v in hashes.values() if len(v) > 1]
    print(f"  결측 {len(empty)}건, 정확한 중복 {len(dups)}건")
    probe = dict(rows[2], id="probe", instruction=rows[2]["instruction"].replace("?", " ?  "))
    print(f"  검출 시험: 띄어쓰기만 바꾼 사본의 해시 같음 {text_hash(probe['instruction']) == text_hash(rows[2]['instruction'])}")

    print(f"\n── 2. 유사 후보: 글자 3-gram Jaccard ≥ {NGRAM_T} ──")
    grams = {i: ngrams(text[i]) for i in ids}
    ng_pairs = [(a, b, jaccard(grams[a], grams[b])) for a, b in combinations(ids, 2)]
    ng_pairs = sorted([p for p in ng_pairs if p[2] >= NGRAM_T], key=lambda p: -p[2])
    for a, b, s in ng_pairs:
        print(f"  {s:.2f}  {a} / {b}  {text[a][:22]} | {text[b][:22]}")
    print(f"  후보 {len(ng_pairs)}쌍")
    copy = text[ids[2]] + " 예를 들어 설명해 주세요."
    print(f"  검출 시험: 요청 한 문장을 덧붙인 사본과의 유사도 {jaccard(grams[ids[2]], ngrams(copy)):.2f}")

    print(f"\n── 3. 유사 후보: 문장 임베딩 코사인 ≥ {EMB_T}(Qwen2.5 평균 풀링) ──")
    emb = sentence_embeddings([text[i] for i in ids])
    sim = emb @ emb.T
    em_pairs = sorted([(ids[a], ids[b], sim[a, b].item()) for a, b in combinations(range(len(ids)), 2)
                       if sim[a, b] >= EMB_T], key=lambda p: -p[2])
    for a, b, s in em_pairs:
        print(f"  {s:.3f}  {a} / {b}  {text[a][:22]} | {text[b][:22]}")
    print(f"  후보 {len(em_pairs)}쌍(사람이 검토해 같은 주제면 같은 그룹으로 묶는다)")

    print("\n── 4. 그룹 분할(분류마다 test 1, validation 1) ──")
    group = groups_from_pairs(ids, [(a, b) for a, b, _ in ng_pairs + em_pairs])
    sizes = sorted((sum(1 for v in group.values() if v == g) for g in set(group.values())), reverse=True)
    print(f"  그룹 {len(set(group.values()))}개, 2개 이상인 그룹 크기 {[s for s in sizes if s > 1]}")
    split = group_split(rows, group)
    for s in ("train", "validation", "test"):
        members = [i for i in ids if split[i] == s]
        print(f"  {s:<11}{len(members):>3}개  " + (str(members) if s != "train" else ""))
    SPLIT.write_text(json.dumps({"seed": SEED, "ngram_threshold": NGRAM_T, "embedding_threshold": EMB_T,
                                 "split": split}, ensure_ascii=False, indent=1) + "\n", encoding="utf-8")

    print("\n── 5. 누출 검사: test·validation 각 문항과 가장 비슷한 train 문항 ──")
    train_ids = [i for i in ids if split[i] == "train"]
    worst = 0.0
    for i in [i for i in ids if split[i] != "train"]:
        best = max(train_ids, key=lambda t: jaccard(grams[i], grams[t]))
        e = sim[ids.index(i), ids.index(best)].item()
        worst = max(worst, jaccard(grams[i], grams[best]))
        print(f"  {i}({split[i][:4]}) ↔ {best}: 3-gram {jaccard(grams[i], grams[best]):.2f}, 임베딩 {e:.3f}")
    print(f"  최대 3-gram 유사도 {worst:.2f} < 기준 {NGRAM_T}: {worst < NGRAM_T}")


if __name__ == "__main__":
    main()
```

```python
# 제43장 실습 2: 미리 적은 합격 기준을 읽고, 채점 함수를 정답과 나쁜 답으로 시험한다
#
# 실행: python examples/ch43/criteria.py

import json
import re
from pathlib import Path

import yaml

ROOT = Path(__file__).resolve().parents[2]
CRITERIA = ROOT / "configs" / "eval_criteria.yaml"


def load_criteria(path: Path = CRITERIA) -> dict:
    c = yaml.safe_load(path.read_text(encoding="utf-8"))
    assert {"domain_ppl", "keyword_hit", "format_ok", "general_ppl"} <= set(c["metrics"])
    return c


def keyword_hit(answer: str, keywords: list) -> float:
    a = answer.replace(" ", "").lower()
    return sum(k.replace(" ", "").lower() in a for k in keywords) / len(keywords)


def sentences(answer: str) -> list:
    return [s for s in re.split(r"(?<=[.!?])\s+", answer.strip()) if s]


def format_ok(answer: str, max_sentences: int) -> bool:
    return answer.strip().endswith("다.") and len(sentences(answer)) <= max_sentences


def judge(c: dict, *, domain_ratio: float, general_ratio: float, hits: list, fmts: list) -> dict:
    m = c["metrics"]
    return {
        "domain_ppl": domain_ratio <= m["domain_ppl"]["max_ratio"],
        "keyword_hit": sum(hits) / len(hits) >= m["keyword_hit"]["min_mean"],
        "format_ok": sum(fmts) / len(fmts) >= m["format_ok"]["min_rate"],
        "general_ppl": general_ratio <= m["general_ppl"]["max_ratio"],
    }


def main() -> None:
    c = load_criteria()
    rows = {r["id"]: r for r in json.loads((ROOT / c["data"]["source"]).read_text(encoding="utf-8"))}
    split = json.loads((ROOT / c["data"]["split"]).read_text(encoding="utf-8"))["split"]
    test = [i for i, s in split.items() if s == "test"]
    max_s = c["metrics"]["format_ok"]["max_sentences"]
    assert sorted(test) == sorted(c["keywords"]), "핵심어는 test 문항 전체에 있어야 한다"

    print(f"기준 파일 version {c['version']}, 지표 {list(c['metrics'])}")
    for k, v in c["metrics"].items():
        print(f"  {k:<12}{v['pass']}")

    bad = {"fpga-010": "배치는 회로를 놓는 것", "fpga-031": "임계 경로는 중요한 경로입니다. 잘 설계하세요!"}
    print("\n문항        정답 핵심어  정답 형식   나쁜 답 핵심어  나쁜 답 형식")
    for i in sorted(test):
        ref, kw = rows[i]["output"], c["keywords"][i]
        b = bad.get(i, "잘 모르겠어요")
        print(f"  {i}  {keyword_hit(ref, kw):>8.2f}  {str(format_ok(ref, max_s)):>8}"
              f"  {keyword_hit(b, kw):>12.2f}  {str(format_ok(b, max_s)):>10}")

    hits = [keyword_hit(rows[i]["output"], c["keywords"][i]) for i in test]
    fmts = [format_ok(rows[i]["output"], max_s) for i in test]
    print("\n정답을 모델의 답으로 가정한 판정(PPL 비율은 예시 값 0.75, 1.04):")
    print(" ", judge(c, domain_ratio=0.75, general_ratio=1.04, hits=hits, fmts=fmts))
    print("일반 PPL이 15% 오른 경우:")
    print(" ", judge(c, domain_ratio=0.75, general_ratio=1.15, hits=hits, fmts=fmts))


if __name__ == "__main__":
    main()
```

## 핵심 정리

- 정확한 중복은 정규화 후 해시로, 거의 같은 문장은 글자 3-gram Jaccard로, 뜻이 같은 문장은 문장 임베딩 코사인으로 찾습니다.
- 임베딩 유사도는 후보를 좁히는 도구이며 형식에 끌릴 수 있습니다. 최종 판단은 사람이 하고, 애매하면 같은 그룹으로 묶습니다.
- 유사한 문항은 그룹으로 묶어 한 분할에 넣고, 분류별로 층화해 나눈 뒤 누출 검사로 확인합니다. 분할은 id 목록 파일로 고정합니다.
- 평가는 도메인 PPL, 핵심어 적중률, 형식 준수율, 일반 PPL 네 방향을 함께 봅니다. 지표 하나로는 판단하지 않습니다.
- 합격 기준은 실험 전에 파일로 적고, 고칠 때는 version과 이유를 남깁니다.
