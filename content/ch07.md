## 장 개요

제01장에서 LLM을 "앞 문맥으로 다음 토큰의 확률을 계산해 하나씩 고르는 일의 반복"이라고 정의했습니다. 이 장은 그 정의를 처음으로 **동작하는 코드**로 만듭니다.

다만 거대한 신경망 대신, 가장 단순한 언어 모델을 씁니다. 바로 앞 글자 하나만 보고 다음 글자를 정하는 **Bigram 모델**입니다. 학습이라고 해 봐야 글자 쌍의 빈도를 세는 것뿐이지만, 이 작은 모델도 LLM과 똑같은 순서로 문장을 만듭니다. 점수(Logits) → Softmax → 선택 → 붙이기 → 반복. 이 순서를 몸에 익히면, 앞으로 Transformer가 하는 일은 "점수를 더 똑똑하게 계산하는 것"으로 정리됩니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 언어 모델은 확률로 어떻게 문장을 만들어 내는가 |
| 실습 결과물 | 글자 단위 Bigram 확률표, Greedy·Sampling 생성 결과 |
| 실습 파일 | `examples/ch07/`의 `corpus.txt`, `bigram.py`, `test_ch07.py` |
| 선수 장 | 제03장(Indexing), 제06장(Softmax) |

```text
[확률] 문장 확률 = 조건부 확률의 곱
   ↓
[한 걸음] Logits → Softmax → 다음 토큰 선택
   ↓
[반복] 고른 토큰을 붙이고 다시 한 걸음 (자기회귀)
   ↓
[핵심 실습] 빈도표로 만든 Bigram 모델이 한 글자씩 문장을 생성
```

## 언어 모델과 조건부 확률

언어 모델(Language Model)은 **문장에 확률을 매기는 모델**입니다. 자연스러운 문장에는 높은 확률을, 어색한 문장에는 낮은 확률을 줍니다.

문장 전체의 확률을 한 번에 계산하기는 어렵습니다. 그래서 언어 모델은 확률의 곱셈 규칙으로 문장을 잘게 나눕니다.

```text
P("언어 모델") = P(언) × P(어 | 언) × P(" " | 언어) × P(모 | 언어 ) × P(델 | 언어 모)
                        └──────────────── 조건부 확률 ────────────────┘
                 P(B | A) = "A가 주어졌을 때 B가 나올 확률"
```

각 항은 "지금까지의 문맥이 주어졌을 때 다음 글자의 확률"입니다. 문장의 확률을 다음 글자 예측 문제의 연속으로 바꾼 것이며, LLM이 다음 토큰 예측만 배워도 문장 전체를 다룰 수 있는 이유가 이 분해에 있습니다.

### 문맥을 얼마나 볼 것인가

조건부 확률의 문맥은 뒤로 갈수록 길어집니다. 문맥을 얼마나 볼지에 따라 모델의 능력이 갈립니다.

| 모델 | 보는 문맥 | 예: "언어 모"의 다음 글자 |
|---|---|---|
| Bigram | 바로 앞 1글자 | `P(? ∣ 모)` |
| Trigram | 바로 앞 2글자 | `P(? ∣ " 모")` |
| Transformer LLM | 앞의 모든 토큰(문맥 길이 안에서) | `P(? ∣ 언어 모)` |

Bigram은 가장 짧은 문맥을 보므로 한계가 뚜렷하지만, 구조는 LLM과 같습니다. 이 장에서 Bigram으로 생성 과정을 익히고, 제2부의 Attention이 "앞의 모든 토큰을 보는 방법"이라는 것을 연결해 이해하게 됩니다.

## Logits에서 다음 토큰까지

생성의 한 걸음은 세 단계입니다.

```text
① 점수(Logits) 계산     문맥 → 어휘의 모든 토큰에 대한 점수   [vocab]
② Softmax              점수 → 합이 1인 확률                   [vocab]
③ 선택                 확률에서 토큰 하나를 고른다             정수 1개
```

| 단계 | Bigram 모델(이 장) | Qwen2.5(실제 LLM) |
|---|---|---|
| ① 점수 | 빈도표의 한 행에 로그: `log(빈도 + α)` | Transformer 전체를 거친 마지막 계층 출력 |
| ② 확률 | Softmax(제06장) | Softmax(제06장) |
| ③ 선택 | Greedy 또는 Sampling | Greedy 또는 Sampling(제20장) |

두 모델의 차이는 ①뿐입니다. Bigram은 빈도를 세어 점수를 만들고, LLM은 수억 개의 가중치로 점수를 계산합니다. ②와 ③은 완전히 같습니다.

### 빈도를 점수로 바꾸는 방법

Bigram 모델에서 "모 다음에 델이 3번, 아가 1번 나왔다"는 빈도를 확률로 바꾸려면, 빈도의 로그를 점수로 삼아 Softmax에 넣습니다.

```text
점수 = log(빈도 + α)
Softmax(점수) = e^log(빈도+α) / Σ e^log(빈도+α) = (빈도 + α) / Σ(빈도 + α)
```

결과는 "빈도를 전체 빈도로 나눈 값"과 같습니다. 일부러 Logits와 Softmax를 거치게 만든 이유는, 실제 LLM과 똑같은 경로로 확률을 얻기 위해서입니다. `α`(0.01)는 한 번도 나오지 않은 조합의 확률이 정확히 0이 되지 않게 하는 작은 값입니다. 이를 평활화(Smoothing)라 부르며, `log(0) = -∞`가 되는 문제도 함께 막아 줍니다.

## Greedy Decoding

확률에서 토큰을 고르는 가장 단순한 방법은 **확률이 가장 높은 토큰을 고르는 것**입니다. 이를 Greedy Decoding(탐욕적 디코딩)이라 부릅니다.

| 방법 | 고르는 규칙 | 장점 | 단점 |
|---|---|---|---|
| Greedy | 항상 가장 높은 확률(`argmax`) | 같은 입력에 같은 출력(재현성) | 같은 구절을 반복하기 쉽다 |
| Sampling | 확률에 비례해 무작위로 뽑기 | 다양한 문장 생성 | 실행마다 결과가 다름(seed로 고정 가능) |

Greedy는 매 순간 최선을 고르지만, 전체로는 최선이 아닐 수 있습니다. 특히 문맥이 짧은 모델에서는 한 번 들어선 길에서 빠져나오지 못하고 같은 구절을 무한히 반복하곤 합니다. 핵심 실습에서 이 현상을 직접 보게 됩니다.

이 교재는 결과를 비교·검증할 때 Greedy를 씁니다. 같은 입력에 언제나 같은 출력이 나와야 학습 전후를 공정하게 비교할 수 있기 때문입니다. 제01장의 Ollama 실습에서 `temperature 0`으로 설정한 것도 Greedy와 같은 효과를 내기 위해서입니다.

## Bigram 언어 모델 구현

Bigram 모델의 "학습"은 빈도표 하나를 만드는 일입니다.

```text
문장: "모델은"
시작·끝 표시를 붙인다:  ^ 모 델 은 $
이웃한 두 글자 쌍:      (^,모) (모,델) (델,은) (은,$)
빈도표에 1씩 더한다:    counts[앞 글자, 다음 글자] += 1
```

| 구성 | 역할 | 실제 LLM의 대응 |
|---|---|---|
| `^`, `$` | 문장 시작·끝 표시 | BOS·EOS 특수 토큰(제08장) |
| 어휘(`vocab`) | 등장한 모든 글자 + 특수 토큰 | 토크나이저의 어휘 집합(제08장) |
| 빈도표 `[V, V]` | 앞 글자별 다음 글자 빈도 | 학습된 가중치 |
| 확률표 `[V, V]` | 각 행이 다음 글자의 확률분포 | 모델 출력 + Softmax |

생성은 `^`(시작)에서 출발해 한 글자씩 고르고, `$`(끝)를 고르면 멈춥니다. 끝 표시를 학습해 두었기 때문에 모델이 스스로 "여기서 문장이 끝난다"를 판단할 수 있습니다. 제45장에서 LLM 학습 데이터의 응답 끝 토큰을 반드시 학습 대상에 넣는 이유도 같습니다. 끝을 배우지 못한 모델은 멈추지 못합니다.

## 핵심 실습

직접 쓴 짧은 문장 10개로 Bigram 모델을 만들고, 확률을 확인한 뒤 한 글자씩 문장을 생성합니다.

파일명: `examples/ch07/corpus.txt`

```text
언어 모델은 다음 글자를 예측한다.
언어 모델은 앞의 문맥을 보고 다음 토큰을 고른다.
모델은 고른 토큰을 다시 입력에 붙인다.
토큰을 하나씩 붙이면 문장이 된다.
문장이 길어지면 같은 일을 더 많이 반복한다.
학습은 가중치를 조금씩 고치는 일이다.
행렬곱은 내적을 모아 놓은 표이다.
내적은 두 벡터가 닮은 정도를 나타낸다.
확률은 점수를 소프트맥스에 넣어 얻는다.
가장 높은 확률의 글자를 고르면 탐욕 생성이다.
```

파일명: `examples/ch07/bigram.py`

```python
# 제07장 핵심 실습: 글자 단위 Bigram 언어 모델로 자기회귀 생성하기
#
# 실행: python examples/ch07/bigram.py
#
# Bigram: 바로 앞 글자 하나만 보고 다음 글자의 확률을 정하는 가장 작은 언어 모델

from pathlib import Path

import torch

BOS, EOS = "^", "$"      # 문장 시작·끝 표시(특수 토큰)


class BigramLM:
    def __init__(self, lines: list, alpha: float = 0.01):
        chars = sorted({c for line in lines for c in line})
        self.vocab = [BOS, EOS] + chars                   # 어휘 집합
        self.stoi = {c: i for i, c in enumerate(self.vocab)}
        V = len(self.vocab)

        # 1) 빈도표: counts[앞 글자, 다음 글자] = 함께 나온 횟수
        self.counts = torch.zeros(V, V)
        for line in lines:
            seq = [BOS] + list(line) + [EOS]
            for a, b in zip(seq, seq[1:]):
                self.counts[self.stoi[a], self.stoi[b]] += 1

        # 2) Logits = log(빈도 + α) → Softmax → 확률표
        #    α는 한 번도 나오지 않은 조합의 확률이 정확히 0이 되지 않게 하는 작은 값
        self.logits = torch.log(self.counts + alpha)
        self.probs = torch.softmax(self.logits, dim=-1)   # 각 행의 합 = 1

    def next_probs(self, prev: str) -> torch.Tensor:
        """앞 글자가 prev일 때 다음 글자의 확률분포 P(다음 | prev)."""
        return self.probs[self.stoi[prev]]

    def sequence_log_prob(self, text: str) -> float:
        """문장 확률 = 조건부 확률의 곱 → 로그를 취해 합으로 계산한다."""
        seq = [BOS] + list(text) + [EOS]
        return sum(torch.log(self.next_probs(a)[self.stoi[b]]).item()
                   for a, b in zip(seq, seq[1:]))

    def generate(self, prefix: str = "", max_new: int = 40, greedy: bool = True,
                 seed: int = 0) -> str:
        """자기회귀 생성: 고른 글자를 문맥 끝에 붙이고 다시 다음 글자를 고른다."""
        generator = torch.Generator().manual_seed(seed)
        out = prefix
        last = prefix[-1] if prefix else BOS
        for _ in range(max_new):
            p = self.next_probs(last)
            if greedy:
                idx = int(torch.argmax(p))                         # 가장 높은 확률
            else:
                idx = int(torch.multinomial(p, 1, generator=generator))  # 확률대로 뽑기
            ch = self.vocab[idx]
            if ch == EOS:
                break
            out += ch
            last = ch
        return out


def load_corpus() -> list:
    text = Path(__file__).with_name("corpus.txt").read_text(encoding="utf-8")
    return [line for line in text.splitlines() if line.strip()]


def main() -> None:
    lm = BigramLM(load_corpus())
    print(f"어휘 크기: {len(lm.vocab)}개 (특수 토큰 2 + 글자 {len(lm.vocab) - 2})")
    print(f"확률표 모양: {tuple(lm.probs.shape)}, 행 합의 최솟값: {lm.probs.sum(dim=-1).min():.6f}")

    print("\n── 1. '모' 다음에 올 글자 상위 3개 ──")
    p = lm.next_probs("모")
    top = torch.topk(p, 3)
    for prob, idx in zip(top.values.tolist(), top.indices.tolist()):
        print(f"  P({lm.vocab[idx]!r} | '모') = {prob:.3f}  (빈도 {int(lm.counts[lm.stoi['모'], idx])}회)")

    print("\n── 2. 문장 확률 = 조건부 확률의 곱 ──")
    for s in ("언어 모델", "모델 언어"):
        print(f"  log P({s!r}) = {lm.sequence_log_prob(s):.2f}")

    print("\n── 3. Greedy Decoding ──")
    for prefix in ("언", "학", "확"):
        print(f"  {prefix!r} → {lm.generate(prefix)!r}")

    print("\n── 4. 확률대로 뽑기(Sampling, seed 고정) ──")
    for seed in (0, 1, 2):
        print(f"  seed {seed}: {lm.generate('언', greedy=False, seed=seed)!r}")


if __name__ == "__main__":
    main()
```

**핵심 코드 풀이**

- `__init__`의 빈도표 만들기가 이 모델의 학습 전부입니다. 문장 앞뒤에 `^`, `$`를 붙이고, `zip(seq, seq[1:])`로 이웃한 두 글자를 짝지어 `counts`에 1씩 더합니다.
- `self.logits = torch.log(self.counts + alpha)`와 `torch.softmax(..., dim=-1)`는 03절의 "빈도 → 점수 → 확률" 경로입니다. `dim=-1`은 제03장의 축 개념 그대로, **각 행(앞 글자)마다** 다음 글자의 확률을 만들라는 뜻입니다. 그래서 모든 행의 합이 1입니다.
- 1번 결과에서 '모' 다음은 '델'이 3번, '아'가 1번 나왔습니다. 빈도 비율은 3:1인데 확률이 0.617과 0.207로 조금 낮은 것은 평활화 `α`가 어휘 88개 모두에 조금씩 나눠 주어진 몫만큼 줄었기 때문입니다. 한 번도 나오지 않은 '의'도 0이 아니라 0.002입니다.
- `sequence_log_prob()`는 01절의 곱셈 분해를 계산합니다. 작은 확률을 여러 번 곱하면 0에 가까워져 다루기 어려우므로, 로그를 취해 **곱을 합으로** 바꿉니다. "언어 모델"(-11.78)이 "모델 언어"(-23.89)보다 훨씬 높은 확률을 받았습니다. 학습 문장에 자주 나온 순서를 모델이 배운 것입니다.
- `generate()`의 반복문이 자기회귀 생성입니다. 고른 글자를 `out`에 붙이고, 그 글자를 다음 걸음의 문맥(`last`)으로 씁니다. `$`를 고르면 멈춥니다.

**결과 읽기: Greedy의 반복**

3번에서 Greedy 생성은 세 입력 모두 "고른 고른 고른…"에 갇혀 최대 길이까지 같은 구절을 반복합니다. 빈도표를 따라가 보면 이유가 보입니다. 공백 다음에는 '고'(4회)가, '고' 다음에는 '른'(2회)이 가장 많습니다. '른' 다음은 '다'와 공백이 1회씩 같은데, 동점이면 어휘 순서가 앞선 공백이 선택됩니다. 그래서 공백 → 고 → 른 → 공백의 고리가 생깁니다. 앞 글자 하나만 보는 모델은 "이미 '고른'을 썼다"는 사실을 기억할 수 없으므로, 같은 길을 되풀이합니다. 문맥이 짧은 모델과 Greedy가 만나면 생기는 전형적인 실패이며, 긴 문맥을 보는 Attention(제2부)과 다양한 선택 방법(제20장)이 필요한 이유입니다.

4번의 Sampling은 매번 다른 문장을 만들고, seed 0과 1처럼 문장 끝 `.` 뒤에서 스스로 멈추기도 합니다. 단어가 뒤섞인 것은 앞 글자 하나만으로는 단어의 경계와 의미를 알 수 없기 때문입니다. 그래도 "언어", "소프트", "벡터"처럼 학습 문장의 글자 조각은 살아 있습니다.

```python
# 제07장 검증 테스트

# 실행: python -m pytest examples/ch07 -q

import sys
from pathlib import Path

import torch

sys.path.insert(0, str(Path(__file__).resolve().parent))

from bigram import BOS, EOS, BigramLM, load_corpus  # noqa: E402


def make_model():
    return BigramLM(load_corpus())


def test_rows_sum_to_one():
    lm = make_model()
    torch.testing.assert_close(lm.probs.sum(dim=-1), torch.ones(len(lm.vocab)))


def test_bigram_count_total():
    # 문장마다 (글자 수 + 1)개의 쌍: [BOS, c1], [c1, c2], ..., [cn, EOS]
    lines = load_corpus()
    assert int(make_model().counts.sum()) == sum(len(line) + 1 for line in lines)


def test_probability_formula():
    # Softmax(log(count + α)) = (count + α) / Σ(count + α)
    lm = make_model()
    row = lm.counts[lm.stoi["모"]] + 0.01
    torch.testing.assert_close(lm.next_probs("모"), row / row.sum())


def test_most_likely_after_mo():
    lm = make_model()
    assert lm.vocab[int(torch.argmax(lm.next_probs("모")))] == "델"


def test_word_order_probability():
    lm = make_model()
    assert lm.sequence_log_prob("언어 모델") > lm.sequence_log_prob("모델 언어")


def test_greedy_is_reproducible():
    lm = make_model()
    assert lm.generate("언") == lm.generate("언")


def test_sampling_reproducible_with_seed():
    lm = make_model()
    assert lm.generate("언", greedy=False, seed=1) == lm.generate("언", greedy=False, seed=1)


def test_generation_stops_at_eos():
    # 'EOS' 확률이 가장 높은 글자('.' 다음)에서 생성이 끝나야 한다.
    lm = make_model()
    assert lm.vocab[int(torch.argmax(lm.next_probs(".")))] == EOS
    assert lm.generate(".") == "."


def test_special_tokens_in_vocab():
    lm = make_model()
    assert lm.vocab[:2] == [BOS, EOS]
```

## 핵심 정리

- 언어 모델은 문장의 확률을 "문맥이 주어졌을 때 다음 토큰의 확률"의 곱으로 나눠 계산합니다.
- 생성의 한 걸음은 Logits → Softmax → 선택이며, 고른 토큰을 붙여 다시 반복하는 것이 자기회귀 생성입니다.
- Bigram과 LLM의 차이는 점수를 계산하는 방법(빈도표 대 Transformer)뿐이고, 확률화와 선택은 같습니다.
- Greedy는 재현성이 있어 검증에 쓰지만, 문맥이 짧으면 같은 구절을 반복하기 쉽습니다.
- 끝 표시(`$`, 실제 LLM의 EOS)를 학습해야 모델이 스스로 멈출 수 있습니다.
