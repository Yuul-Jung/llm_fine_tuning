## 장 개요

지금까지 Attention(제12~16장)과 FFN(제17장)이라는 두 큰 부품을 만들었습니다. 그러나 이 둘을 그냥 이어 붙여 24겹으로 쌓으면 모델은 제대로 학습되지 않습니다. 층을 지날 때마다 값의 크기가 제멋대로 커지거나 작아지고, 깊은 곳까지 학습 신호가 전달되지 않기 때문입니다.

이 장은 깊은 모델을 가능하게 만드는 두 장치, **정규화**(RMSNorm)와 **잔차 연결**(Residual Connection)을 다룹니다. 그리고 지금까지 직접 만든 모든 부품을 조립해 Qwen2.5의 Decoder Layer 하나를 통째로 재현합니다. 라이브러리의 계층 모듈을 하나도 부르지 않고, 가중치 값만 꺼내 우리 함수로 계산합니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 깊은 모델은 어떻게 안정적으로 동작하며, Decoder Layer는 어떻게 조립되는가 |
| 실습 결과물 | LayerNorm·RMSNorm 비교, 잔차 스트림 크기, 직접 조립한 Decoder Layer와 실제 출력 비교 |
| 실습 파일 | `examples/ch18/`의 `norm_residual.py`, `decoder_layer.py`, `test_ch18.py` |
| 선수 장 | 제04장(평균·분산), 제11장(구조 지도), 제15~17장(Attention·FFN 재현) |

```text
x ──┬──▶ RMSNorm ─▶ Attention ─▶ (+) ──┬──▶ RMSNorm ─▶ FFN ─▶ (+) ──▶ 출력
    └─────────────(잔차)────────────┘   └───────────(잔차)───────┘
```

## 정규화가 필요한 이유

신경망의 층을 지날 때마다 값은 가중치와 곱해지고 더해집니다. 제04장에서 본 것처럼 더하는 항이 많을수록 값의 크기가 커지고, 제06장에서 본 것처럼 큰 값은 Softmax를 쏠리게 만듭니다. 층이 24개나 되면 작은 변화도 누적되어, 어떤 층에는 아주 큰 값이, 어떤 층에는 아주 작은 값이 들어오게 됩니다.

값의 크기가 들쭉날쭉하면 두 가지 문제가 생깁니다.

| 문제 | 결과 |
|---|---|
| 층마다 입력의 크기가 다르다 | 같은 가중치가 상황에 따라 전혀 다르게 작동한다 |
| 학습 신호(기울기)의 크기도 흔들린다 | 학습이 불안정하거나 멈춘다(제23장) |

정규화는 각 부품에 들어가기 직전에 **값의 크기를 일정한 수준으로 맞춥니다.** 부품은 언제나 비슷한 크기의 입력을 받으므로 안정적으로 동작합니다. 핵심 실습 1의 4번에서 실제 Qwen2.5의 값이 층을 지나며 0.4에서 100 이상으로 커지는 것을 확인하고, 정규화가 이것을 일정한 크기로 되돌리는 것을 봅니다.

## LayerNorm과 RMSNorm

정규화는 토큰 하나의 벡터(마지막 축)를 기준으로 합니다. 두 가지 방식이 널리 쓰입니다.

```text
LayerNorm:  (x − 평균) ÷ 표준편차 × weight + bias      평균을 0, 분산을 1로
RMSNorm:    x ÷ RMS(x) × weight                        크기(RMS)만 1로
            RMS(x) = √( (x₁² + x₂² + … + xₙ²) ÷ n )      제곱의 평균의 제곱근
```

| 구분 | LayerNorm | RMSNorm |
|---|---|---|
| 평균 빼기 | 한다 | 하지 않는다 |
| 학습 파라미터 | weight, bias | weight만 |
| 계산 | 평균·분산 두 번 | 제곱평균 한 번 |
| 쓰는 모델 | 원조 Transformer, BERT, GPT-2 | Llama, **Qwen** |

RMSNorm은 LayerNorm에서 평균을 빼는 단계를 생략했습니다. 크기를 맞추는 것만으로도 효과가 충분하다는 사실이 알려지면서, 계산이 더 가벼운 RMSNorm이 최근 모델의 표준이 되었습니다. RMSNorm을 거친 벡터는 제곱평균이 1이므로, 896차원 벡터의 길이는 항상 `√896 ≈ 29.9`가 됩니다. 원래 값이 얼마나 컸든 같은 크기로 돌아오고, 그 뒤에 학습된 `weight`를 칸마다 곱해 필요한 크기로 다시 조정합니다.

Qwen2.5의 RMSNorm은 `eps = 1e-6`을 씁니다. RMS가 0에 가까울 때 0으로 나누는 것을 막는 아주 작은 값입니다.

## Residual Connection

잔차 연결은 부품의 출력에 **부품의 입력을 그대로 더해 주는** 지름길입니다.

```text
잔차 연결이 없으면:   출력 = 부품(x)
잔차 연결이 있으면:   출력 = x + 부품(x)
```

간단한 덧셈 하나가 깊은 모델의 학습을 가능하게 합니다.

| 효과 | 설명 |
|---|---|
| 정보 보존 | 부품이 아무것도 배우지 못해도 입력은 그대로 다음 층으로 전달된다 |
| 학습 신호 전달 | 역전파에서 기울기가 덧셈을 따라 곧장 앞쪽 층까지 흐른다(제23장) |
| 점진적 수정 | 각 부품은 입력 전체를 새로 만드는 대신 "고칠 부분"만 배우면 된다 |

잔차 연결 덕분에 Transformer의 데이터 흐름은 하나의 큰 강처럼 볼 수 있습니다. 토큰 벡터가 24개 계층을 따라 흐르는 강(잔차 스트림, Residual Stream)이 있고, 각 계층의 Attention과 FFN은 그 강에서 물을 떠서 가공한 뒤 다시 부어 넣습니다. 핵심 실습 2의 3번에서 잔차 연결을 빼면 0번 계층의 출력이 실제와 완전히 달라지는 것(상대 오차 1.17)을 확인합니다.

## Pre-Norm과 Final Norm

정규화를 어디에 두는지에 따라 두 방식이 있습니다.

```text
Post-Norm(원조 Transformer):  출력 = Norm( x + 부품(x) )
Pre-Norm(Qwen, Llama):        출력 = x + 부품( Norm(x) )
```

Pre-Norm은 부품에 들어가는 값만 정규화하고, 잔차 스트림 자체는 건드리지 않습니다. 강물의 흐름은 그대로 두고, 떠낸 물만 정수해서 쓰는 셈입니다. 잔차 경로가 아무것도 거치지 않고 곧게 이어지므로 깊은 모델에서도 학습이 안정적이라, 오늘날 LLM의 표준이 되었습니다.

대신 Pre-Norm에서는 마지막 계층을 지난 잔차 스트림이 정규화되지 않은 상태로 남습니다. 그래서 모든 계층이 끝난 뒤 **Final Norm**(`model.norm`)을 한 번 더 적용하고, 그 결과를 LM Head에 넣어 Logits를 만듭니다. 제11장의 데이터 흐름 그림에서 `model.norm`이 따로 있었던 이유입니다.

### Decoder Layer 조립

이제 하나의 Decoder Layer를 수식으로 완성할 수 있습니다.

```text
h   = x + Attention( RMSNorm₁(x) )        input_layernorm, self_attn
out = h + FFN( RMSNorm₂(h) )              post_attention_layernorm, mlp
```

계층 하나에 RMSNorm이 두 개, 잔차 연결이 두 번 있습니다. 제11장에서 센 "계층당 RMSNorm 2개(1,792개 파라미터)"가 바로 이 두 정규화의 `weight`입니다.

### 실습 1. 정규화 구현과 잔차 스트림의 크기

파일명: `examples/ch18/norm_residual.py`

```python
# 제18장 실습 1: LayerNorm과 RMSNorm 직접 구현, 잔차 스트림의 크기 관찰
#
# 실행: python examples/ch18/norm_residual.py

import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

import torch  # noqa: E402
import torch.nn.functional as F  # noqa: E402


def layer_norm(x: torch.Tensor, weight: torch.Tensor, bias: torch.Tensor, eps: float = 1e-5):
    """평균을 빼고 표준편차로 나눈 뒤 크기(weight)와 이동(bias)을 학습한다."""
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    return (x - mean) / torch.sqrt(var + eps) * weight + bias


def rms_norm(x: torch.Tensor, weight: torch.Tensor, eps: float = 1e-6):
    """평균은 빼지 않고, 제곱평균제곱근(RMS)으로만 나눈 뒤 크기(weight)를 곱한다."""
    rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + eps)
    return x / rms * weight


def main() -> None:
    torch.manual_seed(0)
    x = torch.randn(2, 4, 8) * 50 + 3            # 크고 치우친 값

    print("── 1. 정규화 전후의 통계(마지막 축 기준) ──")
    ones, zeros = torch.ones(8), torch.zeros(8)
    ln, rms = layer_norm(x, ones, zeros), rms_norm(x, ones)
    for name, t in (("입력", x), ("LayerNorm", ln), ("RMSNorm", rms)):
        r = t.pow(2).mean(dim=-1).sqrt()
        print(f"  {name:<10} 평균 {t.mean(dim=-1)[0, 0].item():+8.3f}   RMS {r[0, 0].item():8.3f}")

    print("\n── 2. PyTorch 함수와 비교 ──")
    w = torch.randn(8)
    e1 = (layer_norm(x, w, zeros) - F.layer_norm(x, (8,), w, zeros)).abs().max().item()
    e2 = (rms_norm(x, w) - F.rms_norm(x, (8,), w, eps=1e-6)).abs().max().item()
    print(f"  LayerNorm 최대 차이 {e1:.1e},  RMSNorm 최대 차이 {e2:.1e}")

    print("\n── 3. 크기가 달라도 같은 결과(RMSNorm은 배율에 무관) ──")
    print(f"  rms_norm(x) = rms_norm(x × 100): {torch.allclose(rms_norm(x, w), rms_norm(x * 100, w), atol=1e-5)}")

    print("\n── 4. 실제 Qwen2.5의 잔차 스트림 크기(토큰 평균 L2 길이) ──")
    from common.qwen import load_model, load_tokenizer
    model, tok = load_model(), load_tokenizer()
    with torch.no_grad():
        hs = model(tok("언어 모델은 다음 토큰을 예측한다.", return_tensors="pt").input_ids,
                   output_hidden_states=True).hidden_states
    for i in (0, 1, 3, 12, 20):
        name = "Embedding 출력" if i == 0 else f"{i}번째 계층 통과 후"
        print(f"  {name:<16} {hs[i].norm(dim=-1).mean().item():8.1f}")
    normed = rms_norm(hs[12], torch.ones(896))          # 가중치를 곱하기 전: RMS = 1
    print(f"  12번째 계층 통과 후 값을 RMSNorm하면: 길이 {normed.norm(dim=-1).mean().item():.1f}"
          f" (= √896 = {896 ** 0.5:.1f})")


if __name__ == "__main__":
    main()
```

**핵심 코드 풀이**

- `layer_norm()`과 `rms_norm()`은 02절의 수식 그대로입니다. 두 함수 모두 `dim=-1`(마지막 축), 즉 토큰 하나의 벡터 안에서 통계를 계산합니다.
- 1번에서 입력은 평균 -21, RMS 50으로 크고 치우쳐 있습니다. LayerNorm은 평균을 0, RMS를 1로 만들고, RMSNorm은 RMS만 1로 만들어 평균(-0.417)은 0이 아닙니다.
- 2번은 PyTorch의 `F.layer_norm`, `F.rms_norm`과 반올림 수준으로 일치함을 확인합니다.
- 3번은 RMSNorm이 입력의 배율과 무관하다는 성질입니다. 값을 100배 키워도 정규화 결과는 같습니다. 크기가 들쭉날쭉한 입력을 일정하게 만드는 원리입니다.
- 4번은 실제 Qwen2.5의 잔차 스트림입니다. Embedding 출력의 길이 0.4가 계층을 지나며 6.5, 52.4, 113.5, 138.2로 커집니다. 각 계층이 Attention·FFN의 결과를 계속 더해 넣기 때문입니다. 그래도 RMSNorm을 거치면 길이가 정확히 `√896 = 29.9`로 돌아옵니다. 다음 부품은 항상 같은 크기의 입력을 받습니다.

### 실습 2. Decoder Layer 통째로 재현

지금까지 만든 함수만으로 Decoder Layer를 조립합니다. 제05장 `linear_forward`, 제15장 `grouped_attention`, 제16장 `apply_rope`, 제17장 `swiglu_ffn`, 이 장의 `rms_norm`입니다. 라이브러리 계층 모듈은 가중치를 꺼내는 데만 쓰고, 계산에는 쓰지 않습니다.

`output_hidden_states=True`로 받은 `hs[i]`는 `i`번 계층의 입력이고 `hs[i+1]`은 그 출력입니다(마지막 `hs[24]`만 Final Norm까지 적용된 값). 그래서 Hook 없이도 계층마다 입력과 정답 출력을 얻을 수 있습니다.

파일명: `examples/ch18/decoder_layer.py`

```python
# 제18장 핵심 실습: 직접 만든 부품만으로 Qwen2.5 Decoder Layer를 조립해 실제 출력과 비교
#
# 실행: python examples/ch18/decoder_layer.py
#
# h   = x + Attention( RMSNorm₁(x) )        잔차 연결 1
# out = h + FFN( RMSNorm₂(h) )              잔차 연결 2

import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
for p in (ROOT, ROOT / "ch05", ROOT / "ch06", ROOT / "ch03", ROOT / "ch14", ROOT / "ch15",
          ROOT / "ch16", ROOT / "ch17", Path(__file__).resolve().parent):
    sys.path.insert(0, str(p))

import torch  # noqa: E402

from common.qwen import load_model, load_tokenizer  # noqa: E402
from linear_scratch import linear_forward  # noqa: E402  (제05장)
from mha_gqa import grouped_attention  # noqa: E402     (제15장)
from norm_residual import rms_norm  # noqa: E402        (이 장)
from rope import apply_rope, rope_cos_sin  # noqa: E402 (제16장)
from swiglu import swiglu_ffn  # noqa: E402             (제17장)

TEXT = "언어 모델은 다음 토큰을 예측한다."


def get(module, name):
    return getattr(module, name).detach()


def self_attention(attn, x, cos, sin):
    """q·k·v_proj(편향 포함) → RoPE·GQA Causal Attention → o_proj(편향 없음)"""
    q = linear_forward(x, get(attn.q_proj, "weight"), get(attn.q_proj, "bias"))
    k = linear_forward(x, get(attn.k_proj, "weight"), get(attn.k_proj, "bias"))
    v = linear_forward(x, get(attn.v_proj, "weight"), get(attn.v_proj, "bias"))
    rope = lambda q_, k_: (apply_rope(q_, cos, sin), apply_rope(k_, cos, sin))  # noqa: E731
    return linear_forward(grouped_attention(q, k, v, 14, 2, rope=rope), get(attn.o_proj, "weight"))


def decoder_layer(layer, x, cos, sin, residual: bool = True):
    """Pre-Norm Decoder Layer 하나. residual=False면 잔차 연결을 뺀 비교용 계산."""
    a = self_attention(layer.self_attn, rms_norm(x, get(layer.input_layernorm, "weight")), cos, sin)
    h = x + a if residual else a
    mlp = layer.mlp
    f = swiglu_ffn(rms_norm(h, get(layer.post_attention_layernorm, "weight")),
                   get(mlp.gate_proj, "weight"), get(mlp.up_proj, "weight"), get(mlp.down_proj, "weight"))
    return h + f if residual else f


def hidden_states(model, tok):
    ids = tok(TEXT, return_tensors="pt").input_ids
    with torch.no_grad():
        return model(ids, output_hidden_states=True).hidden_states


def main() -> None:
    model, tok = load_model(), load_tokenizer()
    hs = hidden_states(model, tok)                 # hs[i] = i번 계층의 입력
    seq = hs[0].shape[1]
    cos, sin = rope_cos_sin(seq, 64, 1e6)

    print("── 1. Decoder Layer 재현(계층 입력 hs[i] → 계층 출력 hs[i+1]) ──")
    with torch.no_grad():
        for i in (0, 12, 22):
            mine = decoder_layer(model.model.layers[i], hs[i], cos, sin)
            print(f"  {i:>2}번 계층: 최대 오차 {(mine - hs[i + 1]).abs().max().item():.1e}, "
                  f"상대 오차 {((mine - hs[i + 1]).norm() / hs[i + 1].norm()).item():.1e}")

    print("\n── 2. 마지막 계층 + Final Norm ──")
    with torch.no_grad():
        last = decoder_layer(model.model.layers[23], hs[23], cos, sin)
        final = rms_norm(last, model.model.norm.weight.detach())
    print(f"  Final Norm 결과와 모델의 마지막 hidden state 최대 오차: {(final - hs[24]).abs().max().item():.1e}")

    print("\n── 3. 잔차 연결을 빼면? ──")
    with torch.no_grad():
        no_res = decoder_layer(model.model.layers[0], hs[0], cos, sin, residual=False)
    print(f"  0번 계층 출력 상대 오차: {((no_res - hs[1]).norm() / hs[1].norm()).item():.2f}")


if __name__ == "__main__":
    main()
```

**핵심 코드 풀이**

- `self_attention()`은 제15·16장의 재현 코드를 라이브러리 모듈 호출 없이 다시 쓴 것입니다. q·k·v_proj는 편향이 있고 o_proj는 없다는 제12장의 사실이 `linear_forward()` 호출에 그대로 드러납니다.
- `decoder_layer()`의 네 줄이 05절의 수식 두 줄입니다. `rms_norm` → `self_attention` → `x + a` → `rms_norm` → `swiglu_ffn` → `h + f`.
- 1번에서 0번·12번·22번 계층 모두 상대 오차가 `1e-6` 이하입니다. 최대 절대오차가 `1e-5` 근처로 보이는 것은 잔차 스트림의 값 자체가 수백 단위로 크기 때문이며, 상대 오차로는 매우 작습니다. 값이 큰 텐서는 상대 오차로 판정하는 것이 공정합니다(설계서 7.1절).
- 2번에서 마지막 계층 뒤에 Final Norm까지 직접 적용한 결과도 모델의 마지막 hidden state와 일치합니다. 이 값에 LM Head를 곱하면 Logits가 됩니다.
- 3번에서 잔차 연결을 빼면 상대 오차가 1.17, 즉 출력이 완전히 다른 값이 됩니다. 잔차 연결이 장식이 아니라 계산의 핵심 경로라는 뜻입니다.

## 핵심 정리

- 정규화는 각 부품에 들어가는 값의 크기를 일정하게 맞춰 깊은 모델을 안정시킵니다.
- RMSNorm은 평균을 빼지 않고 크기(RMS)만 1로 맞춘 뒤 `weight`를 곱합니다. Qwen2.5는 RMSNorm(`eps = 1e-6`)을 씁니다.
- 잔차 연결은 부품의 입력을 출력에 더해, 정보와 학습 신호가 깊은 층까지 곧게 전달되게 합니다.
- Qwen2.5는 Pre-Norm 구조입니다: `h = x + Attn(Norm(x))`, `out = h + FFN(Norm(h))`. 마지막에 Final Norm을 한 번 더 적용합니다.
- 직접 만든 부품만으로 Decoder Layer와 Final Norm을 조립해, 실제 모델 출력과 상대 오차 1e-6 이하로 일치시켰습니다.

**다음 장 연결:** Decoder Layer 하나를 완성했으니, 이제 모델 전체를 조립할 수 있습니다. 제19장에서는 같은 구조를 아주 작은 크기로 만든 Qwen2-Tiny를 처음부터 구현하고, 그 가중치를 Hugging Face의 `Qwen2ForCausalLM`에 넣어 두 모델이 같은 Logits를 내는지 확인합니다.
