## 장 개요

제41장에서 FPGA 질의응답 50개를 작성했습니다. 이 데이터로 학습하려면 학습 도구가 다루기 좋은 형태로 바꿔야 합니다. 파일 형식을 정하고, 학습·검증·평가용으로 나누고, 필요한 열을 덧붙이고, 그 결과를 저장해 매번 같은 데이터로 학습해야 합니다.

이 장은 Hugging Face의 **Datasets** 라이브러리로 이 일을 합니다. 한 줄에 샘플 하나를 두는 JSONL 형식이 학습 데이터에 알맞은 이유를 확인하고, `Dataset`과 `DatasetDict`로 분할을 관리하며, `map`·`filter`·`select` 세 연산으로 전처리를 구성하고, 저장했다가 복원해 결과가 같은지 확인합니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 학습 데이터를 어떤 형식으로 저장하고, 어떻게 나누고 변환해 매번 같은 데이터로 학습하는가 |
| 실습 결과물 | JSONL 파일, 학습·검증·평가 DatasetDict, 대화형 열을 더한 데이터, 저장·복원 일치 확인 |
| 실습 파일 | `examples/ch42/`의 `hf_datasets.py`, `test_ch42.py`, `datasets/fpga_qa/fpga_qa.jsonl` |
| 선수 장 | 제41장(데이터 구조와 원본) |

```text
fpga_qa.json(원본) ─write_jsonl─▶ fpga_qa.jsonl ─load_dataset─▶ Dataset(50)
   ─train_test_split(seed 0)─▶ DatasetDict{train 40, validation 5, test 5}
   ─map(messages 추가)─▶ save_to_disk ─load_from_disk─▶ 같은 데이터
```

## CSV, JSON, JSONL

| 형식 | 구조 | 학습 데이터로 쓸 때 |
|---|---|---|
| CSV | 쉼표로 나눈 표 | 열이 고정된 단순한 값에 알맞다. 값 안의 줄바꿈·쉼표는 따옴표 규칙에 기대야 한다 |
| JSON | 파일 전체가 하나의 배열 | 사람이 읽고 고치기 좋다. 전체를 한 번에 읽어야 한다 |
| JSONL | 한 줄에 JSON 객체 하나 | 줄 수 = 샘플 수. 한 줄씩 읽고, 이어 붙이고, 나눌 수 있다 |

JSONL(JSON Lines)이 학습 데이터의 사실상 표준인 이유는 **한 줄이 한 샘플**이기 때문입니다. 샘플 속 코드에 줄바꿈이 있어도 JSON 안에서는 `\n` 문자로 바뀌므로 줄 구분과 섞이지 않습니다. 그래서 줄 수만 세면 샘플 수를 알 수 있고, 큰 파일도 한 줄씩 읽어 메모리를 아끼며, 두 파일을 이어 붙이거나 일부만 잘라 내는 일이 쉽습니다. 실습 1번에서 같은 샘플이 CSV로는 여러 줄에 걸치는 것을 확인합니다.

이 교재는 사람이 작성·검토하는 원본은 JSON(`fpga_qa.json`)으로, 학습 도구에 넘기는 파일은 JSONL로 둡니다. JSONL은 원본에서 언제든 다시 만들 수 있고, 테스트로 둘이 어긋나지 않았는지 확인합니다.

## Dataset과 DatasetDict

`load_dataset("json", data_files=…)`는 JSONL 파일을 `Dataset`으로 불러옵니다. `Dataset`은 열(Column)마다 자료형(Feature)이 정해진 표이며, 디스크의 Apache Arrow 형식을 그대로 쓰므로 큰 데이터도 메모리에 모두 올리지 않고 다룹니다.

**DatasetDict**는 여러 `Dataset`에 이름을 붙여 묶은 것입니다. 학습(train), 검증(validation), 평가(test)를 하나의 객체로 관리합니다.

| 분할 | 쓰임 | 이 장의 크기 |
|---|---|---|
| train | 가중치를 학습한다 | 40 |
| validation | 학습 중에 확인하고 설정(학습률, 단계 수)을 고른다 | 5 |
| test | 모든 결정이 끝난 뒤 한 번만 평가한다 | 5 |

test를 학습 중에 들여다보고 설정을 고르면, 설정이 test에 맞춰져 평가가 낙관적이 됩니다. 그래서 설정을 고르는 일은 validation이 맡고, test는 마지막까지 아껴 둡니다.

이 장은 `train_test_split`을 두 번 써서 seed 0으로 무작위로 나눕니다. 같은 seed면 언제나 같은 분할이 나옵니다. 다만 무작위 분할에는 한계가 있습니다. 실습에서 보듯 분류별 개수가 고르지 않게 나뉘고(train의 설계 기법이 8개 중 4개뿐), 비슷한 질문이 train과 test에 함께 들어갈 수도 있습니다. 제43장에서 주제 단위로 나누는 분할과 누출 검사로 이 분할을 다시 만듭니다.

## map, filter, select

| 연산 | 하는 일 | 이 장의 예 |
|---|---|---|
| `map(함수)` | 샘플마다 함수를 적용해 열을 바꾸거나 더한다 | 제41장의 대화형 `messages` 열 추가 |
| `filter(조건)` | 조건에 맞는 샘플만 남긴다 | 코드가 있는 샘플만 고르기 |
| `select(번호들)` | 지정한 순서의 샘플만 고른다 | 처음 3개로 빠른 시험용 데이터 만들기 |

세 연산은 원래 데이터를 바꾸지 않고 **새 Dataset을 돌려줍니다**. `map`의 결과는 캐시에 저장되어, 같은 함수를 다시 적용하면 계산을 건너뜁니다. 전처리를 이 세 연산의 조합으로 쓰면, 각 단계가 무엇을 했는지 코드에 그대로 남아 다시 실행하기 쉽습니다. 제45장의 토큰화와 Label Masking은 샘플 하나를 받아 학습 배열을 돌려주는 함수로 만들므로, 같은 함수를 `map`에 넘겨 적용할 수도 있습니다.

## 저장과 복원

전처리를 마친 `DatasetDict`는 `save_to_disk`로 폴더에 저장하고, `load_from_disk`로 그대로 복원합니다. 저장된 폴더에는 분할마다 Arrow 파일과 열 정보가 들어 있습니다.

저장해 두는 이유는 **재현성**입니다. 원본을 다시 읽어 나누고 변환해도 같은 결과가 나와야 하지만, 라이브러리 버전이 바뀌거나 전처리 코드를 고치면 미묘하게 달라질 수 있습니다. 학습에 쓴 데이터 그 자체를 저장해 두면, 나중에 결과를 다시 확인할 때 데이터가 같았는지 의심할 필요가 없습니다. 저장한 폴더는 크기가 커질 수 있으므로 저장소에는 넣지 않고(`models/`), 다시 만드는 코드와 원본만 저장소에 둡니다.

## 핵심 실습

파일명: `examples/ch42/hf_datasets.py`

```python
# 제42장 핵심 실습: 제41장 데이터를 JSONL로 저장하고 Hugging Face Datasets로 불러 분할·변환·저장·복원한다
#
# 실행: python examples/ch42/hf_datasets.py
#
# 만드는 파일: datasets/fpga_qa/fpga_qa.jsonl(저장소에 포함), models/fpga_qa_v1(DatasetDict, 저장소 제외)

import csv
import io
import json
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
ROOT = HERE.parents[1]
for p in (HERE.parent, HERE.parent / "ch41"):
    sys.path.insert(0, str(p))

from datasets import DatasetDict, load_dataset, load_from_disk  # noqa: E402

from check_dataset import load, to_structures  # noqa: E402     (제41장)

JSONL = ROOT / "datasets" / "fpga_qa" / "fpga_qa.jsonl"
SAVED = ROOT / "models" / "fpga_qa_v1"
SEED = 0


def write_jsonl(rows: list, path: Path = JSONL) -> None:
    """한 줄에 샘플 하나. 줄바꿈은 JSON 안에서 \\n으로 바뀌어 줄 구분과 섞이지 않는다."""
    with path.open("w", encoding="utf-8") as f:
        for r in rows:
            f.write(json.dumps(r, ensure_ascii=False) + "\n")


def build(jsonl: Path = JSONL) -> DatasetDict:
    ds = load_dataset("json", data_files=str(jsonl), split="train")
    first = ds.train_test_split(test_size=10, seed=SEED)                 # 40 / 10
    second = first["test"].train_test_split(test_size=5, seed=SEED)      # 10 → 5 / 5
    return DatasetDict(train=first["train"], validation=second["train"], test=second["test"])


def add_messages(example: dict) -> dict:
    return {"messages": to_structures(example)["messages"]["messages"]}


def main() -> None:
    rows = load()
    print("── 1. CSV와 JSON, JSONL ──")
    sample = next(r for r in rows if "\n" in r["input"])
    buf = io.StringIO()
    csv.DictWriter(buf, fieldnames=list(sample)).writerows([sample])
    print(f"  CSV 한 샘플이 차지하는 줄 수: {len(buf.getvalue().splitlines())}  (코드 속 줄바꿈 때문에 여러 줄)")
    write_jsonl(rows)
    lines = JSONL.read_text(encoding="utf-8").splitlines()
    print(f"  JSONL 줄 수 {len(lines)} = 샘플 수 {len(rows)}, 파일 {JSONL.stat().st_size:,}바이트")
    print(f"  첫 줄 앞부분: {lines[0][:70]}…")

    print("\n── 2. Dataset과 DatasetDict ──")
    dd = build()
    print(f"  {dd}".replace("\n", "\n  "))
    print(f"  Features: {dd['train'].features}")

    print("\n── 3. map·filter·select ──")
    dd = dd.map(add_messages)
    print(f"  map 후 열: {dd['train'].column_names}")
    code_only = dd["train"].filter(lambda e: e["input"] != "")
    print(f"  filter(코드가 있는 샘플): train {len(code_only)}개 → {list(code_only['id'])}")
    small = dd["train"].select(range(3))
    print(f"  select(처음 3개): {list(small['id'])}")
    cats = list(dd["train"]["category"])
    by_cat = {c: cats.count(c) for c in sorted(set(cats))}
    print(f"  train 분류별 개수: {by_cat}")

    print("\n── 4. 저장과 복원 ──")
    dd.save_to_disk(str(SAVED))
    back = load_from_disk(str(SAVED))
    same = all(back[s].to_list() == dd[s].to_list() for s in dd)
    print(f"  분할별 샘플 수 {[(s, len(back[s])) for s in back]}")
    print(f"  복원 결과가 저장 전과 완전히 같음: {same}")
    print(f"  분할 id(같은 seed면 언제나 같다): validation {list(back['validation']['id'])}, test {list(back['test']['id'])}")


if __name__ == "__main__":
    main()
```

# 제42장 검증 테스트

import json
import sys
from pathlib import Path

import pytest

HERE = Path(__file__).resolve().parent
for p in (HERE, HERE.parent, HERE.parent / "ch41"):
    sys.path.insert(0, str(p))

pytest.importorskip("datasets")

from check_dataset import load  # noqa: E402
from hf_datasets import add_messages, build, write_jsonl  # noqa: E402


def test_jsonl_roundtrip(tmp_path):
    rows = load()
    path = tmp_path / "a.jsonl"
    write_jsonl(rows, path)
    lines = path.read_text(encoding="utf-8").splitlines()
    assert len(lines) == 50 and [json.loads(x) for x in lines] == rows


def test_split_is_disjoint_and_reproducible(tmp_path):
    path = tmp_path / "a.jsonl"
    write_jsonl(load(), path)
    a, b = build(path), build(path)
    ids = {s: set(a[s]["id"]) for s in a}
    assert [len(a[s]) for s in ("train", "validation", "test")] == [40, 5, 5]
    assert not (ids["train"] & ids["validation"] or ids["train"] & ids["test"] or ids["validation"] & ids["test"])
    assert all(list(a[s]["id"]) == list(b[s]["id"]) for s in a)


def test_map_filter_select_and_save(tmp_path):
    from datasets import load_from_disk
    path = tmp_path / "a.jsonl"
    write_jsonl(load(), path)
    dd = build(path).map(add_messages)
    assert dd["train"][0]["messages"][1]["content"] == dd["train"][0]["output"]
    assert len(dd["train"].filter(lambda e: e["input"] != "")) <= 5
    assert len(dd["train"].select(range(3))) == 3
    dd.save_to_disk(str(tmp_path / "saved"))
    back = load_from_disk(str(tmp_path / "saved"))
    assert all(back[s].to_list() == dd[s].to_list() for s in dd)


def test_committed_jsonl_matches_source():
    jsonl = HERE.parents[1] / "datasets" / "fpga_qa" / "fpga_qa.jsonl"
    rows = [json.loads(x) for x in jsonl.read_text(encoding="utf-8").splitlines()]
    assert rows == load()                       # 원본(json)과 변환본(jsonl)이 어긋나지 않음

## 핵심 정리

- JSONL은 한 줄에 샘플 하나를 두어, 줄바꿈이 있는 데이터도 줄 수 = 샘플 수가 됩니다. 학습 데이터의 표준 형식입니다.
- `Dataset`은 열과 자료형이 정해진 표이고, `DatasetDict`는 train·validation·test를 하나로 묶습니다. 설정은 validation으로 고르고 test는 마지막에 한 번 씁니다.
- 전처리는 `map`(변환·추가), `filter`(거르기), `select`(고르기)로 구성하며, 원래 데이터는 바뀌지 않습니다.
- 전처리 결과는 `save_to_disk`로 저장하고 `load_from_disk`로 복원해, 매번 같은 데이터로 학습합니다.
- 무작위 분할은 분류가 고르지 않게 나뉘고 비슷한 문항이 섞일 수 있습니다. 제43장에서 개선합니다.

**다음 장 연결:** 제43장에서는 데이터의 중복과 유사 문항을 찾아내고, 비슷한 문항이 train과 test에 함께 들어가지 않도록 주제 단위로 다시 나누며, 이후 장의 학습 결과를 판정할 평가 지표와 합격 기준을 실험 전에 미리 적어 둡니다.
