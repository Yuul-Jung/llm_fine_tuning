## 장 개요

제05장의 Linear Layer는 강력하지만 한계가 하나 있습니다. 아무리 여러 겹 쌓아도 결국 **Linear 하나와 같은 일**밖에 못 한다는 것입니다. 이 장은 그 한계를 깨는 활성화 함수(Activation Function)를 다루고, 모델의 마지막 점수를 확률로 바꾸는 Softmax를 직접 구현합니다.

Softmax는 짧은 수식이지만, 정의 그대로 구현하면 큰 숫자에서 계산이 무너집니다. 이 장의 핵심 실습은 그 실패를 직접 재현하고, 한 줄의 처방으로 바로잡는 과정입니다. 이론으로는 같은 식이 컴퓨터에서는 다르게 동작할 수 있다는 것, 이것이 이 장이 전하려는 실사구시의 감각입니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 왜 비선형 함수가 필요하며, Softmax는 어떻게 안전하게 계산하는가 |
| 실습 결과물 | 활성화 함수 비교표와 그래프, 단순·안정화 Softmax 비교 |
| 실습 파일 | `examples/ch06/`의 `activations.py`, `softmax_stable.py`, `test_ch06.py` |
| 선수 장 | 제04장(행렬곱), 제05장(Linear Layer) |

```text
[한계] Linear → Linear = Linear 하나 (아무리 쌓아도 직선)
   ↓
[해결] 사이에 비선형 함수: Sigmoid · ReLU · GELU · SiLU
   ↓
[출력] 점수(Logits) → Softmax → 합이 1인 확률
   ↓
[핵심 실습] 큰 점수에서 단순 Softmax 실패 → 최댓값 빼기로 해결
```

## 비선형이 필요한 이유

Linear 두 개를 연달아 적용하면 어떻게 될까요? 수식을 펼쳐 보면 답이 보입니다.

```text
h = x W₁ᵀ + b₁                       첫 번째 Linear
y = h W₂ᵀ + b₂                       두 번째 Linear
  = (x W₁ᵀ + b₁) W₂ᵀ + b₂
  = x (W₂W₁)ᵀ + (W₂b₁ + b₂)          ← 가중치 W₂W₁, 편향 W₂b₁+b₂인 Linear 하나
```

두 층이 한 층으로 합쳐집니다. 열 층을 쌓아도 마찬가지입니다. 가중치는 늘었지만 표현할 수 있는 관계는 여전히 "직선(선형)"뿐입니다. 언어처럼 복잡한 관계는 직선으로 그릴 수 없습니다.

해법은 Linear 사이에 **곡선 함수**를 끼워 넣는 것입니다. 이 함수가 활성화 함수입니다. 활성화 함수가 들어가면 두 층은 더 이상 하나로 합쳐지지 않고, 층을 쌓을수록 더 복잡한 관계를 표현할 수 있게 됩니다. 핵심 실습 1에서 이 차이를 숫자로 확인합니다.

## Sigmoid, ReLU, GELU, SiLU

활성화 함수는 여러 가지가 있지만, 이 교재에서 알아야 할 것은 네 가지입니다.

| 함수 | 수식 | 특징과 쓰이는 곳 |
|---|---|---|
| Sigmoid | `1 / (1 + e⁻ˣ)` | 0과 1 사이로 눌러 담는다. 게이트, 이진 확률 |
| ReLU | `max(0, x)` | 음수는 0, 양수는 그대로. 고전적 신경망 |
| GELU | `x · Φ(x)` | ReLU를 부드럽게 만든 형태. GPT·BERT 계열 |
| SiLU | `x · σ(x)` | 자기 자신의 Sigmoid를 곱한다. **Qwen2.5**, Llama 계열 |

`Φ(x)`는 표준정규분포에서 `x` 이하일 확률이고, `σ(x)`는 Sigmoid입니다.

```text
          ReLU            GELU / SiLU
  y │        ╱      y │         ╱
    │       ╱         │        ╱
    │      ╱          │      ╱
 ───┼─────╱───     ───┼───╲_╱────
    │                 │   (음수 쪽에 살짝 패인 곡선)
```

ReLU는 0에서 꺾이고, GELU와 SiLU는 그 꺾임을 부드러운 곡선으로 바꿉니다. 부드러운 곡선은 어느 지점에서나 기울기가 정의되어 학습이 안정적입니다. 음수 쪽이 완전히 0이 아니라 살짝 음수로 내려간다는 점도 ReLU와 다릅니다.

Qwen2.5의 `config.json`에는 `"hidden_act": "silu"`라고 적혀 있습니다. 이 교재에서 가장 중요한 활성화 함수는 SiLU이며, 제17장 FFN의 SwiGLU에서 다시 만납니다.

## Softmax와 확률분포

모델의 마지막 계층은 어휘의 모든 토큰에 대해 **점수(Logits)**를 냅니다. Qwen2.5라면 151,936개의 점수입니다. 이 점수는 음수도 있고, 합도 제멋대로입니다. 다음 토큰을 고르려면 이 점수를 **확률**로 바꿔야 합니다.

Softmax는 두 단계로 이 일을 합니다.

```text
① 지수함수로 모두 양수로 만든다      eˣ¹, eˣ², eˣ³ …
② 전체 합으로 나눠 합을 1로 만든다    pᵢ = eˣⁱ / Σⱼ eˣʲ

예) 점수 [1, 2, 3]
    e¹ = 2.72,  e² = 7.39,  e³ = 20.09      합 30.19
    확률 = [0.090, 0.245, 0.665]             합 1
```

| 성질 | 의미 |
|---|---|
| 모든 확률이 0과 1 사이 | 지수함수는 항상 양수 |
| 확률의 합은 정확히 1 | 전체 합으로 나눴기 때문 |
| 점수 순서가 확률 순서 | 큰 점수가 큰 확률 |
| 점수 차이가 크면 쏠림 | 지수함수가 차이를 크게 벌림 |

마지막 성질이 중요합니다. 점수 `[1, 2, 3]`은 1씩 차이 나지만 확률은 약 2.7배씩 차이 납니다. 점수 차이가 10이면 확률은 약 22,000배 차이가 납니다. 제04장에서 "내적의 분산이 크면 Softmax가 한쪽으로 쏠린다"고 한 이유가 바로 이 성질입니다.

## 수치적으로 안정적인 Softmax

정의 그대로의 Softmax에는 함정이 있습니다. FP32가 표현할 수 있는 가장 큰 수는 약 3.4 × 10³⁸인데, `e⁸⁹`만 되어도 이 한계를 넘습니다. 점수가 1000이면 `e¹⁰⁰⁰`은 무한대(`inf`)가 되고, 무한대를 무한대로 나누면 숫자가 아닌 값(`nan`)이 됩니다.

해법은 놀랍도록 간단합니다. **지수함수에 넣기 전에 최댓값을 빼는 것**입니다.

```text
eˣⁱ / Σ eˣʲ  =  eˣⁱ⁻ᵐ / Σ eˣʲ⁻ᵐ        (m은 아무 상수, 분자·분모에 e⁻ᵐ을 곱한 것)

m = max(x)로 고르면
  가장 큰 값 → e⁰ = 1               넘칠 수 없음
  나머지 값  → e^(음수) ≤ 1          넘칠 수 없음
```

수학적으로는 완전히 같은 식이지만, 컴퓨터에서는 언제나 안전하게 계산됩니다. PyTorch의 `torch.softmax`도 내부에서 같은 방식을 씁니다. 같은 이유로 어떤 점수에 같은 값을 더하거나 빼도 Softmax 결과는 변하지 않습니다. 점수 `[1000, 1001, 1002]`와 `[1, 2, 3]`의 확률이 같은 이유입니다.

### 실습 1. 활성화 함수 비교와 Linear 합쳐짐 확인

파일명: `examples/ch06/activations.py`

```python
# 제06장 실습 1: 비선형이 필요한 이유와 활성화 함수 직접 구현
#
# 실행: python examples/ch06/activations.py
# 결과: 화면 비교표 + examples/ch06/activations.png(matplotlib이 있으면)

import math
from pathlib import Path

import torch
import torch.nn.functional as F


def sigmoid(x: torch.Tensor) -> torch.Tensor:
    """0과 1 사이로 눌러 담는다: 1 / (1 + e^(-x))"""
    return 1 / (1 + torch.exp(-x))


def relu(x: torch.Tensor) -> torch.Tensor:
    """음수는 0, 양수는 그대로: max(0, x)"""
    return torch.clamp(x, min=0)


def gelu(x: torch.Tensor) -> torch.Tensor:
    """x에 '정규분포에서 x 이하일 확률'을 곱한다: x · Φ(x)"""
    return x * 0.5 * (1 + torch.erf(x / math.sqrt(2)))


def silu(x: torch.Tensor) -> torch.Tensor:
    """x에 자기 자신의 sigmoid를 곱한다: x · σ(x)  (Qwen2.5가 쓰는 활성화 함수)"""
    return x * sigmoid(x)


def two_linears(x, w1, b1, w2, b2, activation=None):
    """Linear → (활성화) → Linear"""
    h = x @ w1.T + b1
    if activation is not None:
        h = activation(h)
    return h @ w2.T + b2


def main() -> None:
    print("── 1. Linear 두 개는 Linear 하나와 같다 ──")
    torch.manual_seed(0)
    w1, b1 = torch.randn(5, 3), torch.randn(5)
    w2, b2 = torch.randn(2, 5), torch.randn(2)
    x = torch.randn(4, 3)
    # 합친 가중치: W = W2·W1,  합친 편향: b = W2·b1 + b2
    w, b = w2 @ w1, w2 @ b1 + b2
    stacked = two_linears(x, w1, b1, w2, b2)
    merged = x @ w.T + b
    print(f"두 층 결과와 한 층 결과의 최대 차이: {(stacked - merged).abs().max().item():.2e}")
    with_relu = two_linears(x, w1, b1, w2, b2, activation=relu)
    print(f"사이에 ReLU를 넣으면 최대 차이: {(with_relu - merged).abs().max().item():.2f}")

    print("\n── 2. 활성화 함수 값 비교 ──")
    points = torch.tensor([-3.0, -1.0, 0.0, 1.0, 3.0])
    table = {
        "Sigmoid": (sigmoid, torch.sigmoid),
        "ReLU": (relu, F.relu),
        "GELU": (gelu, F.gelu),
        "SiLU": (silu, F.silu),
    }
    print(f"{'x':>8}" + "".join(f"{v:>9.1f}" for v in points.tolist()))
    for name, (mine, ref) in table.items():
        values = mine(points)
        error = (values - ref(points)).abs().max().item()
        print(f"{name:>8}" + "".join(f"{v:>9.4f}" for v in values.tolist())
              + f"   (PyTorch와 최대 차이 {error:.1e})")

    try:
        import matplotlib
        matplotlib.use("Agg")
        import matplotlib.pyplot as plt
    except ImportError:
        return
    xs = torch.linspace(-4, 4, 200)
    for name, (mine, _) in table.items():
        plt.plot(xs, mine(xs), label=name)
    plt.axhline(0, color="gray", linewidth=0.5)
    plt.axvline(0, color="gray", linewidth=0.5)
    plt.legend()
    plt.grid(True, alpha=0.3)
    out = Path(__file__).with_name("activations.png")
    plt.savefig(out, dpi=120, bbox_inches="tight")
    print(f"\n그래프 저장: {out.name}")


if __name__ == "__main__":
    main()
```

### 실습 2. 단순 Softmax의 실패와 안정화

파일명: `examples/ch06/softmax_stable.py`

```python
# 제06장 핵심 실습: 단순 Softmax의 실패와 안정화 Softmax
#
# 실행: python examples/ch06/softmax_stable.py

import torch


def softmax_naive(x: torch.Tensor, dim: int = -1) -> torch.Tensor:
    """정의 그대로: e^xᵢ / Σ e^xⱼ"""
    e = torch.exp(x)
    return e / e.sum(dim=dim, keepdim=True)


def softmax_stable(x: torch.Tensor, dim: int = -1) -> torch.Tensor:
    """최댓값을 먼저 빼고 계산한다. 결과는 수학적으로 같지만 exp가 넘치지 않는다."""
    shifted = x - x.max(dim=dim, keepdim=True).values
    e = torch.exp(shifted)
    return e / e.sum(dim=dim, keepdim=True)


def main() -> None:
    print("── 1. 작은 값: 두 방법 모두 정상 ──")
    small = torch.tensor([1.0, 2.0, 3.0])
    print("단순  :", softmax_naive(small))
    print("안정화:", softmax_stable(small))

    print("\n── 2. 큰 값: 단순 Softmax는 실패 ──")
    large = torch.tensor([1000.0, 1001.0, 1002.0])
    print("exp(1000) =", torch.exp(torch.tensor(1000.0)).item())
    print("단순  :", softmax_naive(large))
    print("안정화:", softmax_stable(large))
    print("torch :", torch.softmax(large, dim=-1))

    print("\n── 3. 최댓값을 빼도 결과가 같은 이유 ──")
    shifted = large - large.max()
    print("[1000, 1001, 1002] - 1002 =", shifted)
    print("[1, 2, 3] - 3             =", small - small.max())
    print("두 입력은 최댓값을 뺀 뒤 같아지므로 Softmax 결과도 같다.")

    print("\n── 4. FP32의 exp가 넘치는 경계 ──")
    for v in (88.0, 88.7, 89.0):
        print(f"exp({v}) = {torch.exp(torch.tensor(v)).item()}")

    print("\n── 5. 실제 어휘 크기(151,936)의 확률분포 ──")
    torch.manual_seed(0)
    logits = torch.randn(151936) * 10
    p = softmax_stable(logits)
    top = torch.topk(p, 3)
    print(f"확률 합: {p.sum().item():.6f},  최대 확률: {top.values[0].item():.4f}")
    print(f"확률이 가장 높은 토큰 ID 3개: {top.indices.tolist()}")


if __name__ == "__main__":
    main()
```

**핵심 코드 풀이**

- `softmax_naive()`는 정의 그대로입니다. 1번처럼 점수가 작으면 정상이지만, 2번처럼 점수가 1000 근처가 되면 `exp(1000) = inf`가 되어 결과가 모두 `nan`이 됩니다.
- `softmax_stable()`은 `x.max(dim, keepdim=True)`로 최댓값을 구해 먼저 뺍니다. `keepdim=True`는 최댓값의 모양을 `[..., 1]`로 유지해, 제04장의 Broadcasting으로 모든 칸에서 뺄 수 있게 합니다.
- 3번은 최댓값을 뺀 뒤 두 입력이 똑같아지는 것을 보여 줍니다. 그래서 2번의 안정화 결과가 1번과 소수점까지 같습니다.
- 4번은 FP32의 한계를 직접 확인합니다. `exp(88.7)`까지는 표현되지만 `exp(89)`는 무한대가 됩니다. 점수가 89만 넘어도 단순 Softmax는 무너진다는 뜻입니다.
- 5번은 실제 Qwen의 어휘 크기 151,936개로 확률분포를 만듭니다. 15만 개가 넘는 확률의 합이 정확히 1이고, 점수 차이가 크면 한 토큰에 확률이 크게 몰리는(0.7191) 쏠림도 볼 수 있습니다. 이 확률에서 다음 토큰을 고르는 방법은 제07장에서 다룹니다.

from pathlib import Path

import torch

@pytest.mark.parametrize("mine, ref", [
    (sigmoid, torch.sigmoid), (relu, F.relu), (gelu, F.gelu), (silu, F.silu)])
def test_activation_matches_torch(mine, ref):
    x = torch.linspace(-6, 6, 101)
    torch.testing.assert_close(mine(x), ref(x))


def test_activation_hand_values():
    assert sigmoid(torch.tensor(0.0)).item() == 0.5
    assert relu(torch.tensor(-2.0)).item() == 0.0
    assert silu(torch.tensor(0.0)).item() == 0.0


def test_linear_stack_collapses_without_activation():
    torch.manual_seed(0)
    w1, b1, w2, b2 = torch.randn(5, 3), torch.randn(5), torch.randn(2, 5), torch.randn(2)
    x = torch.randn(4, 3)
    merged = x @ (w2 @ w1).T + (w2 @ b1 + b2)
    torch.testing.assert_close(two_linears(x, w1, b1, w2, b2), merged)
    assert not torch.allclose(two_linears(x, w1, b1, w2, b2, activation=relu), merged)


def test_softmax_sums_to_one_and_matches_torch():
    torch.manual_seed(0)
    x = torch.randn(3, 10) * 5
    p = softmax_stable(x)
    torch.testing.assert_close(p.sum(dim=-1), torch.ones(3))
    torch.testing.assert_close(p, torch.softmax(x, dim=-1))


def test_naive_fails_stable_succeeds_on_large_logits():
    large = torch.tensor([1000.0, 1001.0, 1002.0])
    assert torch.isnan(softmax_naive(large)).any()
    torch.testing.assert_close(softmax_stable(large), torch.softmax(large, dim=-1))


def test_shift_invariance():
    x = torch.tensor([1.0, 2.0, 3.0])
    torch.testing.assert_close(softmax_stable(x), softmax_stable(x + 1000))

## 핵심 정리

- Linear만 쌓으면 Linear 하나와 같습니다. 사이에 비선형 활성화 함수를 넣어야 층을 쌓는 의미가 생깁니다.
- Qwen2.5는 SiLU(`x · σ(x)`)를 씁니다. 0 근처에서 부드럽게 꺾이고 음수 쪽이 살짝 패인 곡선입니다.
- Softmax는 지수함수와 전체 합 나누기로 점수를 합이 1인 확률로 바꿉니다. 점수 차이를 지수적으로 벌립니다.
- 단순 Softmax는 점수가 89만 넘어도 FP32에서 무너집니다. 최댓값을 먼저 빼면 같은 결과를 안전하게 얻습니다.

**다음 장 연결:** 이제 점수를 확률로 바꿀 수 있습니다. 제07장에서는 이 확률로 **다음 토큰을 고르고, 고른 토큰을 다시 입력에 붙이는** 자기회귀 생성의 원리를 Bigram 언어 모델로 직접 구현합니다.
