## 장 개요

제22~24장에서 학습의 재료를 모두 갖췄습니다. 손실을 재고(제22장), Gradient를 구하고(제23장), Optimizer로 가중치를 고칩니다(제24장). 이 장에서는 이 재료로 제19장의 **무작위 Qwen2-Tiny를 처음부터 학습**합니다. 아무것도 모르던 모델이 고정 데이터의 문장을 배워 가는 과정을 손실 곡선으로 지켜보고, 사전학습한 모델을 저장했다가 다시 불러 새로운 분야(자전거 정비)로 **Full Fine-tuning**합니다.

이 장은 LLM이 만들어지는 두 단계(제21장)를 아주 작은 크기로 직접 재현하는 장입니다. 그리고 이 과정에서 학습의 대표적인 두 가지 함정, **과적합**과 **망각**을 숫자로 만납니다.

| 구분 | 내용 |
|---|---|
| 핵심 질문 | 무작위 모델은 어떻게 언어를 배우며, 배운 모델을 새 분야에 맞추면 무엇을 얻고 잃는가 |
| 실습 결과물 | 사전학습·Full FT 손실 기록과 곡선, 저장·재로딩 일치 확인, 학습 전후 PPL 비교, 메모리 측정 |
| 실습 파일 | `examples/ch25/`의 `trainer.py`, `pretrain_tiny.py`, `test_ch25.py`, 도메인 데이터 `datasets/fixed/domain_*.txt` |
| 선수 장 | 제19장(Qwen2-Tiny), 제21장(고정 데이터), 제22~24장(손실·Gradient·Optimizer) |

```text
무작위 Qwen2-Tiny ──사전학습(고정 데이터)──▶ 저장 ──재로딩──▶ Full FT(자전거 정비) ──▶ 저장
   손실 ≈ 12.0              손실 ≈ 5.6     같은 출력          도메인 PPL ↓, 일반 PPL ↑
```

## 학습 루프 구성

학습은 같은 동작의 반복입니다. 이 장에서 그 반복을 `train()` 함수 하나로 만들어, 제26장 이후의 부분 학습과 LoRA 학습에서도 그대로 씁니다.

```text
한 단계:
  ① 묶음 꺼내기       무작위로 블록 2개(Batch 2)
  ② 순전파·손실       model(input_ids=x, labels=x).loss   (제22장의 한 칸 이동 포함)
  ③ 역전파            loss.backward()                     (제23장)
     (①~③을 accum번 반복해 Gradient를 더함)
  ④ Clipping          Gradient 전체 노름을 1.0 이하로
  ⑤ 갱신              optimizer.step(), scheduler.step()  (제24장)
  ⑥ 초기화            optimizer.zero_grad()
```

`train()`은 `requires_grad=True`인 파라미터만 Optimizer에 넘깁니다. 지금은 모든 파라미터가 대상이지만, 제26장에서 일부를 얼리면 같은 함수가 자동으로 나머지만 학습합니다.

일정한 간격마다 학습률, 학습 손실, Gradient 노름, 평가 손실을 기록합니다. 학습이 잘 되는지는 이 기록으로만 판단할 수 있습니다. 평가 손실을 잴 때는 `model.eval()`과 `torch.no_grad()`로 학습 상태를 건드리지 않습니다.

## Scheduler, Accumulation, Clipping 적용

제24장에서 목적만 정리한 세 기법을 실제로 적용합니다.

| 기법 | 이 장의 설정 | 기록에서 볼 곳 |
|---|---|---|
| Warmup + Cosine | 사전학습 Warmup 20단계, 최대 학습률 1e-3 | 학습률 열이 0에서 올랐다가 0으로 내려간다 |
| Accumulation | Batch 2 × 2번 = 유효 묶음 4 | 메모리는 묶음 2개분만 쓴다 |
| Clipping | 노름 1.0 | Grad노름 열은 **자르기 전** 값이다 |

Grad노름 열에 1.0보다 큰 값이 보이면, 그 단계에서 Clipping이 Gradient를 줄였다는 뜻입니다. 학습 초반이나 학습률이 높은 구간에서 크게 나타나고, 학습이 안정되면 작아집니다. Gradient 노름이 갑자기 수십, 수백으로 치솟거나 NaN이 되면 학습이 무너지는 신호이므로, `train()`은 NaN·Inf를 만나면 즉시 멈추게 했습니다.

## 소규모 사전학습

설계서의 GT 1030 기준대로 FP32, 시퀀스 128, Batch 2로 학습합니다. 고정 학습 데이터는 블록 25개뿐이므로, 300단계 × 유효 묶음 4 = 1,200블록, 즉 약 48 Epoch을 학습합니다.

이 규모는 진짜 사전학습과 비교하면 장난감입니다. Qwen2.5가 18조 토큰을 본 데 비해 우리는 3,300토큰을 48번 봅니다. 그래도 원리는 같습니다. 무작위 모델의 손실 12(어휘를 고르게 찍는 수준)가 내려가는 것은, 모델이 한국어 토큰의 분포와 문장 패턴을 배우고 있다는 뜻입니다.

데이터가 작은 만큼 **과적합**이 빨리 옵니다. 학습 손실은 계속 내려가지만, 어느 순간부터 평가 손실은 다시 올라갑니다. 학습 데이터를 외우기 시작한 것입니다. 실제 학습에서는 평가 손실이 가장 낮았던 지점의 Checkpoint를 고르거나, 그 지점에서 학습을 멈춥니다(Early Stopping).

## Hugging Face 형식 저장

사전학습을 마친 모델은 제19장과 같은 Hugging Face 형식으로 저장합니다.

```text
models/qwen2-tiny-pretrained/
  config.json            구조(hidden 256, 계층 4, …)
  model.safetensors      가중치(공유 텐서는 한 번만)
  generation_config.json 생성 기본값
  tokenizer.json 등      Qwen2.5 토크나이저
```

이 폴더 하나가 이후 모든 도구의 입력이 됩니다. `from_pretrained`로 다시 부르면 Full FT를, PEFT(제30장)로 부르면 LoRA를, 제6부의 변환 도구로 부르면 GGUF를 만들 수 있습니다. 저장이 제대로 되었는지는 **재로딩 전후의 출력이 비트 하나까지 같은지**로 확인합니다.

## Full Fine-tuning

사전학습한 모델을 다시 불러 **자전거 정비** 분야의 문장(학습 8블록, 평가 1블록)으로 모든 가중치를 다시 학습합니다. 이것이 Full Fine-tuning입니다. 사전학습보다 작은 학습률(3e-4)과 짧은 학습(60단계)을 씁니다. 이미 배운 것을 크게 흔들지 않고 새 분야에 맞추기 위해서입니다.

평가는 두 가지로 합니다. 새 분야를 배웠는지 보는 **도메인 평가**, 원래 알던 것을 잊지 않았는지 보는 **일반 평가**입니다. 파인튜닝은 언제나 이 두 숫자를 함께 봐야 합니다. 도메인 손실만 내려가고 일반 손실이 크게 오른다면, 모델은 새것을 배우는 대신 옛것을 잊은 것입니다. 이 현상을 **파국적 망각**(Catastrophic Forgetting)이라 합니다.

## 0.5B Full FT 메모리 계산

Qwen2-Tiny의 Full FT는 가중치·Gradient·AdamW 상태를 합쳐 640MiB의 고정 메모리가 필요하고, 활성값을 더해도 설계 예산(GT 1030 VRAM 2GB 중 약 1.5GB)에 들어갑니다. 같은 계산을 Qwen2.5-0.5B에 적용하면 다음과 같습니다.

```text
가중치     494,032,768 × 4바이트 = 1.84GiB
Gradient   494,032,768 × 4바이트 = 1.84GiB
AdamW 상태 494,032,768 × 8바이트 = 3.68GiB
───────────────────────────────────────────
합계                               7.36GiB   + 활성값  >  GT 1030 2GiB
```

가중치만으로 이미 2GiB에 가깝습니다. 0.5B 모델의 Full Fine-tuning은 GT 1030에서 **실행 불가**로 판정합니다. 메모리가 충분한 CPU에서는 가능하지만 매우 느립니다. 이 제약이 제26장부터 다루는 PEFT와 LoRA의 출발점입니다.

## 핵심 실습

### 학습 루프

파일명: `examples/ch25/trainer.py`

```python
# 제25장: 제3·4부 학습 실습이 함께 쓰는 학습 루프
#
# 한 단계 = (묶음 accum개) × [순전파 → 손실 ÷ accum → 역전파]
#           → Gradient Clipping → optimizer.step → scheduler.step → zero_grad

import math
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "ch24"))

import torch  # noqa: E402

from optim_memory import warmup_cosine  # noqa: E402  (제24장)


@torch.no_grad()
def eval_loss(model, blocks: torch.Tensor, device: str) -> float:
    """블록마다 모델의 평균 손실을 구해 다시 평균(블록마다 유효 토큰 수가 같으므로 전체 평균과 같다)"""
    was_training = model.training
    model.eval()
    losses = [model(input_ids=b.to(device), labels=b.to(device)).loss.item() for b in blocks.split(1)]
    model.train(was_training)
    return sum(losses) / len(losses)


def train(model, train_blocks, eval_sets: dict, *, steps: int, batch: int = 2, accum: int = 2,
          lr: float = 1e-3, warmup: int = 10, clip: float = 1.0, weight_decay: float = 0.1,
          device: str = "cpu", seed: int = 0, log_every: int = 25) -> list:
    """학습 가능한(requires_grad=True) 파라미터만 AdamW로 학습하고 기록(list of dict)을 돌려준다."""
    torch.manual_seed(seed)
    g = torch.Generator().manual_seed(seed)
    model.to(device).train()
    params = [p for p in model.parameters() if p.requires_grad]
    opt = torch.optim.AdamW(params, lr=lr, weight_decay=weight_decay)
    sched = torch.optim.lr_scheduler.LambdaLR(opt, lambda s: warmup_cosine(s, warmup, steps))

    def record(step, train_loss, grad_norm):
        row = {"step": step, "lr": opt.param_groups[0]["lr"], "train": train_loss, "grad_norm": grad_norm}
        for name, blocks in eval_sets.items():
            row[name] = eval_loss(model, blocks, device)
        return row

    history = [record(0, float("nan"), float("nan"))]
    for step in range(1, steps + 1):
        total = 0.0
        for _ in range(accum):                                       # Gradient Accumulation
            idx = torch.randint(0, len(train_blocks), (batch,), generator=g)
            x = train_blocks[idx].to(device)
            loss = model(input_ids=x, labels=x).loss / accum
            loss.backward()
            total += loss.item()
        grad_norm = torch.nn.utils.clip_grad_norm_(params, clip).item()   # 자르기 전 노름
        if not math.isfinite(grad_norm):
            raise RuntimeError(f"{step}단계에서 Gradient가 NaN·Inf")
        opt.step()
        sched.step()
        opt.zero_grad(set_to_none=True)
        if step % log_every == 0 or step == steps:
            history.append(record(step, total, grad_norm))
    model.eval()
    return history
```

### 사전학습 → 저장 → 재로딩 → Full Fine-tuning

파일명: `examples/ch25/pretrain_tiny.py`

```python
# 제25장 핵심 실습: Qwen2-Tiny 사전학습 → 저장 → 재로딩 → Full Fine-tuning
#
# 실행: python examples/ch25/pretrain_tiny.py
#
# 저장: models/qwen2-tiny-pretrained/, models/qwen2-tiny-bike/ (.gitignore로 커밋 제외)
# 손실 곡선: examples/ch25/loss_curve.png (.gitignore로 커밋 제외)

import json
import math
import resource
import sys
import time
from pathlib import Path

HERE = Path(__file__).resolve().parent
for p in (HERE, HERE.parent, HERE.parent / "ch19", HERE.parent / "ch24"):
    sys.path.insert(0, str(p))

import torch  # noqa: E402
from transformers import Qwen2ForCausalLM  # noqa: E402
from transformers.utils import logging  # noqa: E402

from common.device import select_device  # noqa: E402
from common.fixed_data import load_blocks  # noqa: E402
from common.qwen import load_tokenizer  # noqa: E402
from hf_compat import to_hf  # noqa: E402              (제19장)
from optim_memory import full_ft_budget  # noqa: E402  (제24장)
from tiny_model import Qwen2Tiny, init_weights  # noqa: E402
from trainer import eval_loss, train  # noqa: E402

logging.disable_progress_bar()
MODELS = HERE.parents[1] / "models"
PRE_STEPS, FT_STEPS = 300, 60


def show(history: list, keys: tuple) -> None:
    print("  " + f"{'단계':>5}{'학습률':>9}{'학습':>8}{'Grad노름':>10}" + "".join(f"{k:>9}" for k in keys))
    for r in history:
        print("  " + f"{r['step']:>5}{r['lr']:>9.1e}{r['train']:>8.3f}{r['grad_norm']:>10.2f}"
              + "".join(f"{r[k]:>9.3f}" for k in keys))


def plot(pre: list, ft: list, path: Path) -> None:
    try:
        import matplotlib
        matplotlib.use("Agg")
        import matplotlib.pyplot as plt
    except ImportError:
        return
    fig, ax = plt.subplots(figsize=(7, 4))
    ax.plot([r["step"] for r in pre], [r["일반평가"] for r in pre], label="pretrain: eval")
    ax.plot([r["step"] for r in pre[1:]], [r["train"] for r in pre[1:]], label="pretrain: train")
    off = pre[-1]["step"]
    ax.plot([off + r["step"] for r in ft], [r["도메인평가"] for r in ft], label="full FT: domain eval")
    ax.plot([off + r["step"] for r in ft], [r["일반평가"] for r in ft], label="full FT: general eval")
    ax.set_xlabel("step")
    ax.set_ylabel("loss")
    ax.legend()
    fig.tight_layout()
    fig.savefig(path, dpi=120)


def main() -> None:
    device, _ = select_device()
    tok = load_tokenizer()
    data = {s: load_blocks(tok, s) for s in ("train", "eval", "domain_train", "domain_eval")}
    print(f"장치 {device}, 블록: " + ", ".join(f"{k} {tuple(v.shape)}" for k, v in data.items()))

    model = to_hf(init_weights(Qwen2Tiny(), seed=0))
    trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
    print(f"학습 가능 파라미터 {trainable:,}개(전체), FP32·AdamW 고정 메모리 "
          f"{sum(full_ft_budget(trainable, 'AdamW').values()) / 2**20:.0f}MiB\n")

    print(f"── 1. 사전학습: Batch 2 × Accumulation 2 = 유효 4, {PRE_STEPS}단계, lr 1e-3, Warmup 20 ──")
    t0 = time.perf_counter()
    pre = train(model, data["train"], {"일반평가": data["eval"]}, steps=PRE_STEPS,
                lr=1e-3, warmup=20, device=device, log_every=50)
    show(pre, ("일반평가",))
    print(f"  걸린 시간 {time.perf_counter() - t0:.0f}초")

    print("\n── 2. Hugging Face 형식 저장 → 재로딩 → 출력 비교 ──")
    pre_dir = MODELS / "qwen2-tiny-pretrained"
    model.save_pretrained(pre_dir)
    tok.save_pretrained(pre_dir)
    reloaded = Qwen2ForCausalLM.from_pretrained(pre_dir, dtype=torch.float32).to(device).eval()
    probe = data["eval"][:1].to(device)
    with torch.no_grad():
        same = torch.equal(model(probe).logits, reloaded(probe).logits)
    print(f"  저장 파일 {sorted(f.name for f in pre_dir.iterdir())}")
    print(f"  재로딩 전후 Logits 완전히 같음: {same}")

    before = {k: eval_loss(reloaded, data[k], device) for k in ("eval", "domain_eval")}
    print(f"\n── 3. Full Fine-tuning(자전거 정비 도메인): {FT_STEPS}단계, lr 3e-4 ──")
    ft = train(reloaded, data["domain_train"], {"도메인평가": data["domain_eval"], "일반평가": data["eval"]},
               steps=FT_STEPS, lr=3e-4, warmup=5, device=device, log_every=20)
    show(ft, ("도메인평가", "일반평가"))
    after = {k: eval_loss(reloaded, data[k], device) for k in ("eval", "domain_eval")}
    print("  PPL 비교       학습 전      학습 후")
    for k, label in (("domain_eval", "도메인 평가"), ("eval", "일반 평가")):
        print(f"  {label:<10}{math.exp(before[k]):>10.1f}{math.exp(after[k]):>12.1f}")
    reloaded.save_pretrained(MODELS / "qwen2-tiny-bike")
    tok.save_pretrained(MODELS / "qwen2-tiny-bike")

    peak = resource.getrusage(resource.RUSAGE_SELF).ru_maxrss / 1024      # Linux: KiB → MiB
    print(f"\n── 4. 메모리: 프로세스 최대 RSS {peak:,.0f}MiB(CPU, 모델 두 벌·데이터·라이브러리 포함) ──")
    if device == "cuda":
        print(f"  GPU 최대 할당 {torch.cuda.max_memory_allocated() / 2**20:,.0f}MiB")
    b = full_ft_budget(494_032_768, "AdamW")
    print(f"  0.5B Full FT 고정 메모리 {sum(b.values()) / 2**30:.2f}GiB > GT 1030 2GiB → 실행 불가")

    plot(pre, ft, HERE / "loss_curve.png")
    (HERE / "history.json").write_text(json.dumps({"pretrain": pre, "full_ft": ft}, ensure_ascii=False,
                                                  indent=1), encoding="utf-8")


if __name__ == "__main__":
    main()
```

**결과 읽기**

- **1번 사전학습**에서 일반 평가 손실이 11.99에서 150단계의 5.62까지 내려갑니다. 무작위 모델이 고정 데이터의 문장 패턴을 배웠습니다. PPL로 보면 약 16만에서 약 280으로 줄었습니다.
- 150단계 이후 학습 손실은 0.57까지 계속 내려가지만 평가 손실은 5.62 → 5.84로 다시 오릅니다. **과적합**입니다. 학습 손실만 봤다면 학습이 아주 잘 된 것으로 착각했을 것입니다.
- 학습률 열이 처음 20단계 동안 올라갔다가 Cosine 곡선을 따라 0으로 내려가고, Grad노름은 학습 중반 5~6까지 커졌다가 학습률이 줄면서 1 아래로 내려갑니다. 노름이 1을 넘은 단계는 Clipping이 Gradient를 줄였습니다.
- **2번**에서 저장한 모델을 다시 불러온 결과가 원래 모델과 비트 하나까지 같습니다. 이 폴더를 이후 장에서 그대로 씁니다.
- **3번 Full FT**에서 도메인 평가 PPL이 884.9 → 157.0으로 크게 줄었습니다. 자전거 정비 문장의 표현을 배웠습니다. 그러나 일반 평가 PPL은 342.8 → 399.2로 올랐습니다. 60단계의 짧은 학습만으로도 원래 알던 것을 일부 잊었습니다. **망각**입니다.
- **4번**의 최대 RSS는 CPU 프로세스 전체(모델 두 벌, 라이브러리 포함)의 값입니다. GT 1030 경로에서는 GPU 최대 할당량이 함께 출력되며, 이 값을 설계 예산(약 1.5GB 이하)과 비교합니다(교재 검증 환경 미검증).

이 결과에서 제3부의 다음 질문이 나옵니다. 모든 가중치를 바꾸지 않고, 일부만 학습하면 망각을 줄이면서 메모리도 아낄 수 있지 않을까요? 제26장에서 확인합니다.

# 전체 학습(수 분)은 pretrain_tiny.py로 실행하고, 테스트는 짧은 학습과 저장된 기록을 확인한다.

import json
import math
import sys
from pathlib import Path

import pytest
import torch

HERE = Path(__file__).resolve().parent
for p in (HERE, HERE.parent, HERE.parent / "ch19", HERE.parent / "ch24"):
    sys.path.insert(0, str(p))

from tiny_model import TINY, Qwen2Tiny, init_weights  # noqa: E402
from trainer import eval_loss, train  # noqa: E402


def small_tiny():
    """테스트용으로 계층 1개, 어휘 앞부분만 쓰는 축소판(같은 Qwen2 구조)"""
    from transformers import Qwen2Config, Qwen2ForCausalLM
    cfg = Qwen2Config(**{**TINY, "num_hidden_layers": 1, "vocab_size": 512}, tie_word_embeddings=True)
    torch.manual_seed(0)
    return Qwen2ForCausalLM(cfg)


def test_short_training_reduces_loss():
    torch.manual_seed(0)
    blocks = torch.randint(0, 64, (6, 32))            # 어휘 64개만 쓰는 무작위 데이터
    blocks[:, 1::2] = blocks[:, ::2] + 1                # 규칙: 짝수 위치 다음은 +1
    model = small_tiny()
    hist = train(model, blocks, {"평가": blocks[:2]}, steps=40, batch=2, accum=2, lr=3e-3,
                 warmup=5, log_every=20)
    assert hist[-1]["평가"] < hist[0]["평가"] - 1.0
    assert all(math.isfinite(r["grad_norm"]) for r in hist[1:])


def test_scheduler_ends_at_zero_and_clipping_recorded():
    blocks = torch.randint(0, 64, (4, 16))
    hist = train(small_tiny(), blocks, {}, steps=10, warmup=2, log_every=5, clip=0.5)
    assert hist[-1]["lr"] == pytest.approx(0.0, abs=1e-12)
    assert hist[1]["grad_norm"] > 0                     # 자르기 전 노름을 기록


def test_frozen_parameters_are_not_trained():
    model = small_tiny()
    emb_before = model.model.embed_tokens.weight.detach().clone()
    model.model.embed_tokens.weight.requires_grad_(False)
    train(model, torch.randint(0, 64, (4, 16)), {}, steps=5, warmup=1, log_every=5)
    assert torch.equal(model.model.embed_tokens.weight, emb_before)


def test_save_reload_identical(tmp_path):
    from transformers import Qwen2ForCausalLM
    model = small_tiny().eval()
    model.save_pretrained(tmp_path)
    again = Qwen2ForCausalLM.from_pretrained(tmp_path, dtype=torch.float32).eval()
    ids = torch.randint(0, 512, (1, 12))
    with torch.no_grad():
        assert torch.equal(model(ids).logits, again(ids).logits)


def test_recorded_history():
    path = HERE / "history.json"
    if not path.exists():
        pytest.skip("pretrain_tiny.py를 먼저 실행")
    h = json.loads(path.read_text(encoding="utf-8"))
    pre, ft = h["pretrain"], h["full_ft"]
    assert pre[0]["일반평가"] == pytest.approx(math.log(151936), abs=0.2)
    assert min(r["일반평가"] for r in pre) < 6.0                    # 사전학습으로 크게 감소
    assert ft[-1]["도메인평가"] < ft[0]["도메인평가"] - 1.0           # 도메인 학습 효과
    assert ft[-1]["일반평가"] > ft[0]["일반평가"]                    # 일반 능력 일부 손실(망각)

## 핵심 정리

- 학습 루프는 순전파 → 손실 → 역전파(→ Accumulation) → Clipping → 갱신 → 초기화의 반복이며, 학습률·손실·Gradient 노름·평가 손실을 함께 기록합니다.
- 무작위 Qwen2-Tiny는 300단계의 사전학습으로 평가 손실이 12에서 5.6까지 내려갔지만, 작은 데이터를 반복하면 곧 과적합이 옵니다. 평가 손실로 멈출 지점을 고릅니다.
- Hugging Face 형식으로 저장한 모델은 재로딩 후 출력이 완전히 같으며, 이후 PEFT·TRL·GGUF가 모두 이 폴더를 씁니다.
- Full Fine-tuning은 새 분야의 손실을 크게 줄이지만, 일반 능력의 일부를 잃는 망각을 함께 일으킵니다.
- 0.5B 모델의 FP32 Full FT는 고정 메모리만 7.36GiB로 GT 1030에서 실행할 수 없습니다.

**다음 장 연결:** 제26장에서는 가중치의 일부를 얼리고 나머지만 학습하는 부분 학습을 다룹니다. Qwen2-Tiny의 마지막 Block만 학습해 학습 가능 파라미터와 메모리가 얼마나 줄어드는지, 망각은 어떻게 달라지는지 Full FT와 비교합니다.
