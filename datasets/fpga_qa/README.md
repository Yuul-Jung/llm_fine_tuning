# FPGA 도메인 질의응답 데이터셋 v1

| 항목 | 내용 |
|---|---|
| 파일 | `fpga_qa.json`(작성 원본, 제41장), 제42장에서 JSONL로 변환 |
| 샘플 수 | 50 |
| 형식 | `id`, `category`, `instruction`, `input`(없으면 빈 문자열), `output` |
| 언어·문체 | 한국어, 존댓말 서술형(`~입니다.`), 답변 1~4문장 |
| 출처 | 이 교재를 위해 새로 작성(외부 문서·질의응답 인용 없음) |
| 라이선스 | 교재 원고와 같은 조건으로 배포 |
| 검증 | `examples/ch41/check_dataset.py`(필수 항목, 중복, 분류, 문체) |
| 분할 | `split_v1.json`(제43장): 유사 문항 그룹 단위, 분류마다 validation·test 1개씩, train 38 / validation 6 / test 6 |
| 보강 | `augment_v1.json`(제50장): train 문항마다 질문만 바꾼 변형 1개(38개), 답·입력은 원본과 같음 |
| 평가 기준 | `configs/eval_criteria.yaml`(제43장, version 2): validation·test 문항의 핵심어 포함 |

## 설계표

| 분류 | 목표 수 | 질문 유형 |
|---|---|---|
| 개념 | 10 | FPGA 구조와 설계 단계의 용어 설명 |
| Verilog 문법 | 10 | 문법 요소의 의미, 짧은 코드 해석 |
| 설계 기법 | 8 | 래치, FSM, 카운터, 파이프라인, 리셋, 디바운싱, 고정소수점 |
| 타이밍 | 8 | 셋업·홀드, 슬랙, 임계 경로, 클럭 도메인, 클럭 제약 |
| 도구와 흐름 | 7 | 설계 흐름, 테스트벤치, 제약 파일, 보고서, 디버깅 도구 |
| 디버깅 | 7 | 오류·경고의 원인과 확인 순서, 코드 속 버그 찾기 |

특정 벤더 도구의 명령이나 보드의 핀 번호처럼 제품마다 다른 내용은 답변에 넣지 않거나 "보드의 회로도에서 확인"으로 안내합니다.
