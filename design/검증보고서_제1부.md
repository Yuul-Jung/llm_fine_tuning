## 3. 발견 사항과 조치

| 번호 | 위치 | 문제 | 조치 |
|---|---|---|---|
| 1 | 제01장 04절 | "GT 1030은 FP16이 1/64라 오히려 FP32가 빠르다"고 단정. 제02장은 실제 행렬곱 속도가 라이브러리 처리에 따라 다를 수 있다고 설명해 서로 어긋남 | "하드웨어 16비트 연산 능력이 1/64라 16비트로 계산해도 빨라지지 않는다(제02장 실측)"로 수정 |
| 2 | 제08장 05절 | "어휘가 영어와 코드 데이터를 많이 반영해 만들어졌다"는 학습 데이터 구성 단정(근거 미제시) | 제09장에서 확인한 사실(영어 단어 조각이 어휘에 많음)로 수정 |
| 3 | 제04장 02절 | 제06장에서 정의하는 Softmax를 설명 없이 사용(선수학습 순서) | 처음 등장 위치에 짧은 정의와 장 번호 추가 |
| 4 | 제09장 05절 | "Qwen의 학습 데이터"가 모델 학습 데이터로 읽힐 수 있음 | "Qwen 토크나이저를 학습한 데이터"로 정정 |
| 5 | 설계서 제01장 04절 | 절 제목 불일치 | 설계서를 원고 제목으로 맞춤 |

수정한 장(01·04·08·09)은 rule_md 버전 규칙에 따라 게시 파일을 `_v02`로 올렸습니다.
