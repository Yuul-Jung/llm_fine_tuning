수정한 게시 장의 판 번호: 제41·42·44·49·50장 v02, 제43장 v02, 제47·48장 v03. 8·9번은 게시 전에 고쳐 판 번호에 반영하지 않았습니다.

**test 사용 이력 공개:** 2번 수정 전(제47~49장 v01 작성 중)에 기준 모델·LoRA·QLoRA의 test 답을 저자가 본 적이 있습니다. 그 답을 근거로 바꾼 설정·데이터·기준은 없으며(핵심어와 합격선은 제43장에서 학습 전에 확정, 제50장의 오답 분석과 보강은 validation 답만 근거), 이 사실을 여기에 기록합니다.

## 5. 남은 확인 사항

- 저장소 규칙 3(모든 실습은 `select_device()`로 장치 결정) 대비: 제46~48·50장 실습은 장치를 CPU로 고정함(0.5B FP32는 GT 1030에 들어가지 않는다는 이유는 본문에 있으나, Qwen2-Tiny 경로는 GPU에서도 실행 가능). 제49장은 `hardware()`로 장치를 고름. 다음 개정에서 Tiny 경로에 `select_device()`를 적용하고 0.5B FP32 경로는 CPU 고정 이유를 코드 주석에 남길 것(실패 아님, 미해결로 기록)

- GT 1030 경로: QLoRA 도메인 학습의 실제 최대 VRAM(계산값 895MiB)과 속도, Paged Optimizer 동작
- 데이터 확대: validation·test 각 6문항으로는 작은 지표 차이를 구별할 수 없음. 빈 주제(DSP, generate, ILA 등)의 새 문항과 새 validation·test가 필요
- llama.cpp GGUF 변환과 Ollama 실제 응답(제6부): 사용자 환경 확인 또는 실행 허가 필요(제2부 보고서와 같음)
