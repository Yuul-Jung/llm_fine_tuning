## 3. 발견 사항과 조치

| 번호 | 위치 | 문제 | 조치 |
|---|---|---|---|
| 1 | 제25·26·29장 결과 해석 | 도메인 평가 데이터가 블록 1개(예측 127개)뿐인데, 884.9 → 858.0 같은 작은 PPL 차이도 학습 효과처럼 읽힐 수 있음 | 제25장에 평가 크기의 한계와 "크게 벌어지는 차이만 해석" 원칙을 명시, 제29장에 해당 차이를 의미 있는 학습으로 보지 않는다고 명시 |
| 2 | 제21장 03절 | 파국적 망각을 "제50장에서 측정"이라 했으나 실제로는 제25장부터 측정 | "제25장에서 처음 측정하고 제50장에서 실전 데이터로 다시 측정"으로 정정 |
| 3 | 제28장 04절 | "제29장은 q·v에만, 제30장에서 대상을 바꿔 비교"라 예고했으나 실제로는 제29장이 7종 전부까지 학습 비교, 제30장은 대상별 파라미터 수만 확인 | 실제 구성에 맞게 정정 |
| 4 | 제29장 실습(작성 중 발견) | `apply_lora()`의 A 초기값이 전역 난수 상태에 따라 달라져, 같은 설정을 다른 순서로 실행하면 결과가 달라짐(재현성 결함) | `seed` 인자로 A 초기화를 고정하고 테스트 추가, 재실행 결과로 본문 갱신 |
| 5 | 제29장 결과 | LoRA 7종 설정의 일반 PPL 상승(망각)이 Full FT보다 큼. "LoRA는 망각이 없다"는 통념과 다른 결과 | 결과를 그대로 기록하고 학습률·대상·r이 균형을 정한다고 해석. 제40장 비교 실험의 과제로 연결 |
| 6 | 제27장 결과 | Base → Instruct 변화량 ΔW가 행렬마다 저랭크 정도가 크게 다름(0번 q_proj는 집중, FFN은 거의 집중 없음) | 저랭크 가정을 "목표 과제에 필요한 변화는 저랭크로 충분할 수 있다"로 한정하고, 학습 결과로 판정한다고 서술 |
| 8 | 제28장 실습 2번 | B = 0 예제의 A를 난수 고정 없이 만들어, 실행할 때마다 `dL/dB` 값이 달라짐(본문 출력과 불일치) | 난수 고정(`torch.manual_seed(0)`) 추가, 두 번 실행해 같은 출력 확인 후 본문 갱신 |
| 7 | 제2부 규칙 대조 연장 | 제23·24·27·28장의 소형 수학 실습은 `select_device()` 없이 CPU(일부 FP64)에서 실행 | 유지(의도된 설계): 수치 검증용 소형 계산이며, Qwen2-Tiny 학습 실습(제23·25·26·29·30장)은 모두 `select_device()` 사용 |

수정한 장은 rule_md 버전 규칙에 따라 게시 파일을 올렸습니다: 제21·25·28·29장 v02.
